# B514: turn on B501 and the graph-structure write path by default (walk off), plus the SHACL gate

**Status:** done · **Principle:** 1, 2, 3, 7 (ship behind a flag, gate it, then flip the default)

The levers below were each gated on the published metric and were a gain or score-neutral. The owner
decided to flip their defaults on.

| Flag | Default | Gate |
|---|---|---|
| `[retrieval] conversation_embedded_statements` (B501) | on | LongMemEval oracle preference 0.30 to 0.567 (10 gained / 2 lost); LoCoMo-10 replay pooled 0.526 to 0.548 (22 / 10, up on 3 of 4) |
| `[observations] entities` (B504) | on | R96, with the next three: fresh-ingest LoCoMo 0.517 vs main 0.525 (7 gained / 8 lost, neutral) |
| `[retrieval] graph_linking` (B503) | on | R96 |
| `[retrieval] skos_vocab` (B508) | on | R96 |
| `[observations] owl_properties` (B509) | on | R96 |
| `[observations] shacl_gate` (B507) | on | R93: neutral (1 gained / 1 lost) |
| `[retrieval] graph_linking_limit` | **0** | the v1 walk hurt (R95: 7 gained / 14 lost), so links are written and the walk adds no section; its redesign is gated separately |

Kept off: the v1 walk (limit 0), `graph_walk_v2`, `answer_aggregate`, `[observations] supersede`
(B499's string rule; with `owl_properties` on, B509's OWL supersession replaces it and the writer never
applies both).

Extraction cost: the entity, kind and cardinality fields add roughly 20-40% output tokens per
fact-bearing turn.

The SHACL gate needs pyshacl and rdflib, both core dependencies. If either cannot be imported the gate
logs once and skips; ingest is never blocked.

Tests: `tests/test_b514_flip_defaults.py` pins the defaults. Tests of the old flag-off behaviour set the
flag off explicitly.
