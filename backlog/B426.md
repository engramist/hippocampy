# B426 - Remove Customer (the platform) Name From the Public Repo — Tree + Git History

State: tree genericized (this PR); history rewrite performed separately (see below)
Priority: P1
Branch: chore/genericize-customer-name

### Why

`engramist/hippocampy` is a **public** repo. It named a specific prospective
customer/evaluator throughout — two customer docs (removed in #209), a code path, backlog
cards, plans, and the tracker. A named-customer relationship, their evaluation, and their
deployment specifics should not be public. The user directed a full scrub: genericize the
tree **and** rewrite git history.

### Tree genericization (this PR)

- Removed the two customer docs earlier (#209): `docs/platform-response.md`,
  `docs/platform-integration-guide.md`.
- Genericized the name across the live tree (ordered, context-aware replacements → "the
  platform" / "Multi-Tenant …" / "external review" / "tenant-*"): 2 code comments
  (`embeddings.py`, `schema.py`, plus `brain_daemon.py`), 4 test docstrings/fixtures
  (`test_app_continuity`, `test_bundle_compiler_stages`, `test_embeddings_offline_mode`,
  `test_secret_scrubber`), backlog cards (B311/B345/B347/B348/B362/B365/B385/B425), the
  B-385 plan, `planCardMatches.md`, and `subagent-fanout-execution-plan.md`.
- Renamed `backlog/plans/B-385-cloud-platform-service.md` →
  `…-cloud-multi-tenant-service.md` (filename carried the name).
- Deleted the **stale duplicate** `masterBacklogTracker.md` at repo root (canonical is
  `backlog/masterBacklogTracker.md`).
- Verified: no residual name in the tracked tree; edited test files green (70 passed).

### Git history rewrite (separate, force-push)

Per explicit user authorization, history is rewritten with `git filter-repo` to (a) purge
the two doc files from every commit and (b) replace the name string across historical
blobs + commit messages. A mirror backup is taken first. Repo has 0 forks (bus factor 1),
so collateral of the force-push is minimal. This is the same class of operation as B296
(InvertorsDocs history purge).

### Note

The customer name still exists in Claude/agent session transcripts and any external copies
— out of scope for the repo. This card covers the repository tree + its git history only.
