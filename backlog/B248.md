# B248 - Update ARC_AGI Consumer to HippoCampy/Campy Namespace

State: ready
Priority: P0

Plan: backlog/plans/B-248-update-arc-agi-consumer-to-hippocampy-campy.md

### Problem

ARC_AGI is the known external consumer that still calls SideQuests/`sidequests` integration paths. As HippoCampy migrates public names, import namespaces, MCP server names, CLI commands, and config filenames, ARC_AGI must be updated deliberately so ARC smoke tests and live benchmark workflows continue to use the shared memory system.

### What This Card Does

Defines the cross-repo migration work for the sibling `ARC_AGI` repository. ARC_AGI should prefer Campy/HippoCampy names for new calls while remaining compatible with older local SideQuests installs during the transition.

### Dependencies

- B241 complete - HippoCampy/Campy public branding and CLI aliases exist
- B242 recommended - `campy` Python import namespace shim exists
- B244 recommended before final cutover - MCP/installer module paths use `campy.*`
- ARC_AGI repository available as a sibling repo at `../ARC_AGI`

### Files to Inspect in ARC_AGI

| Path Pattern | Reason |
|---|---|
| `run_single_puzzle.py` | Live smoke runner and brain socket/MCP integration |
| `benchmarks/**/*.py` | ARC benchmark consumers and memory calls |
| `tests/**/*.py` | Tests expecting `sidequests` or old MCP paths |
| `README.md`, `docs/**` | User-facing setup instructions |
| `.env*`, config templates | Old socket/config/env names |
| `pyproject.toml`, scripts, Makefile | CLI/module invocation references |

### Acceptance Criteria

- [ ] ARC_AGI prefers `campy` CLI commands in docs and scripts.
- [ ] ARC_AGI prefers `campy` MCP server name where it configures or documents MCP usage.
- [ ] ARC_AGI supports `CAMPY_BRAIN_SOCKET`, `CAMPY_SOCKET_PATH`, or current Campy transport defaults.
- [ ] ARC_AGI keeps fallback support for legacy `SIDEQUESTS_BRAIN_SOCKET`, `SIDEQUESTS_SOCKET_PATH`, or `~/.sidequests/brain.sock` during the transition.
- [ ] ARC_AGI imports `campy` where Python import access is needed, with `sidequests` fallback only if required for compatibility.
- [ ] ARC_AGI live smoke tests still fail clearly if no daemon socket exists, with error text telling the user to run `campy start` or `campy setup`.
- [ ] ARC_AGI tests cover both new Campy names and legacy fallback names.
- [ ] No ARC_AGI code creates a second durable memory store; it must continue using the shared Campy/KuzuDB memory service.

### Validation Commands

```

```

### Outcome

ARC_AGI becomes a first-class Campy consumer without losing compatibility with currently installed SideQuests-era local memory setups.
