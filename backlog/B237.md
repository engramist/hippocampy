# B237 - Hosted One-Line Bootstrap Installer

State: ready
Priority: P0

Plan: backlog/plans/B-237-hosted-one-line-bootstrap-installer.md

### Problem

The current bootstrap script works from a source checkout, but users still need to clone the repo first. The desired user experience is a single command that bootstraps Campy on a new machine, installs the package, starts the daemon, registers available clients, and tells the user what succeeded.

### What This Card Does

Creates a hosted/public bootstrap installer path suitable for:

```bash
curl -fsSL https://raw.githubusercontent.com/djs54/hippocampy/main/scripts/bootstrap.sh | bash
```

The script should be safe, idempotent, version-aware, and transparent. It should install from the package path created by B236, not from a mutable source checkout unless explicitly requested with a development flag.

### Dependencies

- B236 complete or at least a validated local package artifact
- B231 complete - existing source bootstrap, doctor, and repair behavior

### Acceptance Criteria

- [ ] `scripts/bootstrap.sh` is shellcheck-clean where shellcheck is available, and `bash -n` clean everywhere.
- [ ] Bootstrap rejects unsupported Python versions with an actionable message.
- [ ] Bootstrap creates or uses an isolated install location (`pipx`, `uv tool`, or managed venv) without writing into system Python.
- [ ] Bootstrap is idempotent: running it twice does not duplicate Codex, Claude, VS Code, launchd, or skill config.
- [ ] Bootstrap never deletes `~/.campy/brain.db`, journals, logs, or user wiki/manual notes.
- [ ] Bootstrap starts or repairs the daemon and then runs `campy doctor`.
- [ ] Bootstrap registers Codex, Claude Code, Claude Desktop, and VS Code when present, and reports skipped clients clearly.
- [ ] Bootstrap can run in `--dry-run` mode and print planned actions without mutating the machine.
- [ ] Bootstrap supports `--dev-source PATH` for local development installs without making that the public default.
- [ ] README contains the final one-line command plus a safer inspect-first variant.

### Validation Commands

```bash
bash -n scripts/bootstrap.sh
bash scripts/bootstrap.sh --dry-run
.venv/bin/pytest -q tests/test_bootstrap_script.py tests/test_installer_idempotency.py tests/test_doctor_cli.py tests/test_setup_cli.py
rg -n "curl -fsSL|bootstrap.sh|pipx|uv tool|doctor" README.md Instalation_Instructions.md scripts tests
```

### Outcome

A user can bootstrap Campy from one terminal command without first cloning the repo, while still getting safe diagnostics, idempotency, and explicit visibility into what changed.
