# B241 - Rename Product to HippoCampy and Add `campy` CLI

State: complete
Priority: P0

Plan: backlog/plans/B-241-rename-product-to-hippocampy-campy.md

### Problem

The public package/name `sidequests-brain` is not available as the desired public identity, and the existing naming is too repo-specific for a friendly one-click install. The project needs a durable public name before PyPI, bootstrap, Homebrew, and public docs are finalized.

The proposed name is **HippoCampy**, with **`campy`** as the short command name. This preserves the hippocampus/memory metaphor while making the product friendlier and easier to type.

### What This Card Does

Renames the public-facing product identity from HippoCampy to HippoCampy, adds `campy` as the primary CLI command, and preserves backwards compatibility for existing local users through aliases and migration behavior.

This card intentionally separates product branding from graph ontology. Existing graph concepts such as `MainQuest` and `SideQuest` remain valid domain terms unless a later schema-migration card explicitly renames them.

### Dependencies

- B230 complete - installed-mode package resources exist
- B231 complete - installer/doctor are idempotent enough for migration work
- B236 should use the new package name before public publication

### Naming Decisions

| Layer | New Name | Compatibility Rule |
|---|---|---|
| Human product name | HippoCampy | Replace public-facing `HippoCampy` branding |
| Short name | Campy | Use in docs and installer output |
| CLI command | `campy` | Keep `sidequests` as deprecated alias for at least one release |
| Daemon command | `campy-daemon` | Keep `sidequests-daemon` alias for at least one release |
| Python distribution | `hippocampy` preferred | Verify availability before publishing; fallback to `campy-memory` or `hippocampy-memory` if unavailable |
| Python import package | keep `sidequests` initially | Avoid breaking internal imports in this card; optional wrapper package can be added later |
| Runtime directory | `~/.campy` preferred | Auto-migrate or alias from `~/.sidequests`; never delete user memory |
| Launchd label | `ai.hippocampy.brain` | Keep old `ai.sidequests.brain` cleanup/compat support |
| MCP server name | `campy` / `hippocampy` | Remove duplicate old blocks safely; keep old aliases during migration |
| OpenClaw extension id | `hippocampy` or `campy-memory` | Preserve old extension migration notes |
