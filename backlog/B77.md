### B77 · Graph Cycle Detection: O(n) List Scan → Set Lookup

**Problem:** `explore_graph` BFS/DFS inner loop uses `if nbr["id"] in [n["node_id"] for n in curr_nodes]` which rebuilds a list on every neighbor check. With 1000 nodes visited and high-degree nodes (100+ edges), this is O(100k) comparisons per expansion.

**What it does:** Replaces the O(n) list scan with an O(1) set membership check.

**Depends on:** None

**Files to modify:**
- `mcp_engine/tools/explore_graph.py` — use `visited_ids: set` instead of list comprehension

**Adapter allow-list propagation check:** No tool changes — N/A.

**Acceptance Criteria:**
- `explore_graph` uses a `set` for visited node tracking, not a list comprehension
- `rg "visited" mcp_engine/tools/explore_graph.py` shows set usage
- `pytest tests/ -k explore_graph -q` passes
- No behavioral change (same nodes returned, same traversal order)

**Outcome:** `explore_graph` performance scales linearly with graph size instead of quadratically.
