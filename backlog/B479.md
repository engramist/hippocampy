# B479 - Query Understanding: Boost the Speaker and Date the Question Names (M2.3)

State: implemented (2026-10-10; boosts ship OFF, gate pending)
Priority: P2

Plan: `learnings/e2e-improvement-plan.md` M2.3

### Problem Statement

Conversation questions name who said it ("What did Speaker 1 say about...",
"Where has Melanie camped?") and sometimes when ("in May 2023"). The
conversation stage ignores both, although every Message now carries
`speaker` and `occurred_at` (B472).

### Fix

`campy/brain/thalamus/query_cues.py::parse_query_cues(question,
known_speakers)` -- pure, regex only, no LLM -- returns the speaker(s) with a
weight and explicit time ranges. `GraphGateway._apply_query_cues` adds
`boost * weight * top_fused_score` to matching candidates before ranking
(boost, never filter). Rules are documented in the module docstring:

- Speaker: "Speaker N" or a known speaker name (distinct speakers among the
  retrieval candidates -- no extra query, no cache). The evidence speaker is
  the one the question says said/mentioned/told something; an addressee
  ("asks Speaker 1", "to Speaker 1") is dropped; if nothing marks one, the
  non-addressee mentions share the weight (1.0 alone, 0.5 each).
- Time: only absolute expressions (ISO date, "May 8, 2023", "May 2023",
  "in 2023"). "in May", "last week" are not resolvable and give no range.
  Matches against `occurred_at` only (stored time is not event time).

Config (both default 0.0 = off; a new NamedQuery
`thalamus.bundle_conversation_cued` carries the params, the existing query is
untouched and still used when both are 0):

| setting | env var |
|---|---|
| `[retrieval] speaker_boost` | `CAMPY_RETRIEVAL_SPEAKER_BOOST` |
| `[retrieval] time_boost` | `CAMPY_RETRIEVAL_TIME_BOOST` |

Scale: fused RRF scores top out near 2/60; a boost of 0.5 adds half the
leader's score, about one to two rank steps among the leaders.

### Measure

A/B on DMR and LoCoMo-10 (T0 replay, golden stores) with the env vars at
0.25 / 0.5 / 1.0 vs off. Done when DMR and LoCoMo-10 temporal are up and
nothing else is down; then pick a default.
