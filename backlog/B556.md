# B556: regenerating the migration fixture writes edge properties that write_edge rejects

**Status:** Open. Found while merging B549 (2026-11-06).

**Principles:** P6 (a test must measure what it claims).

**What was seen.** B549 added a Concept column and regenerated `tests/fixtures/exhaustive_migration_graph.jsonl`. The generator gave the INSTANCE_OF and BROADER rows the edge properties that schema.py declares (link_source, link_status, agreed_by, evidence_set, steward_reason). But `oxigraph_client.EDGE_REIFICATION` classifies both edges as `plain`, because those annotations are written through SPARQL (kinds.link_broader_sourced, the B535 steward), not `write_edge`. So `test_migration_roundtrip` raised "INSTANCE_OF is classified 'plain' (no properties) but properties were passed". B549 kept main's edge rows by hand.

**To do.** Make the generator skip the properties of edges that EDGE_REIFICATION classifies as plain, or mark those columns SPARQL-only in schema.py so the generator and the classification agree. Add a test that the regenerated fixture equals the committed one.

**Related files.** scripts/generate_migration_fixture.py tests/test_migration_roundtrip.py
