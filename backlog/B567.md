# B567: an allowed predicate in another form is kept, not rejected

**Status:** Fixed 2026-11-13 (`observations/extract.py`: `predicate_lemma_key`, `predicate_by_lemma`; count
`predicate_normalised`). Found by the capture-recall diagnosis of the step-Q "no fact on a gold turn" class.

**Principles:** P3 (the closed set of nine predicates still decides; only the form is normalised), P6.

**What.** The extractor proposed "prefer" where the closed set has "prefers". On a re-run over the 57 substantive gold
turns with no fact, this happened 7 times on 3 gold turns (and twice on 60 control turns). The predicate check rejected
each as `bad_predicate`, though the predicate is allowed.

**Rule.**
- A proposed predicate that is not one of the nine, but whose lemma key equals that of an allowed predicate, is kept as
  the allowed predicate. The lemma key is the words joined by "_", with the first word reduced to its verb lemma by
  WordNet.
- The mapping is derived once from `observations.PREDICATES`, never from a list of seen errors: prefer -> prefers,
  plan -> plans, own -> owns, do -> did, relate_to -> relates_to, locate_in -> located_in, change_to -> changed_to,
  have_attribute -> has_attribute, be_a -> is_a.
- Any other form ("wrote", "was", "loved") is still rejected.
- Without WordNet nothing is mapped.
- A rule fix at the write, so there is no flag.

**Measure.** Re-run the extractor on the same 57 gold turns, then run step Q on those copies.
Prediction: +0 to +2 query hits; "no fact on a gold turn" from 79 to 76-79.
