### Problem

Investigation B355 successfully migrated Campy's embedding backend to `fastembed` / ONNX Runtime, reducing the embedding engine's own memory footprint by ~6.5x (from 1.22 GB down to 186 MB). However, B355's verification revealed that the live `brain_daemon.py` still starts with an idle baseline resident footprint of **~1.2 GB**.

**Root cause:** Step 1 (NER Zoning) and Step 1b (Fast Relations) depend on `spacy` (`en_core_web_md`). spaCy's internal machine learning backend (`thinc`) imports `torch` unconditionally at module import time, independent of whether PyTorch is needed for the configured model. Once `libtorch` is loaded into Python process memory:
1. Native C++ arenas and thread pools are initialized, imposing a non-reclaimable ~1 GB physical footprint floor.
2. In multi-tenant or containerized environments (e.g. AWS ECS tasks, Docker containers), this inflated baseline makes Campy vulnerable to sudden `OOMKilled` events when small query bursts occur.
3. It prevents Campy from fulfilling its promise as a lightweight, transparent background daemon for developer laptops.

### What it does (scope)

This card decouples Step 1 and Step 1b from PyTorch-dependent spaCy runtimes, dropping the daemon's startup footprint from ~1.2 GB to **<200 MB**.

1. **Lightweight NER Zoning (Step 1):**
   - Replace the heavy spaCy pipeline with an ONNX-native token classification model using `fastembed` or direct `onnxruntime` (e.g., a quantized MiniLM or BGE NER head).
   - Reuses the ONNX Runtime execution provider already loaded by the embedding engine, incurring zero additional framework overhead.
   - Preserves extraction of core entity categories: `PERSON`, `ORG`, `PRODUCT`, `CONCEPT`, `EVENT`.

2. **Lightweight Universal Verb Extraction (Step 1b):**
   - Refactor Step 1b's syntactic relation extraction (matching universal verb lemmas: *require*, *enable*, *replace*, *contradict*, *part_of*) to use a lightweight dependency parser or rule-based POS tagger that does not link to `libtorch`.
   - Maintain 100% extraction parity for the 5 core universal relation types.

3. **Dependency and Import Isolation:**
   - Remove `spacy` and `thinc` from mandatory runtime dependencies in `pyproject.toml` and `requirements.txt`.
   - Add an automated CI barrier test: `assert 'torch' not in sys.modules` upon importing `campy.brain_daemon`.

4. **Footprint Validation:**
   - Measure physical footprint using `vmmap -summary` on macOS and `/proc/[pid]/status` on Linux, verifying startup footprint < 200 MB.
