# B238 - Clean-Machine One-Click Installer Validation Harness

State: ready
Priority: P0

Plan: backlog/plans/B-238-clean-machine-one-click-validation-harness.md

### Problem

A bootstrap script is not trustworthy until it has been tested from a clean environment. Local success on the development machine is not enough; the install path must be validated against fresh macOS-style homes, missing configs, absent launchd plists, missing clients, and partially-installed states.

### What This Card Does

Builds a repeatable validation harness for the one-click installer. The harness should simulate clean homes and optionally run on an actual disposable macOS user/VM. It should verify package install, daemon launch, socket health, client config idempotency, activity logging, and uninstall/repair behavior.

### Acceptance Criteria

- [ ] Harness can run with a temporary `HOME` and does not touch the developer's real `~/.campy`.
- [ ] Harness validates fresh install from no config/no daemon/no client state.
- [ ] Harness validates repeated install is idempotent.
- [ ] Harness validates partial install repair: missing launchd plist, missing Codex config block, missing skill, and missing activity log.
- [ ] Harness verifies daemon socket exists and `campy status` succeeds after install.
- [ ] Harness verifies `campy activity --lines 5` works after install.
- [ ] Harness verifies `campy tool list` includes `memory_decision` and expected core tools.
- [ ] Harness can skip client-specific checks when the client binary/config is absent, without failing the whole install.
- [ ] Validation docs include a manual checklist for the user's work computer.
- [ ] CI workflow is added only if it can run without secrets or private machine state.

### Validation Commands

```bash
bash -n scripts/validate_one_click_install.sh
bash scripts/validate_one_click_install.sh --dry-run
.venv/bin/pytest -q tests/test_bootstrap_clean_home.py tests/test_bootstrap_script.py tests/test_installer_idempotency.py tests/test_doctor_cli.py
HOME=$(mktemp -d) bash scripts/bootstrap.sh --dry-run
```

### Outcome

The one-click installer has evidence from clean-environment validation instead of relying on the development machine's already-working state.
