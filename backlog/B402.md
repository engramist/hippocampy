### Problem

`CLAUDE.md` names `docs/ARCHITECTURE.md` as the source of truth for architecture and
design, shared across all agents (Claude, Gemini, Codex). But architectural questions
that are **open** — under investigation, measured but unresolved, or deliberately
deferred — have nowhere to live in it.

They currently scatter:

- `docs/superpowers/specs/` — dated design docs, discoverable only if you already know
  the filename
- backlog cards — scoped to a unit of work, not to a standing question
- conversation transcripts — effectively lost

Concrete cost, from this week: the analysis of whether the spaCy ingestion step earns
its place produced a real finding (the graph carries a SKOS `Label` gazetteer that
Step 1 never consults — entity recognition without entity linking). That reasoning
lives in one dated spec file. An agent reading `ARCHITECTURE.md` — which is what the
Layer 1 File Bridge and every onboarding path point at — would never find it, and
would reasonably assume the spaCy step is settled design.

The same gap swallowed B384's `<80 MB` premise: it was import-time-only RSS, was
never re-derived, and got repeated into four cards before anyone measured warm.

### What it does

Add an **Open Research Questions** section to `docs/ARCHITECTURE.md` that indexes
active and resolved investigations, so the source-of-truth document distinguishes
*settled design* from *current best guess*.

Each entry carries:

- **Question** — stated as a question, not a task
- **Status** — `open` / `measuring` / `resolved` / `deferred` (with the deferral reason)
- **Why it matters** — what changes depending on the answer
- **Evidence so far** — measured numbers, with how they were measured
- **Where the detail lives** — link to the spec/design doc
- **Decision rule** — what result implies what action, where one has been fixed in advance

### Acceptance Criteria

- [ ] Section added with a stated format and all four seed entries populated.
- [ ] Every entry links to its evidence; no claim without a source or a measurement.
- [ ] Numbers carry their methodology (warm vs cold RSS, sample size).
- [ ] Cross-referenced from `Required Companion References` so it is reachable from
      the top of the document.

      already known, including what is known to be uncertain.

### Outcome

Open questions live in the source of truth alongside settled design, so an agent can
tell the difference — and a measured correction (like the `<80 MB` figure) propagates
instead of being rediscovered.
