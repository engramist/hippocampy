# B222 - Read-Only Markdown Wiki Exporter from Dreaming

State: complete
Priority: P1

Plan: backlog/plans/B-222-read-only-markdown-wiki-exporter.md

### Problem

SideQuests has graph-native memory and Dreaming synthesis, but there is no generated human browsing surface. Users must query tools or inspect the graph directly, which is powerful but not tactile.

We need a read-only Markdown exporter that creates Obsidian-compatible pages from graph memory without creating a second data store.

### What This Card Does

Adds a wiki projection writer that runs during the sweep/Dreaming phase and writes bounded, read-only Markdown pages from KuzuDB nodes and edges.

This card implements the exporter for the default persona only. Persona-specific filtering is handled by B223. It also adds the first easy-use path: a generated Obsidian vault with `Home.md`, index pages, stable wiki links, and CLI commands to find or open the vault.

### Acceptance Criteria

- [x] Exporter writes Markdown under a configured output directory, defaulting to `wiki/personas/default/`.
- [x] Exporter creates an Obsidian-friendly vault structure with `Home.md`, `Index.md`, `Topics.md`, and `Sources.md`.
- [x] Pages use Obsidian-style `[[Wiki Links]]` for related pages and stable source-backed page titles.
- [x] `sidequests wiki path` prints the generated vault path.
- [x] `sidequests wiki open` opens Obsidian via an `obsidian://open` URL when available, and falls back to opening the folder or printing the path.
- [x] `sidequests wiki status` reports whether projection is enabled, output path, last generated timestamp if known, and page count.
- [x] Each page has projection front matter with `source_node_ids`, `generated_at`, `persona`, and `manual_edits_supported: false`.
- [x] Exported pages are deterministic for the same graph state.
- [x] Exporter writes atomically via temp file then rename.
- [x] Exporter never reads Markdown projection files back into memory.
- [x] Page size is bounded by config to prevent token bloat.
- [x] Related-page and backlink counts are bounded by config to avoid noisy Obsidian graph views.
- [x] Sweep summary reports wiki pages written/skipped/errors.
- [x] Feature is disabled by default unless `[wiki_projection].enabled = true`.
