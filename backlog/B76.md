### B76 · Add Embedding Dimension Validation at Schema Init

**Problem:** Schema declares `FLOAT[384]` for all embedding columns. If the config's embedding model produces a different dimension (e.g., 768 from `bge-base-en-v1.5`), schema init succeeds but all embedding writes silently fail or produce truncated vectors.

**What it does:** At schema initialization, embeds a test string and asserts the dimension matches the declared schema dimension.

**Depends on:** None

**Files to modify:**
- `mcp_engine/schema.py` — add dimension check in `init_schema()`

**Adapter allow-list propagation check:** No tool changes — N/A.

**Acceptance Criteria:**
- `init_schema()` calls `emb.embed("test")` and checks `len(result) == 384`
- If dimension mismatch, raises `ValueError` with clear message: "Embedding model produces {actual} dimensions but schema expects 384"
- `pytest tests/ -k schema -q` passes
- Test added that verifies the dimension check fires on mismatch

**Outcome:** Misconfigured embedding models are caught at startup, not at write time.
