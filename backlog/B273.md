### Problem

Users who prefer Homebrew should be able to install Campy with `brew install hippocampy`. This is especially natural for macOS users who already use brew for their development tools.

### What This Card Does

Creates a Homebrew formula that installs hippocampy and its dependencies, sets up the daemon via launchd, and runs `campy setup`.

### Dependencies

- B272 (install script — shares the install logic, formula can reference it)
- Package must be published to PyPI first

### Files to Create

1. **`scripts/homebrew/hippocampy.rb`** — Homebrew formula:

```ruby
class Hippocampy < Formula
  include Language::Python::Virtualenv

  desc "AI memory that learns from every conversation"
  homepage "https://github.com/engramist/hippocampy"
  url "https://files.pythonhosted.org/packages/source/h/hippocampy/hippocampy-0.1.0.tar.gz"
  sha256 "PLACEHOLDER_SHA256"
  license "Apache-2.0"

  depends_on "python@3.12"

  def install
    virtualenv_install_with_resources
  end

  def post_install
    system bin/"campy", "setup"
  end

  def caveats
    <<~EOS
      To start the Campy brain daemon:
        campy start

      To check status:
        campy status

      To re-register with AI agents:
        campy setup
    EOS
  end

  test do
    assert_match "HippoCampy", shell_output("#{bin}/campy --version")
  end
end
```

2. **Create a Homebrew tap repository** (separate repo: `engramist/homebrew-campy`):
   - This is a separate GitHub repo, not a file in this repo
   - Contains the formula above
   - Users install with: `brew tap engramist/campy && brew install hippocampy`
   - Or submit to homebrew-core for `brew install hippocampy` directly (requires package popularity)
