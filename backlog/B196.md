## Problem Statement

Step 6 (Contradiction Arbitration) checks incoming content against existing nodes in the gray zone (similarity 0.75-0.92). But it only fires during ingestion — if two Lessons were ingested at different times and ended up contradicting each other, the system never notices.

Karpathy's "lint" concept: periodically scan the entire knowledge base for contradictions, stale facts, and orphaned pages.

## Root Causes

1. Step 6 only compares new content vs existing — not existing vs existing
2. No periodic pairwise audit of high-strength nodes within the same domain
3. `CONTRADICTS` edges only created during ingestion, not by post-hoc analysis
4. No detection of Lessons that give opposite advice for the same archetype

## What This Card Does

1. **New sweep step**: `_audit_consistency()` — runs after dreaming, before centroid recomputation
2. **Pairwise comparison**: For each domain, find Lesson pairs with embedding similarity > 0.70 but conflicting content (detected by LLM)
3. **Action options**:
   - High confidence both → Create `DisambiguationEvent` for human review
   - One clearly supersedes → Create `DEPRECATED_BY` edge, archive the old one
   - Both valid in different contexts → LLM synthesizes a nuanced meta-lesson (B191)
4. **Stale fact detection**: Lessons older than 30 days with no recent `APPLIES_TO` or `RELATED_TO` activity → flag as potentially stale
5. **Orphan detection**: Lesson nodes with no inbound edges (never linked to anything) → flag for review

## Graph Design (Graph Expert Analysis)

**No new node types.** Uses existing `DisambiguationEvent`, `DEPRECATED_BY`, `Lesson`.

**Access pattern for pairwise audit**:
```cypher
MATCH (l1:Lesson), (l2:Lesson)
WHERE l1.domain = l2.domain AND l1.lesson_id < l2.lesson_id
  AND l1.archived = false AND l2.archived = false
  AND l1.pathway_strength > 0.3 AND l2.pathway_strength > 0.3
WITH l1, l2
-- Then vector similarity check in application code (Kuzu can't do cross-node vector similarity in Cypher)
```

**Performance concern**: Pairwise is O(n^2) within a domain. Mitigate:
- Only audit top-20 highest-strength Lessons per domain per sweep
- Skip pairs already audited (track via `last_audited_at` on Lesson)
- Run at most 10 LLM calls per sweep cycle

**Stale detection**:
```cypher
MATCH (l:Lesson)
WHERE l.archived = false AND l.lesson_type != 'synthesis'
  AND l.created_at < timestamp($thirty_days_ago)
  AND NOT EXISTS { MATCH (l)-[:APPLIES_TO|RELATED_TO|GENERALIZES_LESSON]->() }
RETURN l
```

**Orphan detection**:
```cypher
MATCH (l:Lesson)
WHERE l.archived = false
  AND NOT EXISTS { MATCH ()-[:CONTAINS_LESSON|PRODUCED_LESSON|PRODUCED_PLAN_LESSON|LEARNED]->(l) }
RETURN l
```
