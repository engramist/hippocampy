# B480 - Optional Two-Step "Select Then Answer" Mode for ask (M4.3)

State: implemented (2026-10-10; default off; gate pending)
Priority: P2

Plan: `learnings/e2e-improvement-plan.md` Part D stages 4/5 and M4.3;
`learnings/2026-10-m2-reranker.md`; `learnings/e2e-status.md`.

### Problem Statement

On DMR the right turn is in the bundle for most lost questions, and the 8b
answer model answers from a similar, wrong turn. The one gain so far came from
the prompt (B475 cite-or-abstain: DMR 0.52 -> 0.60, LoCoMo-10 adversarial
0/12 -> 3/12). Every retrieval change since (rank order, reranker, near-dup
collapse, speaker/date boosts) flipped several answers each way and netted ~0
or negative, and a larger answer model (gemma4:26b) did not help (DMR
0.60 -> 0.59, LoCoMo-10 0.35 -> 0.28, and it never abstains). The failure is
in choosing among lines the model is shown, so make that choice a separate,
easy step.

### Implementation

`[ask] answer_mode = "direct" | "select"` (default `"direct"`, byte-identical
to before). Env override `CAMPY_ASK_ANSWER_MODE`.

1. Select step: same bundle; every rendered evidence item is numbered
   `[1]..[n]` (across sections); one LLM call (temperature 0, no token cap,
   so reasoning-style models cannot return an empty capped reply) asks which
   lines contain the answer.
2. Reply `NONE` -> return "I don't have that information." with no second
   call. Otherwise the answer prompt is rebuilt from ONLY the selected lines,
   keeping section headers/descriptions and stamps, with the existing
   cite-or-abstain instruction.
3. Unparseable reply (empty, no integers and no NONE, all numbers out of
   range) -> fall back to the full direct prompt for that question.
   Out-of-range numbers among valid ones are ignored.
4. `meta` records `answer_mode`, `n_lines`, `selected_lines` (None on
   fallback), `select_fallback`.
5. Harness variants: direct mode unchanged. In select mode H2 guards the
   final answer only (never the select reply or the NONE abstention); H1's
   identifier preamble is skipped when a selected-lines prompt is used (it
   would re-inject lines the selection dropped) and applies on fallback.
   Compression runs before selection, unchanged.

### Measure (gate pending)

Replay DMR and LoCoMo-10 with `CAMPY_ASK_ANSWER_MODE=select` vs direct.
Watch abstention rate on adversarial questions and `selected_lines` accuracy
from `meta`. Merge as default only if net gain beyond the within-noise flips
seen from the retrieval changes; otherwise keep as an opt-in flag. Costs one
extra LLM call per question.
