# B246 - Make `campy-memory` the Only Primary Skill Namespace

State: complete
Priority: P1

Plan: backlog/plans/B-246-make-campy-memory-primary-skill-namespace.md

### Problem

The canonical memory-use skill was renamed to `campy-memory`, but legacy `sidequests-memory` folders still exist for compatibility. We need to make `campy-memory` the only primary source while keeping old installed skills from breaking abruptly.

### What This Card Does

Makes `skills/campy-memory/SKILL.md` and packaged `campy-memory` the canonical skill. Legacy `sidequests-memory` becomes a short forwarding/deprecation note or compatibility resource only.

### Dependencies

- B241 complete - Campy memory skill exists
- B242 complete - Campy namespace exists

| File | Action |
|---|---|
| `skills/campy-memory/SKILL.md` | MODIFY - canonical source of truth |
| `campy/data/campy-memory/SKILL.md` | MODIFY - packaged copy matches canonical |
| `skills/sidequests-memory/SKILL.md` | MODIFY - deprecated forwarding note, no full duplicate policy |
| `sidequests/data/sidequests-memory/SKILL.md` | MODIFY - legacy packaged forwarding note if retained |
| `campy/cli/register.py` | MODIFY - install `campy-memory`, repair/remove stale owned `sidequests-memory` when safe |

### Acceptance Criteria

- [ ] Canonical skill tests read `skills/campy-memory/SKILL.md`.
