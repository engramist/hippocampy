# B473 - Relation Noise on Chat: Invented Engineering Relations and Bare Endpoint Concepts

State: implemented (2026-10-10; measurement pending)
Priority: P1

Plan: (inline — this card is self-contained)

### Problem Statement

Found by B472's Phase 0 store audit: campy-benchmarks R20a, DMR, 50
questions, hippocampy `402c96c`, llama3.1:8b, run with `diag_graph_audit.py`
over the 50 kept stores (engramist/hippocampy#278):

- **Step 3b invents engineering relations on chat.**
  - The stores held 943 ALTERNATIVE_TO, 233 CHOSEN_OVER and 162 EXTENDS
    edges. Only Step 3b's LLM writes those types (Step 1b's verb patterns
    cannot).
  - The conversations are persona chit-chat ("Mustang", "my car", "Taylor
    Swift"), not choices between options.
  - Step 3b ran whenever a message had two or more typed entities that
    Step 1b had not related. The model, offered five types and "or null",
    mostly picked a type.
- **Bare Concepts for LLM endpoint strings.**
  - 1,784 of 2,047 Concepts (87%) had no gist class.
  - `_store_relation` calls `_ensure_concept_exists` on both endpoints and
    creates a minimal, untyped `confidence_low` Concept
    (`create_minimal_concept`) for any string that matches no Concept.
  - An LLM's endpoint strings are its own wording, so each mismatch minted a
    bare Concept, and the invented edge then linked them.
- **Why it matters.** Both feed the graph that B472's later phases, and the
  bundle's graph stage, would traverse. They also inflate concept counts,
  lower the precision of Step 5 matches, and cost an LLM call per message.

### Decision and Implementation

1. **Cue gate for Step 3b.**
   - The Loop calls `extract_semantic_relations` only when
     `step3b_relations.has_relation_cue(text)` holds. That means a choice,
     replacement, realization or extension cue: "instead of", "rather than",
     "vs", "alternative", "chose/picked/selected/went with/decided",
     "prefer", "replac*", "supersed*", "deprecat*", "migrat*",
     "switch/swap", "upgrade/downgrade", "retire", "phase out",
     "implement*", "extend*", "extension/plugin", "built/based on", "on top
     of", "wrap*", or a "moved/changed/ported ... from ... to" clause.
   - Skips are counted in the Loop summary (`step3b_skipped_no_cue`).
   - `extract_semantic_relations` itself is unchanged.
2. **LLM relations link only existing Concepts.**
   - A relation with `inferred_by == "LLM"` is stored only when both
     endpoints resolve, via `_endpoint_concept_id`: exact text first,
     strongest first, then any preferred or alternative Label (B472 Phase
     2). Otherwise it is dropped and counted
     (`relations_dropped_unresolved`).
   - Step 1b's syntactic relations (`inferred_by == "system"`) and
     precomputed ones still create missing endpoints. B32 and B464 need
     that: "Final decision: nose2 has been replaced by pytest" can be the
     only place "pytest" is named.
   - Endpoint lookup for every relation now also accepts labels.

Tests: `tests/test_b473_relation_noise.py`:
- cue and no-cue sentences, including the B464 and B468 phrasings and chat
  or travel sentences;
- the Loop skipping Step 3b without a cue and reaching it with one;
- an unresolved LLM endpoint creating nothing;
- an LLM relation between existing Concepts (one by alternative label)
  being stored;
- a Step 1b REPLACES still creating both endpoints.

### Measurement (pending)

Run `diag_graph_audit.py` on DMR and LoCoMo-10 stores built with the B473
commit, against R22 (B472 Phase 2):
- ALTERNATIVE_TO / CHOSEN_OVER / EXTENDS counts and untyped Concepts should
  fall sharply;
- accuracy and evidence recall must not regress;
- the LoCoMo **fixture** must stay 28/28 with 0 INVERTED supersession
  edges (`diag_supersession_edges.py`). Supersession sentences carry cues,
  and Step 1b keeps creating their endpoints.

### Risks

- A real choice phrased without a listed cue ("Postgres beat MySQL in our
  tests") loses its Step 3b relation. Step 1b and the decision senses are
  unaffected. Widen the cue list from measured misses, not in advance.
- An LLM relation whose endpoint was named only in that message, and never
  became a Concept, is dropped. That is the intended trade: no Concept is
  minted from model wording.
