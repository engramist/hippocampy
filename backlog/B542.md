# B542: rebuilt capture lane: NLP marks every turn, the model answers closed questions, a rule writes typed facts

**Status:** Open. Phase 1 (design and offline replay on store copies) before any code.

**Principles:** P8 (every fact hangs off its subject by a typed relation to a typed object entity), P3 (NLP and the model propose; one declared rule writes), P2 (list, count and latest answers then come from a query on the subject), P7 (behind a flag; the current path stays as it is until the gate).

**Why.** Tracing "What books has Tim read?" (conv-43 D6:8, 2026-10-27): spaCy labels "The Name of the Wind" `WORK_OF_ART` correctly, then the Loop drops it. Step 2 compares the embedding of the whole message with seven class centroids written for software work (this turn 0.179, noise floor 0.18; 27% of conv-43 turns and 19% of conv-26 turns lose every entity this way), and step 4 keeps an entity only as a decision, constraint, requirement or action item (a title survives only if it is called a constraint or an action item; people never survive without a keyword). In conv-43, places 1 of 22, organisations 0 of 16 and titles 1 of 9 became Concepts. The Observation extractor reads the turn but writes the object as free text (`prefers: "really good"`). B540 and the L3 screen hit the same wall: the object entities are not in the graph.

**Shape** (the practices that worked in the earlier project's capture trials):
1. **NLP marks every turn, as evidence, never as a filter:** named entities with labels, quoted titles, noun phrases, what "it"/"that" refers to inside the turn, time expressions (B538).
2. **A fixed package per window of turns:** the marked turns, the known subjects (speakers and people already in the graph), the kind vocabulary (B525) and the relation vocabulary.
3. **The model reads every turn and answers closed questions:** the subject from the closed list, the relation from the vocabulary, the object as an exact span of the turn, its kind from the vocabulary or "new kind" as a candidate. The model never creates an id.
4. **One declared rule writes:** an Observation with subject -> relation -> object entity (INSTANCE_OF kind) -> source turn, only when the quote and span check out; every NLP-marked named entity becomes a Concept with its label whatever the model says.
5. **The old decision tracker no longer decides what is stored** (B543).

**Measure.** Phase 1, offline on store copies (design conversations, then the unseen ones unchanged): named entities stored against those NLP finds; gold evidence turns with an Observation; Observations with a typed object entity and a subject; the L3 kind-query reach on the 130 / 183 missing gold turns (5 / 9 today); a seeded hand audit of 60 written facts. Phase 2: GPU gate on unseen LoCoMo against main, decision rule as usual.
