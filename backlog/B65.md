### B65 · Register Missing Tools in OpenClaw Extension

**Problem:** The OpenClaw extension only exposes 7 of the 13+ tools available in the Brain Daemon, missing critical functionality like `set_quest`, `explore_graph`, and `ingest_document`.

**What it does:** Adds the missing tool registrations to the OpenClaw extension's `index.ts` and ensure they are properly mapped to the Brain Daemon's MCP endpoints.

Missing tools to add:
- `set_quest`
- `explore_graph`
- `diff_since`
- `branch_quest`
- `complete_quest`
- `ingest_document`

**Acceptance Criteria (Evaluation):**
- `extensions/hippocampy/src/index.ts` registers all mentioned tools.
- Each new tool correctly forwards requests to the Brain Daemon.
- Agent can see and use these tools when allowed by sandbox policy.

**Outcome:** Full power of the Brain Daemon is available to OpenClaw-based agents.
