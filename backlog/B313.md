# B313 - Authority Property: Projected vs Earned Memory

State: todo
Priority: P0

Plan: (inline — self-contained, sized for a Sonnet-level implementer)

Depends on: **B312** (provenance fields). B313 reuses `source` and `source_version`, so
land B312 first.

### Why

Campy's `CLAUDE.md` states: *"KuzuDB is the single source of truth for all persistent
agent state."* That is correct for facts Campy learns — a lesson an agent earned exists
nowhere else, and losing it loses it permanently.

It is **wrong** for facts Campy merely mirrors from somewhere authoritative. If Campy
ingests a capability catalog harvested from git, or App/Iteration records owned by
another service, or run history owned by a workflow engine, then Campy holding that data
as "source of truth" creates exactly the failure mode governed platforms fear: a second,
silently-stale authority. Their standard names it directly — *"graph projections are
rebuildable from those authorities and never become a second hand-maintained catalog."*

Both kinds of fact need to live in one graph so they can be traversed together. What they
must not share is an authority contract.

This also turns a risk into a feature: once every projected fact carries
`source_version`, **drift becomes queryable** — "show me every projected fact whose
`source_version` is behind the current source version." Staleness stops being invisible
and becomes a report.

Local Campy benefits too, not just cloud. `CONTEXT.md`/ADR file-bridge content and any
future git-harvested facts are projected; conversation-derived lessons are earned. Backup
and export can then treat them differently — you must never lose earned memory, and you
should never bother backing up projected memory.

### What This Card Does

**Task 1 — Add the `authority` column.**

Same mechanism as B312: DDL in `NODE_TABLES` plus a `_MIGRATIONS` entry per table
(`campy/brain/hippocampus/schema.py`, `_MIGRATIONS` list at ~line 1117).

| Column | Type | Values |
|---|---|---|
| `authority` | `STRING` | `earned` \| `projected` |

Apply to the same Tier 1 + Tier 2 table set B312 used. Define the vocabulary as a
module-level frozenset next to B312's supersession-reason frozenset.

**Default is `earned`.** Rationale: it is the conservative default — treating a projected
fact as earned means you back up something you didn't need to; treating an earned fact as
projected means you *delete something unrecoverable* during a rebuild. Old rows migrating
in with NULL must be read as `earned`, not as unknown. Make that explicit in a helper
rather than scattering `or "earned"` across call sites:

```python
def authority_of(row) -> str:
    """NULL/missing authority reads as 'earned' — the safe default."""
```

**Task 2 — Enforce the invariant that makes `projected` meaningful.**

A `projected` fact is worthless unless it can actually be rebuilt. So on write:

- `authority == "projected"` **requires** non-NULL `source` and non-NULL `source_version`.
  Raise `ValueError` otherwise. Without those, "rebuildable" is a claim nobody can check.
- `authority == "earned"` has no such requirement.

Put this in a single validation function in `campy/brain/hippocampus/provenance.py`
(created by B312) and call it from the write helper, so there is one place to audit:

```python
def validate_authority(authority: str, source: str | None,
                       source_version: str | None) -> None:
```

**Task 3 — Two queries that make the property useful.**

Add to `campy/brain/hippocampus/provenance.py`:

```python
async def find_stale_projections(
    db: KuzuClient, *, source: str, current_version: str,
    tables: list[str] | None = None,
) -> list[dict]:
    """Projected facts from `source` whose source_version != current_version."""

async def drop_projections(
    db: KuzuClient, *, source: str, dry_run: bool = True,
) -> dict:
    """Delete all projected facts from one source so it can be re-projected.
    MUST refuse to touch any row where authority != 'projected'."""
```

`drop_projections` is the operation that makes re-projection safe and is also the single
most dangerous function in this card. It must:
- default to `dry_run=True` and return a count without deleting
- filter on `authority = 'projected' AND source = $source` — never on `source` alone
- return `{"deleted": N, "skipped_earned": M}` so a caller can see if the filter caught
  anything it would have destroyed
- be covered by a test that seeds an `earned` row with the same `source` and asserts it
  survives

**Task 4 — Surface authority in recall output.**

Wherever recall results carry `confidence` today, carry `authority` alongside it. Find
the result-shaping code (start with `campy/brain/thalamus/tools/retrieval.py` and
`campy/brain/thalamus/bundle_compiler.py`) and include it in the dict.

Consumers need to distinguish "Campy learned this" from "Campy is mirroring this from
git" — those warrant different trust and different follow-up. Do not filter or re-rank
on it in this card; just make it visible.

**Task 5 — Export/backup distinction.**

`campy/brain/hippocampus/graph/export.py` (354 lines) already exists. Add an
`include_projected: bool = False` parameter to the main export entrypoint. Default
excludes projected facts — they are reproducible from their source, so a backup that
includes them is larger and no more valuable. Document in the docstring that a full
disaster-recovery export of *earned* memory is the thing that actually matters.

### Acceptance Criteria

- [ ] `authority` column present on all Tier 1 tables, fresh DB and migrated DB
- [ ] Writing `authority='projected'` without `source_version` raises `ValueError`
- [ ] Writing `authority='projected'` without `source` raises `ValueError`
- [ ] Writing `authority='earned'` with no provenance succeeds (no regression on the
      existing capture path)
- [ ] `authority_of()` returns `earned` for a NULL/missing value
- [ ] `find_stale_projections()` returns only rows whose `source_version` differs from
      the supplied current version, and returns `[]` when everything is current
- [ ] **`drop_projections()` refuses to delete `earned` rows** — test seeds one `earned`
      and one `projected` row with the *same* `source`, asserts only the projected row is
      deleted and `skipped_earned == 1`
- [ ] `drop_projections(dry_run=True)` deletes nothing and still reports the count
- [ ] Recall results include `authority` for both earned and projected facts
- [ ] `export(include_projected=False)` omits projected rows; `True` includes them
- [ ] `pytest tests/ -q` failure set identical to pre-change baseline

### What This Card Does NOT Do

- Does not build any harvester or projection ingest path — nothing writes `projected`
  facts yet except tests. This card establishes the contract; the first real producer
  comes later.
- Does not re-rank or filter recall by authority
- Does not implement scheduled drift detection — `find_stale_projections()` is a
  function, not a background job
- Does not change what `archived` means or how sweep works

### Outcome

Campy can hold mirrored facts from external systems **without becoming a competing source
of truth for them** — the specific objection that would otherwise block adoption inside a
governed platform. Backup/DR gets an honest scope (earned memory is irreplaceable,
projected memory is regenerable), and catalog drift becomes a query instead of an
undetected decay.
