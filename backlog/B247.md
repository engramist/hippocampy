# B247 - Final Legacy Name Audit and Optional Folder Cleanup

State: ready
Priority: P1

Plan: backlog/plans/B-247-final-legacy-name-audit-and-folder-cleanup.md

### Problem

After the namespace/config/skill migrations, some `SideQuests` or `sidequests` names may remain in historical docs, patent records, legacy compatibility shims, or generated artifacts. We need a final audit that distinguishes intentional legacy references from stale public-facing names.

### What This Card Does

Creates a documented legacy-name audit, removes or renames stale folders/files where safe, and records intentional exceptions so future agents do not repeatedly churn historical/patent/compatibility files.

### Dependencies

- B243 complete - implementation package moved
- B244 complete - MCP paths moved
- B245 complete - config namespace moved
- B246 complete - skill namespace cleaned up

### Files to Create/Modify

| File | Action |
|---|---|
| `docs/legacy-name-audit.md` | CREATE - intentional vs stale legacy references |
| `InvertorsDocs/**` | REVIEW ONLY - preserve patent/provisional source filenames unless explicitly approved |
| `backlog/**` | MODIFY selectively - only active/future cards should use HippoCampy/Campy |
| `docs/**` | MODIFY selectively - public docs use HippoCampy/Campy; historical docs may keep legacy names |
| `tests/**` | MODIFY - test names may remain legacy only when testing compatibility |
| `.gitignore` | MODIFY if old generated artifacts need cleanup rules |

### Acceptance Criteria

- [ ] `docs/legacy-name-audit.md` lists every remaining `sidequests`/`SideQuests` path or reference category.
- [ ] Public install docs contain no stale `sidequests-brain` product branding.
- [ ] Active backlog cards B236+ use HippoCampy/Campy except for explicit legacy compatibility notes.
- [ ] Historical patent/provisional artifacts are not renamed unless approved.
- [ ] Import package shim and config fallback references are documented as intentional.
- [ ] Generated artifacts such as old `.mcpb`, preflight wheels, caches, and build folders are removed or ignored.

### Validation Commands

```bash
find . -path './.git' -prune -o -path './.venv' -prune -o -path './build' -prune -o -path './dist' -prune -o -iname '*sidequest*' -print | sort
rg -n "sidequests-brain|SideQuests Brain|sidequests-memory|sidequests.toml|from sidequests|python -m sidequests" . --glob '!.git/**' --glob '!.venv/**' --glob '!build/**' --glob '!dist/**'
.venv/bin/pytest -q
bash scripts/audit_public_release.sh
```

### Outcome

The repo has a clear, documented line between intentional legacy compatibility and stale pre-Campy naming.
