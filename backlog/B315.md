# B315 - AuthContext: Principal Derivation and Threading

State: done
Priority: P0

Plan: (inline — self-contained, sized for a Sonnet-level implementer)

Depends on: nothing hard. **B316 (workspace router) depends on this.**

### Why

Campy today has no concept of *who* is asking. `campy/brain_daemon.py:_dispatch` (line
217) routes every JSON-RPC call as:

```python
handler = TOOL_HANDLERS.get(method)
result = await handler(params, self.db, self.config)
```

One global `self.db` (`brain_daemon.py:65`, `KuzuClient(str(DB_PATH))`), no caller
identity, no scoping. That is correct for local single-user Campy and completely
insufficient the moment more than one principal shares a deployment.

The design rule this card exists to enforce:

> **The workspace and tenant are derived from the transport credential, never from the
> request params.**

If an agent can pass a `workspace_id` argument, an agent can read another tenant's memory
— textbook confused-deputy, and with LLM agents it is one prompt injection away from
being exercised. This must be structurally impossible, not merely discouraged.

Framing that keeps one code path: **local Campy is single-tenant cloud with auth
stubbed.** Local mode returns a real `Principal` (tenant `local`, workspace `local`, all
scopes), not `None`. Handlers never branch on "are we local?" — if local becomes a
special-cased path, the two deployments drift and the cloud path stops being exercised by
local tests.

### What This Card Does

**Task 1 — The `Principal` type.**

New module `campy/brain/auth.py`:

```python
@dataclass(frozen=True)
class Principal:
    subject_id: str        # stable user/service identity
    tenant_id: str         # isolation boundary — "local" in local mode
    workspace_id: str      # DB shard key (B316 consumes this) — "local" locally
    scopes: frozenset[str] # e.g. {"memory.read","memory.write"}
    client: str            # "claude-code", "gemini-cli", …  (observability only)
    session_id: str | None
    derived_from: str      # "local-single-user" | "oidc" | "iam" — how we know this

    def require(self, scope: str) -> None:
        """Raise PermissionError if scope not held."""
```

`derived_from` is not decoration — during an incident it is the difference between "we
trusted a token" and "we trusted a request body."

Scope vocabulary (module-level frozenset, start small):
`memory.read`, `memory.write`, `memory.admin`, `visibility.override`.

**Task 2 — Resolver interface, one implementation.**

```python
class PrincipalResolver(Protocol):
    async def resolve(self, transport_ctx: TransportContext) -> Principal: ...

class LocalSingleUserResolver:
    """Local mode. Returns a fixed Principal with all scopes."""
```

`TransportContext` carries only what the *transport* knows — peer credentials from the
unix socket, HTTP headers, TLS identity. **It must not carry the JSON-RPC `params`.**
Enforce structurally: construct `TransportContext` in the connection handler
(`_handle_connection`, `brain_daemon.py:193`) *before* the request body is parsed, and
give `_dispatch` no way to mutate it. Add a comment at the construction site saying why,
because the next person to touch it will not have this context.

Cloud resolvers (OIDC/IAM) are **out of scope** — build only the Protocol and the local
implementation. A stub `tests/` fake resolver proves the seam works for a non-local
principal.

**Task 3 — Thread the principal to handlers.**

The tool convention is uniform: `async def name(params: dict, db: KuzuClient,
config: dict) -> dict`, across ~14 modules in `campy/brain/thalamus/tools/`. Updating
every handler in one card is a large mechanical diff with real regression risk.

Use **signature inspection for incremental adoption.** In `brain_daemon.py`, compute once
at import:

```python
import inspect
_WANTS_PRINCIPAL = {
    name for name, fn in TOOL_HANDLERS.items()
    if "principal" in inspect.signature(fn).parameters
}
```

then in `_dispatch`:

```python
if method in _WANTS_PRINCIPAL:
    result = await handler(params, self.db, self.config, principal=principal)
else:
    result = await handler(params, self.db, self.config)
```

Handlers opt in by adding `*, principal: Principal` to their signature. This is a
deliberate tradeoff — it is slightly implicit, in exchange for not rewriting 40+ function
signatures in a single commit. Document the tradeoff in the code comment and note that
the end state is mandatory (see the ratchet below).

**Task 4 — Convert the two capture paths and add a ratchet.**

Convert `campy/brain/thalamus/tools/capture.py` and `lessons.py` (`upsert_lesson`) to
accept `principal` and use it for B312's `source` field —
`f"{principal.client}:{principal.subject_id}"`. This makes B312 and B315 compose: facts
become attributable to a principal rather than to a guessed client string.

Add `scripts/check_principal_ratchet.py`, same shape as B314's Cypher ratchet: count
handlers in `TOOL_HANDLERS` that do **not** declare `principal`, compare to a checked-in
baseline, fail if the count rises. Follow-up cards drive it to zero, at which point the
inspection branch is deleted and the parameter becomes required.

**Task 5 — The forbidden-key guard.**

In `_dispatch`, before invoking a handler, reject requests whose `params` contain any of
`tenant_id`, `workspace_id`, `subject_id`, `principal`, `scopes`:

```python
_FORBIDDEN_PARAM_KEYS = frozenset({
    "tenant_id", "workspace_id", "subject_id", "principal", "scopes",
})
```

Return a JSON-RPC error (code `-32602`, invalid params) naming the offending key. This is
belt-and-braces on top of Task 2's structural separation, and it is what turns "an agent
tried to escalate" from a silent success into a logged, visible failure. Log at WARNING
with the principal's `subject_id` and the rejected key.

Check whether any current tool legitimately accepts one of these names before adding the
guard — if one does, rename that parameter as part of this card and note it in the PR.

### Acceptance Criteria

- [ ] Local mode yields a real `Principal` (tenant `local`, workspace `local`, all
      scopes, `derived_from == "local-single-user"`) — **not** `None`
- [ ] `Principal.require()` raises `PermissionError` for a scope not held, returns None
      when held
- [ ] `TransportContext` has no field carrying request params — assert by constructing one
      and checking its declared fields
- [ ] A request whose `params` contain `workspace_id` is rejected with JSON-RPC `-32602`
      and the key named in the message. **Repeat this test for every key in
      `_FORBIDDEN_PARAM_KEYS`** — this is the confused-deputy guard and deserves full
      coverage, not one representative case.
- [ ] The rejection is logged at WARNING with the subject_id
- [ ] A handler declaring `principal` receives it; one that does not still works unchanged
      (both directions tested — the second is the regression guard for the other ~38
      handlers)
- [ ] A fake non-local resolver in tests produces a `Principal` with a different tenant,
      and `capture` attributes the fact to it — proves the seam works for cloud without
      building a cloud resolver
- [ ] Facts written via `capture` carry `source` derived from the principal (composes with
      B312 if landed; if B312 has not landed, assert the value passed to the write helper)
- [ ] Ratchet script exits 0 on the current tree and non-zero when a converted handler
      loses its `principal` parameter
- [ ] `pytest tests/ -q` failure set identical to pre-change baseline

### What This Card Does NOT Do

- Does not build OIDC, IAM, or Cognito resolvers — Protocol + local impl only
- Does not open more than one database — still one global `self.db` (that is **B316**)
- Does not add visibility (`private`/`team`/`org`) fields or filtering — separate card,
  and it should land only once B316 has established whether isolation is physical
  (per-workspace DB) or predicate-based
- Does not convert the other ~38 handlers — ratchet enforces direction
- Does not add authentication to the HTTP/socket transports themselves

### Outcome

Campy knows who is asking, by construction rather than by convention, and the answer
cannot be forged from the request body. Local behavior is unchanged in effect but now runs
the same code path cloud will use — so the multi-tenant path is exercised by every local
test run instead of only in production.
