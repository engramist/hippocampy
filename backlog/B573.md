# B573: test_b69_valence stubs the embedder only when nothing imported it, and otherwise calls a real model server

**Status:** Open. Found 2026-11-16 while fixing B571 on PR 450. It fails the same way on main.

**Principles:** P6 (measure correctly before believing): a test that reaches a real local model server depending on
run order is not isolated.

**What.** `tests/test_b69_valence.py::setup_module` stubs `campy.brain.hippocampus.graph.embeddings` only
`if ... not in sys.modules`. When another test file has already imported the real module (for example,
`tests/test_query_hits.py` run ahead of it), the stub is skipped. `test_retrieval_ranking_with_outcome_boost` and
`test_passive_outcome_reporting` then call the real embedding providers with the model name "mock", and fail
wherever a local model server answers (here: 404 from the local endpoint; "All embedding providers failed"). They
pass in the full suite and on CI only because of where they fall in the run order.

**Fix (to design).** Patch the embedder functions the code under test calls, with `monkeypatch`, whatever is already
imported, instead of installing a module only when it is absent. `test_explore_graph.py` has the same conditional
stub and should get the same fix.

**Graph edge.** None: test isolation only.
