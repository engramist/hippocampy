### Problem

U.S. Provisional Patent Application **#64/017,066** was filed on March 25, 2026. The strict statutory deadline to file the Non-Provisional Application and preserve priority is **March 25, 2027** (~6.5 months remaining).
To withstand patent prosecution and establish defensible priority against prior art, every claimed novel mechanism must have:
1. Direct, traceable, working code implementations in the repository.
2. Isolated regression tests proving the mechanism operates deterministically as described.
3. Empirical logs, execution traces, and performance data ready for patent counsel.

> **Execution Precedence & Dual-Engine Strategy:** This card is executed against the current, working `main` codebase **before** undertaking major storage re-platforming (B384). Freezing deterministic reduction-to-practice evidence now on the legacy engine provides counsel with an auditable baseline. To ensure long-term validity and true engine-agnostic legal defensibility, all test assertions target **observable mechanism outputs** (returned context bundles, MCP tool responses, loop-step return values, token estimates, and confidence gate outcomes) rather than graph query internals or private database calls. At Gate 2, this exact observable suite will be re-certified against Oxigraph, providing dual-engine patent reduction-to-practice proof.

### What it does (scope)

Build a dedicated **Patent Claim Verification Suite** covering the 9 core IP claims:
1. **Gated Consolidation Loop:** 9-step biomimetic pipeline (Steps 1–7 + 1b, 3b, 4b).
2. **Shape-First Principle:** Ontological grounding (gist to schema.org) before semantic reasoning.
3. **Kahneman System 1/2 Dual-Process Classifier:** Fast centroid cosine similarity (>0.85) + deliberate LLM escalation (0.60–0.85).
4. **Cocktail Party Selective Attention Gate:** Filtering conversational background noise (<0.60) from salient facts (>0.90).
5. **Context Window as Working Memory Model:** Explicit tracking of loaded/unloaded graph nodes per session.
6. **Smart Deduplication via Load Tracking:** Demoting recently loaded nodes in retrieval without complete exclusion.
7. **Session Handoff Intelligence:** Continuity transfer of decision history between distinct context windows.
8. **Bloat Detection via Token Estimation:** Context utilization monitoring and proactive bloat alerts.
9. **Valence-Weighted Graph Retrieval & Amygdala Reflex:** Outcome reinforcement from Plan nodes propagating through edges to warn agents prior to execution.

Generate a comprehensive, automated evidence report (`docs/patent-evidence-pack.md`) citing exact file lines, test results, and input/output traces.

- **Deterministic Conformance Graph Fixture (`tests/fixtures/patent_conformance_graph.jsonl`):**
  All 9 claim verification tests execute against a locked, canonical graph fixture containing predetermined multi-hop topologies, cyclic references, valence-weighted outcomes, and contradictory constraints (`migration-security-testing.md`). Uses the engine-agnostic JSONL node/rel serialization supported by Campy's graph export/import tools. Assertions evaluate observable mechanism outputs across public APIs and consolidation steps, keeping the suite decoupled from internal query syntax.
