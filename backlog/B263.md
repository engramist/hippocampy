# B263 - OpenClaw Adapter Activation

State: complete -- verified via git log 2026-08-02 (feat(B263) ab43886); card file was stale
Priority: P2

Plan: backlog/plans/B-263-openclaw-adapter.md

### Problem

The OpenClaw plugin config exists at `extensions/hippocampy/openclaw.plugin.json` with `autoCapture: true` and `autoRecall: true`, but the adapter integration is incomplete. OpenClaw detection exists in `detect.py` but there's no `register_openclaw()` in `register.py`. The plugin config references a `brainUrl` but the actual MCP client connection isn't wired.

### What This Card Does

Completes the OpenClaw integration by:
1. Adding `register_openclaw()` to `register.py`
2. Implementing the `autoCapture` and `autoRecall` behavior based on plugin config
3. Wiring the OpenClaw plugin to connect to the Campy daemon

### Dependencies

- B255 complete (plugin installation path)
- B262 recommended (REST API simplifies OpenClaw integration)

### Design Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Connection method | REST API (`/api/v1/`) or MCP SSE | REST is simpler for OpenClaw's plugin system |
| autoCapture | POST each turn to `/api/v1/notify` | Same as notify_turn MCP tool |
| autoRecall | GET `/api/v1/recall` at session start | Returns recall context for prompt injection |
| Registration | Copy plugin config to OpenClaw's extensions dir | Standard OpenClaw plugin installation |

### Changes

**New `campy/cli/register_openclaw.py`:**
- `register_openclaw()` function
- Copies `extensions/hippocampy/openclaw.plugin.json` to OpenClaw's extensions directory
- Verifies daemon connectivity

**Modified `campy/cli/register.py`:**
- Import and expose `register_openclaw`

**Modified `campy/cli/main.py`:**
- Add `openclaw` target to `setup` command

**Modified `campy/cli/detect.py`:**
- `detect_openclaw()` also checks for OpenClaw's config directory

### Acceptance Criteria

- [ ] `register_openclaw()` copies plugin config to OpenClaw extensions directory
- [ ] `campy install --plugin` detects and registers OpenClaw when present
- [ ] `campy doctor` reports OpenClaw plugin status
- [ ] Plugin config `autoCapture: true` results in turn capture via REST/MCP
- [ ] Plugin config `autoRecall: true` results in session-start recall
