# B257 - Upgrade Plugin Skills with Memory OS Tools

State: complete -- verified via git log 2026-08-02 (feat(B257) 68143e6); card file was stale
Priority: P0

Plan: backlog/plans/B-257-upgrade-plugin-skills.md

### Problem

The 4 plugin skills at `plugin/skills/` predate the Memory OS work (B249-B254). The recall skill only knows about `current_truth`. It doesn't mention `compile_context`, `memory_decision`, `ingest_data`, `recall_procedures`, `recall_relevant_lessons`, or other retrieval tools added since the plugin was written.

### What This Card Does

Updates all 4 existing plugin skills and adds a new `session-start` skill with the explicit session-start recall protocol.

### Dependencies

- B256 complete (tools must be reachable before we teach agents to use them)

### Design Decisions

| Decision | Choice | Rationale |
|---|---|---|
| New skill added | `plugin/skills/session-start/SKILL.md` | Session-start recall protocol is the critical missing piece |
| Skill tone | Assertive mandatory triggers, not passive suggestions | Agents interpret "you can..." as "you don't have to..." |
| Tool coverage | All retrieval tools documented in recall skill | Agents need a complete menu |

### Changes Per Skill

**`plugin/skills/recall/SKILL.md`:**
- Add `compile_context` for multi-entity queries
- Add `memory_decision` as the "not sure?" entry point
- Add `recall_procedures`, `recall_relevant_lessons`, `reconstruct_timeline`
- Add explicit trigger phrases: "Before answering architecture questions → current_truth"

**`plugin/skills/memory-awareness/SKILL.md`:**
- Add tabular data ingestion mentions (`ingest_data`)
- Update insight surfacing for bundle compilation

**`plugin/skills/status/SKILL.md`:**
- Add `compile_context` token budget guidance
- Add bundle truncation awareness

**`plugin/skills/quest-management/SKILL.md`:**
- Minor: reference `diff_since` when switching quests

**`plugin/skills/session-start/SKILL.md` (NEW):**
- Step 1: Call `memory_decision` with user's first message
- Step 2: If recommended, call the suggested recall tool
- Step 3: If continuing an existing quest, call `diff_since`
- Step 4: Surface what the Brain knows before working blind

### Acceptance Criteria

- [ ] All 5 plugin skills are present and reference current tools
- [ ] `session-start/SKILL.md` contains explicit step-by-step protocol
- [ ] No references to old tool names or missing tools
- [ ] Trigger language is assertive ("ALWAYS call..." not "you can call...")
