# B244 - Switch MCP and Installer Module Paths to `campy.*`

State: ready
Priority: P0

Plan: backlog/plans/B-244-switch-mcp-and-installer-module-paths-to-campy.md

### Problem

Even after the implementation package moves, installed MCP registrations may still point at `sidequests.*` module paths. New installs should register `campy.*` module paths, while repair/uninstall must clean stale `sidequests.*` entries without duplicating servers.

### What This Card Does

Updates setup, install, doctor, adapter registration, and tests so new MCP configs use `campy.*` module paths. Legacy `sidequests.*` registrations remain readable and repairable.

### Dependencies

- B243 complete - `campy` implementation namespace exists with `sidequests` shims

### Files to Create/Modify

| File | Action |
|---|---|
| `campy/cli/register.py` | MODIFY - write `python -m campy.adapters.mcp_server` where applicable |
| `campy/cli/setup.py` | MODIFY - new MCP registrations use `campy.*` paths |
| `campy/cli/install.py` | MODIFY - installer writes `campy.*` paths |
| `campy/cli/doctor.py` | MODIFY - diagnose and repair legacy `sidequests.*` module paths |
| `campy/cli/uninstall.py` | MODIFY - remove both `campy` and legacy `sidequests` entries |
| `tests/test_installer_idempotency.py` | MODIFY - assert new paths and stale cleanup |
| `tests/test_setup_cli.py` | MODIFY - assert `campy.*` module paths |
| `tests/test_doctor_cli.py` | MODIFY - assert repair behavior |

### Acceptance Criteria

- [ ] New Codex config uses `[mcp_servers.campy]` and a `campy` module path where module mode is used.
- [ ] New VS Code MCP config uses `python -m campy.adapters.mcp_server`.
- [ ] New Claude/Gemini registrations use the `campy` MCP server name and `campy` module paths where applicable.
- [ ] Existing `sidequests.*` module registrations are detected as legacy.
- [ ] Repair removes duplicate/stale legacy entries only after writing the new `campy` entry.
- [ ] No MCP config contains duplicate `campy` and `sidequests` server blocks after repair.

### Validation Commands

```bash
.venv/bin/pytest -q tests/test_installer_idempotency.py tests/test_setup_cli.py tests/test_doctor_cli.py tests/test_uninstall.py tests/test_mcp_server_adapter.py
.venv/bin/pytest -q tests/test_adapters.py tests/test_adapter_claude_desktop.py tests/test_adapter_chatgpt_desktop.py
```

### Outcome

New installs and repaired installs point at the `campy` namespace, while legacy `sidequests` module paths remain safely recoverable.
