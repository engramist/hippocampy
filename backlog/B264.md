# B264 - Hermes Agent Adapter

State: backlog
Priority: P2

Plan: backlog/plans/B-264-hermes-adapter.md

### Problem

Hermes Agent is an external agent framework that supports "Session Recall" — loading context at the start of each agent session. Hermes can spawn background agents. Campy should be the ambient memory layer for Hermes-spawned agents, providing compiled context bundles so each spawned agent starts with full project context instead of working blind.

### What This Card Does

Creates a Hermes Agent adapter that:
1. Provides session recall via Campy's `compile_context` tool
2. Captures turns from Hermes agent sessions
3. Supports Hermes's background agent spawning with per-agent context bundles

### Dependencies

- B252 (bundle compiler must work)
- B262 recommended (REST API is the simplest integration path)

### Design Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Integration method | REST API client + MCP SSE fallback | REST is simplest; MCP SSE for full tool access |
| Session recall | Call `compile_context` with agent's task description | Bundle compiler handles heterogeneous assembly |
| Spawned agent context | Thin context bundle scoped to the spawned task | Spawned agents get focused context, not full project dump |
| Adapter location | `adapters/hermes/adapter.py` | Follows existing adapter pattern |
