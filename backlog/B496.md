# B496: Relation extraction writes a replacement for negated and person "swap" sentences

**Status:** complete (2026-10-20) (2026-10-20) · **Found:** 2026-10-20

Supersedes the remaining cases of the unmerged PR #281 (a parallel B466 implementation). Run against main, #281's test file failed 4 of 14 cases:

- "We substituted REST with gRPC." gave nothing ("substitute" only knew the "for" frame).
- "Do not replace Memcached with Redis." and "We did not replace Memcached with Redis." wrote `Redis REPLACES Memcached`. A denied replacement states none; writing the edge makes the memory report a still-current value as retired. This is the serious one (a false supersession).
- "We swapped seats with the other team." wrote a replacement; it trades places, it does not replace a technology.

## Fix (`campy/brain/temporal_lobe/loop/step1b_relations.py`)
- Negation scope: a replace-type or move verb under `neg` ("not", "n't", "never"), under a negated governing clause ("decided not to replace"), or under "instead of / rather than / without" writes no REPLACES edge.
- "substitute X with Y" reads as Y replacing X (alongside the existing "substitute Y for X").
- swap/exchange need two names (not common nouns like "seats", "the other team"), and not both people; the "with Y hangs off the object" fallback is limited to "replace"/"substitute" so it no longer turns "swapped seats with ..." into a replacement.
