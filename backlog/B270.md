# B270 - Rewrite campy setup to Delegate to Native Plugin Installers

State: complete -- verified via git log 2026-08-02 (feat: implement B265-B276 215b588); card file was stale
Priority: P1

Plan: backlog/plans/B-270-native-plugin-install.md

### Problem

`campy setup` currently does manual file surgery — scatter-copying skills to `~/.codex/skills/`, writing hooks.json, editing config.toml, etc. This is fragile and broke repeatedly during the codebase refactor. All three platforms now have native plugin install commands that handle this properly.

### What This Card Does

Rewrites the platform registration functions in `campy setup` to delegate to native plugin install commands when available, falling back to manual installation for older CLI versions.

### Dependencies

- B265 (unified plugin directory must exist with all three manifests)
- B266 (skills must be renamed)
- B267 (hooks must be consolidated)

1. **`campy/cli/register.py`** — Update these functions:

   **`register_claude_code()`** (~line 116):
   Replace `claude mcp add` approach with:
   ```python
   def register_claude_code(adapter_path: str) -> bool:
       """Register Campy with Claude Code using native plugin install."""
       try:
           plugin_dir = _find_plugin_dir()
           if plugin_dir is None:
               logging.error("Plugin directory not found")
               return False
           
           # Try native plugin install first
           cmd = ["claude", "plugin", "install", str(plugin_dir)]
           result = subprocess.run(cmd, capture_output=True, text=True)
           
           if result.returncode == 0:
               logging.info("Claude Code plugin installed natively")
               return True
           
           # If "already installed" — try update
           if "already" in (result.stderr or "").lower():
               cmd = ["claude", "plugin", "update", "hippocampy"]
               subprocess.run(cmd, capture_output=True, text=True)
               logging.info("Claude Code plugin updated")
               return True
           
           # Fallback to legacy registration
           logging.warning(f"Native plugin install failed ({result.stderr}), falling back to legacy")
           return _register_claude_code_legacy(adapter_path)
       except FileNotFoundError:
           logging.error("Claude Code CLI ('claude') not found in PATH")
           return False
   ```

   **Add `_find_plugin_dir()` helper** (new function):
   ```python
   def _find_plugin_dir() -> Path | None:
       """Locate the plugin/ directory in the repo or installed package."""
       # Check repo root
       repo_root = Path(__file__).parent.parent.parent
       candidate = repo_root / "plugin"
       if (candidate / ".claude-plugin" / "plugin.json").exists():
           return candidate
       # Check installed package data
       try:
           from importlib import resources
           pkg = resources.files("campy.data").joinpath("plugin")
           pkg_path = Path(str(pkg))
           if (pkg_path / ".claude-plugin" / "plugin.json").exists():
               return pkg_path
       except Exception:
           pass
       return None
   ```
