# B269 - Update ChatGPT Desktop Registration to Streamable HTTP

State: complete — re-verified 2026-08-03: `rg "7799/sse"` returns zero matches in campy/cli/ or adapters/; `register_chatgpt_desktop()` in campy/cli/register.py:250 prints `http://127.0.0.1:7799/mcp` (source-read, line 259)

### Problem

ChatGPT Desktop registration in `campy setup` still tells users to paste `http://127.0.0.1:7799/sse`. ChatGPT Desktop now supports MCP natively via the OpenAI Apps SDK, and supports Streamable HTTP. We should point at `/mcp` and update the registration instructions.

### What This Card Does

Updates all ChatGPT Desktop registration instructions and adapter code to use the Streamable HTTP endpoint (`/mcp`) instead of the deprecated SSE endpoint (`/sse`).

### Dependencies

- B268 (Streamable HTTP transport must be working)

### Files to Modify

1. **`campy/cli/main.py`** — Find the ChatGPT Desktop instructions block (search for `127.0.0.1:7799/sse` or "ChatGPT Desktop"):
   Change URL from `http://127.0.0.1:7799/sse` to `http://127.0.0.1:7799/mcp`

2. **`campy/cli/install.py`** — Find `_register_chatgpt_desktop` method:
   Update any `/sse` references to `/mcp`

3. **`campy/cli/register.py`** — Search for "chatgpt" or "ChatGPT" and update URLs

4. **`adapters/chatgpt_desktop/`** — If this directory exists, check for `/sse` references and update

```bash
rg -i "chatgpt.*sse\|sse.*chatgpt\|7799/sse" --type py --type md -l
```
