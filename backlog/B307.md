### Problem (found by a live post-B305/B306 eval matrix run, 2026-08-02)

B305 added a 0.70 cosine-similarity floor to `_stage_plans` (and other bundle stages) to
stop off-topic filler reaching `ask`. It worked — negative-control hallucination is fully
fixed (48/48 pass across the eval matrix, see PR #19 for the scorer fix that revealed
this). But the same floor also zeroed out the **paraphrase**, **cross_lane**, and
**continuation** question families across every model — families that scored partial
credit (0.00–0.50) in the pre-B305 run now score 0.00 uniformly.

Root cause, verified directly:

```python
>>> cosine_similarity(
...     "Who or what split the big tools module into smaller files?",   # the question
...     "Implement B292 by splitting campy/brain/thalamus/tools/__init__.py "
...     "into focused domain modules while preserving behavior, exports, "
...     "and TOOL_HANDLERS parity.",                                     # the correct answer's Plan.goal
... )
0.3227
```

A genuinely correct match, at less than half the 0.70 floor. This is the same
question-vs-goal embedding mismatch B303 first diagnosed (imperative goal text vs.
question-phrased queries land far apart under `sentence-transformers/all-MiniLM-L6-v2`).
Before B305, "no floor at all" meant this weak-but-correct match still surfaced — the
same mechanism that let genuinely irrelevant content leak in for negative controls. B305
closed the loophole uniformly and correctly for true non-matches, but a single global
cosine floor cannot distinguish "weak because irrelevant" from "weak because paraphrased,"
so it now excludes both. B303's existing lexical bypass only fires on exact card
identifiers (`\bB\d+\b`) or quoted phrases — "who split the big tools module" contains
neither, so it gets no help.

### What This Card Does

Extend the existing lexical-bypass mechanism (do not invent a new one) to catch
topically-overlapping paraphrases, not just exact identifiers.

1. In `campy/brain/thalamus/tools/quests.py`, add a second term-extraction path
   alongside `_extract_lexical_terms`: a lightweight significant-word extractor over the
   query — lowercase, strip a small stopword list (reuse or write a short one: articles,
   auxiliary verbs, question words — "who", "what", "the", "did", "does", "into", etc.),
   keep tokens of length ≥ 4. This does not need to be fancy (no BM25, no stemming) — the
   goal is catching shared distinctive nouns/verbs ("split", "tools", "module"), not a
   full IR ranking function.
2. In `_lexical_plan_rows` (or a parallel function), treat a plan as a lexical bypass
   candidate if it shares **at least 2** significant terms with the query (not 1 — a
   single shared common word like "module" alone is too weak a signal and would
   re-introduce noise; require the co-occurrence). Card-identifier and quoted-phrase
   matches from `_extract_lexical_terms` remain single-term-sufficient (unchanged,
   they're exact matches already).
3. Plans that bypass via this new path are tagged distinctly from identifier-lexical
   hits (e.g. `bypass_reason="keyword_overlap"` vs `"identifier"`) in whatever internal
   structure `_rank_plan_neighbors` already threads through — check its current
   `lexical_ids` handling and extend the shape rather than replacing it, so identifier
   hits keep their existing priority ordering ahead of keyword-overlap hits.
4. The 0.70 vector floor is UNCHANGED for pure similarity-ranked results — this card
   only widens the bypass, it does not lower the floor. Do not touch `bundle_compiler.py`
   unless `_stage_plans`'s call signature needs a new parameter to pass through
   (check first; the fix may be fully containable in `quests.py`).

### What This Card Does NOT Do

- Does not lower the 0.70 vector-similarity floor
- Does not add embedding-model changes, query rewriting, or a reranker — keyword overlap
  only, matching the existing lexical-bypass pattern's complexity level
- Does not touch `cross_lane`/`continuation` question scoring directly — if those
  families improve as a side effect of the same fixture plans becoming reachable, great;
  if they need their own diagnosis after this lands, that's a further card, not this one
