# B226 - ARC Mechanic Memory Schema and Publish Tool

State: complete (2026-05-03)
Priority: P0

Plan: backlog/plans/B-226-arc-mechanic-memory-schema-and-publish-tool.md

### Problem

The sibling `ARC_AGI` repo now publishes compact world-model mechanic summaries through `publish_mechanic_summary(summary=...)`, but sidequests-brain does not expose that tool. ARC currently degrades cleanly with `capability_missing`, which prevents crashes, but no aggregate mechanic memory is actually stored.

This blocks the ARC-AGI-3 architecture where local observations compile into reusable cross-game mechanics.

### What This Card Does

Adds graph-native ARC mechanic memory storage and a `publish_mechanic_summary` tool. The tool persists mechanic summaries as labeled-property-graph records in KuzuDB with stable IDs, provenance, confidence, action/effect signatures, failure modes, and recovery-policy hooks.

Graph model choice: labeled property graph. ARC mechanic memory is traversal-first and edge-metadata-heavy; RDF/ontology is not required for this operational layer.

### Acceptance Criteria

- [ ] `publish_mechanic_summary` appears in `tools/list`.
- [ ] Tool accepts ARC payloads shaped like `{"summary": {...}, "async_dispatch": true}`.
- [ ] Tool writes durable KuzuDB state; no Python-only shadow store.
- [ ] Mechanic records use stable IDs from summary id/signature/task provenance.
- [ ] Upsert is idempotent: publishing the same summary twice does not duplicate nodes or edges.
- [ ] Stored facts include action-set signature, effect patterns, terminal relevance, coordinate relevance, preconditions, failure modes, recovery policies, confidence, source task IDs, and evidence counts when present.
- [ ] Provenance records source task/run/session and created/updated timestamps.
- [ ] Large raw payloads are summarized or bounded; no unbounded JSON blob becomes the primary memory.
- [ ] Existing tools and schema initialization remain backward compatible.
- [ ] Docs/tool-catalog and architecture docs mention the tool.

ARC can publish learned world-model mechanics into SideQuests graph memory instead of losing them behind `capability_missing`.
