### B83 · Add Truncation Warning to explore_graph

**Problem:** `explore_graph` has `MAX_NODES=1000` that silently truncates results. The LLM receives partial results with no indication that exploration was incomplete.

**What it does:** Adds an `"exploration_truncated": true` flag to the response when MAX_NODES is hit.

**Depends on:** None

**Files to modify:**
- `mcp_engine/tools/explore_graph.py` — add truncation flag to response

**Adapter allow-list propagation check:** No tool changes — N/A.

**Acceptance Criteria:**
- Response includes `"exploration_truncated": true` when MAX_NODES is reached
- Response includes `"exploration_truncated": false` when exploration completed fully
- `pytest tests/ -k explore_graph -q` passes

**Outcome:** LLMs know when graph exploration was incomplete and can request more targeted traversals.
