# B233 - Non-Provisional Strategy and Public Disclosure Guardrails

State: complete
Priority: P0

Plan: backlog/plans/B-233-non-provisional-strategy-and-public-disclosure-guardrails.md

### Problem

The provisional patent is filed, but public release still needs guardrails. The non-provisional deadline is March 25, 2027, and public product/docs/code should not accidentally undermine claim strategy, disclose trade-secret tuning details unnecessarily, or create confusion about what is patent-pending versus open-source implementation detail.

The repo currently mixes implementation, backlog history, inventor notes, patent prep material, and release docs. Before public distribution, SideQuests needs a clear non-provisional strategy checklist and public disclosure boundary.

### What This Card Does

Creates a non-provisional strategy and public-disclosure guardrail package for release planning.

This is not legal advice and does not replace patent counsel. It turns the filed PPA facts and repo state into actionable engineering/release guidance: what can ship, what should remain private, what should be reviewed by counsel, and what deadlines/claims must stay visible.

### Acceptance Criteria

- [ ] Strategy doc records PPA application number, confirmation number, priority date, and non-provisional deadline from the canonical notebook.
- [ ] Strategy doc lists patent-pending claims currently documented in architecture and inventor notes.
- [ ] Strategy doc identifies implementation areas that may require counsel review before public release.
- [ ] Public disclosure boundary classifies architecture docs, inventor docs, backlog archives, ARC-related artifacts, tuning parameters, benchmark results, and installer code.
- [ ] README uses accurate patent-pending language without overstating granted rights.
- [ ] Docs clearly state that the non-provisional deadline is March 25, 2027.
- [ ] Docs include a release checklist: packaging, installer, private-data audit, license, PyPI, Smithery, Homebrew, and public repo visibility.
- [ ] Any recommendation to keep routing tables, thresholds, seed examples, or tuning details private is explicitly marked as a strategy choice, not a technical requirement.
- [ ] No public doc claims that a utility patent is granted.
- [ ] The card produces a concise counsel-review packet list for future non-provisional work.
