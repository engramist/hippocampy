# B515: pin preshed below 3.0.14

**Status:** Done

preshed 3.0.14 (released 2026-10-24) breaks spacy 3.8.3: `spacy.load('en_core_web_md')`
fails in `tokenizer.from_disk` with `OverflowError: Python int too large to convert to C ssize_t`.
CI on every new PR failed (pytest patent-claim tests, Docker "Models load offline") while main's
last run, on preshed 3.0.13, passed. Reproduced in a clean venv: 3.0.14 fails, 3.0.13 loads.

Fix: `preshed<3.0.14` in requirements.txt and pyproject.toml. Lift the pin once a fixed preshed
(or a spacy that works with it) ships.
