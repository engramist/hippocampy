# B424 - Enforce `principal.scopes` in `route_tool_call` (Authorization Was Decorative)

State: fixed (this PR)
Priority: P0
Branch: fix/b424-scope-enforcement

### Problem

External re-vet (2026-09-11, condition 5) HIGH finding: `auth.py` defines
`memory.read` / `memory.write` / `memory.admin` scopes on `Principal`, but the shared
dispatch chokepoint `route_tool_call` (`campy/brain_daemon.py`) **never consulted them**.
`grep -rnE "\.scopes|has_scope|require_scope" campy web` returned nothing outside
`auth.py`. Authorization was therefore binary-per-workspace: any authenticated caller —
including a principal intended to be read-only — could invoke every write tool
(`notify_turn`, `upsert_lesson`, `record_rule`, `ingest_*`, …). This is the #1 pilot
precondition in the re-vet.

### Fix

Tool→scope policy in `auth.py` and enforcement at the one chokepoint both transports
share:

- `READ_ONLY_METHODS` (33 retrieval/query tools) + `required_scope_for(method)`:
  read-only tools require `memory.read`; **everything else requires `memory.write`**.
  The write default is deliberate and **fail-safe** — a new or unclassified tool can only
  ever over-restrict a read, never silently expose a write. Ambiguous tools that mutate as
  a side effect (`ask` captures its result; `arc_classify_game_archetype`) are left off the
  allowlist so they land on the write default.
- `route_tool_call` calls `principal.require(required_scope_for(method))` after the
  method-known check and **before any handler runs or the DB is touched**. `.require()`
  raises `PermissionError`, which each transport already maps to its error envelope.
- Local single-user (`_ALL_SCOPES`) and default-runtime (`{read, write}`) principals hold
  the needed scopes, so single-user behaviour is unchanged; only a restricted remote
  principal is newly gated.

Proven by `tests/test_b424_scope_enforcement.py`: classification (incl. fail-safe unknown
→ write), every registered tool classified + no stale allowlist entries, a read-only
principal is denied a write tool **before dispatch**, and a read+write principal clears
the gate. Regression: auth/dispatch/transport/workspace suites green (350 passed); the
`_FakePrincipal` db-resolution double updated to model the `require` contract.

### Follow-on

Classification is curated + fail-safe; if a future tool needs `memory.admin`, add an
admin tier then (no destructive tool exists in the current 61). Relates to re-vet
conditions 2 (auth surface, already met) and 5 (this).
