# B272 - Create curl Install Script (Primary Install Path)

State: ready
Priority: P1

Plan: backlog/plans/B-272-curl-install-script.md

### Problem

Installing Campy requires Python/pip knowledge (`pipx install hippocampy && campy setup`). Campy targets non-technical users who may not have Python packaging experience. We need a one-command install that handles everything.

### What This Card Does

Creates an install script at `scripts/install.sh` that a user runs with:
```bash
curl -fsSL https://campy.ai/install | sh
```

The script handles:
1. Detecting the OS (macOS, Linux)
2. Checking for Python 3.12+ (installs via brew on macOS if missing)
3. Installing pipx if not present
4. Installing hippocampy via pipx
5. Running `campy setup` to register with all detected AI agents
6. Printing a success summary

### Dependencies

- B265 (unified plugin directory)
- B270 (campy setup delegates to native install)

### Files to Create

1. **`scripts/install.sh`** (~150 lines):

```bash
#!/usr/bin/env bash
set -euo pipefail

# Colors
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
BLUE='\033[0;34m'
NC='\033[0m' # No Color

echo -e "${BLUE}╔═══════════════════════════════════╗${NC}"
echo -e "${BLUE}║   Installing HippoCampy Memory    ║${NC}"
echo -e "${BLUE}╚═══════════════════════════════════╝${NC}"
echo ""

# Detect OS
OS="$(uname -s)"
ARCH="$(uname -m)"

if [ "$OS" != "Darwin" ] && [ "$OS" != "Linux" ]; then
    echo -e "${RED}Unsupported OS: $OS. Campy supports macOS and Linux.${NC}"
    exit 1
fi

# Step 1: Check Python 3.12+
echo -e "${YELLOW}[1/4]${NC} Checking Python..."
PYTHON=""
for cmd in python3.12 python3.13 python3; do
    if command -v "$cmd" &>/dev/null; then
        version=$("$cmd" --version 2>&1 | grep -oP '\d+\.\d+')
        major=$(echo "$version" | cut -d. -f1)
        minor=$(echo "$version" | cut -d. -f2)
        if [ "$major" -ge 3 ] && [ "$minor" -ge 12 ]; then
            PYTHON="$cmd"
            break
        fi
    fi
done

if [ -z "$PYTHON" ]; then
    if [ "$OS" = "Darwin" ]; then
        echo -e "${YELLOW}Python 3.12+ not found. Installing via Homebrew...${NC}"
        if ! command -v brew &>/dev/null; then
            echo -e "${RED}Homebrew not installed. Install it first: https://brew.sh${NC}"
            exit 1
        fi
        brew install python@3.12
        PYTHON="python3.12"
    else
        echo -e "${RED}Python 3.12+ not found. Install it with your package manager:${NC}"
        echo "  Ubuntu/Debian: sudo apt install python3.12"
        echo "  Fedora: sudo dnf install python3.12"
        exit 1
    fi
fi
echo -e "${GREEN}  ✓ Found $($PYTHON --version)${NC}"

# Step 2: Check/install pipx
echo -e "${YELLOW}[2/4]${NC} Checking pipx..."
if ! command -v pipx &>/dev/null; then
    echo "  Installing pipx..."
    "$PYTHON" -m pip install --user pipx 2>/dev/null || "$PYTHON" -m ensurepip --user && "$PYTHON" -m pip install --user pipx
    "$PYTHON" -m pipx ensurepath 2>/dev/null || true
    # Re-source PATH
    export PATH="$HOME/.local/bin:$PATH"
fi
echo -e "${GREEN}  ✓ pipx available${NC}"

# Step 3: Install hippocampy
echo -e "${YELLOW}[3/4]${NC} Installing HippoCampy..."
if command -v campy &>/dev/null; then
    echo "  Upgrading existing installation..."
    pipx upgrade hippocampy 2>/dev/null || pipx install hippocampy --force
else
    pipx install hippocampy
fi
echo -e "${GREEN}  ✓ HippoCampy installed${NC}"

# Step 4: Run setup
echo -e "${YELLOW}[4/4]${NC} Setting up AI agent integrations..."
campy setup

echo ""
echo -e "${GREEN}╔═══════════════════════════════════╗${NC}"
echo -e "${GREEN}║   HippoCampy installed! 🧠        ║${NC}"
echo -e "${GREEN}╚═══════════════════════════════════╝${NC}"
echo ""
echo "Commands:"
echo "  campy status     — check daemon health"
echo "  campy start      — start the brain daemon"
echo "  campy setup      — re-register with AI agents"
echo ""
```

### Outcome

Users can install Campy with a single command: `curl -fsSL https://campy.ai/install | sh`. No Python/pip knowledge needed.

### Notes

- The URL `https://campy.ai/install` requires a web host. For now, users can use `curl -fsSL https://raw.githubusercontent.com/djs54/hippocampy/main/scripts/install.sh | sh`
- The script should NOT require sudo (pipx installs to user space)
- The script must be idempotent — running it twice should upgrade, not fail
