# B430 - 15 Pre-Cutover Edge Types Were Never Classified in `EDGE_REIFICATION` (Found via Real B417 Migration Validation)

State: ready
Priority: P3
Branch: (none yet)

### Problem

While validating the B417 Kùzu→Oxigraph migrator against a copy of a real, pre-cutover
415 MB `brain.db` backup, 15 real historical edge types with real row data in the legacy
graph were skipped because they have **no `EDGE_REIFICATION` entry at all** in today's
`oxigraph_client.py` — they were never carried forward during the B389/B397 SPARQL
cutover:

`ADJACENT_TO`, `BLOCKS`, `CAUSES_CHANGE_IN`, `CONFIRMS`, `CONTAINS_ENTITY`,
`CORRELATES_WITH`, `CO_MOVES_WITH`, `DERIVED_FROM_FACT`, `EXECUTED_AS`, `INFERRED_FROM`,
`OBSERVED_IN`, `REQUIRES_ENTITY`, `RESPONDS_TO`, `STRUCTURALLY_SIMILAR`,
`SUPPORTS_HYPOTHESIS`.

All 15 have valid, known endpoint node tables today (verified: e.g. `ADJACENT_TO`
GridEntity→GridEntity, `CONFIRMS` Concept→Hypothesis, `SUPPORTS_HYPOTHESIS`
ActionFact→Hypothesis, `OBSERVED_IN` GridEntity→GridSnapshot) — it is specifically the
edge *type itself* that has no plain/star/occurrence classification, so
`classify_edge()` raises for every one of them and the B417 migrator correctly skips and
reports them (per `docs/rdf-schema-mapping.md` §4.2d: an unclassified edge must never be
guessed) rather than crashing or silently mis-writing them.

This is **not a B417 migrator bug** — verified by the same validation run that every one
of the 57 legacy *node* tables migrated with zero skips, zero row failures, zero dropped
columns (27,023 nodes, 44,427 edges across 22 correctly-classified rel types). It is a
pre-existing data-completeness gap in the Oxigraph schema itself, surfaced by having real
legacy data to migrate against for the first time.

### Scope

For each of the 15: read its write call site(s) (if any remain in `campy/` — some may
already be fully dead code from an earlier feature) to determine the correct
plain/star/occurrence classification per `docs/rdf-schema-mapping.md` §4.2c's governing
rule ("classify from the write call site, not the name"), or confirm it is genuinely dead
and deliberately leave it unclassified. Add classified ones to `EDGE_REIFICATION` +
`REL_COLUMNS`, then re-run `campy migrate-legacy` against the real backup to confirm the
edge-migration count grows correspondingly.

### Provenance

Found by hippocampy-75 on 2026-09-14 while doing the real-data validation pass for
B417 item 3 (the Kùzu→Oxigraph migrator) — a copy of the developer's real
`~/.campy/brain.db.kuzu-bak-202609091` was migrated into a scratch Oxigraph store to prove
the migrator works on production data, not just synthetic fixtures. Relates to B417
(migrator), B413/B420-B422 (the `EDGE_REIFICATION` classification-drift bug family).
