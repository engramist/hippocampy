# B469 - Retire the Kùzu Leftovers: Tests and Cypher That Production Never Runs

State: ready (filed 2026-10-05)
Priority: P2

### Problem Statement

B397 (2026-09-07) replaced Kùzu with Oxigraph + sqlite-vec, and the daemon
runs only on Oxigraph. The cutover left three kinds of Kùzu residue that
production never executes but that the test suite and the query registry
still depend on. They cost effort and give false confidence:

1. **323 of the suite's 2,386 test functions (28 files) run against a Kùzu
   test double**, `tests/kuzu_test_client.py` (the deleted production client,
   moved into `tests/`). The gateway executes a query's `cypher` for any
   client that is not Oxigraph, so these tests check the Cypher text of each
   query, not the SPARQL that production runs. Two examples:
   - `tests/test_bundle_compiler_stages.py::TestStageGraphStructure` tests the
     bundle's graph traversal on Kùzu. The production SPARQL of the same
     queries returned archived Concepts until B467, and no test noticed.
   - B467's first fix also added an archived filter to the Cypher. It broke
     those three Kùzu tests, whose schema has no `archived` column on
     Concept, while changing nothing a user runs.
2. **Every `NamedQuery` must carry a Cypher string** (`gateway.py`
   `NamedQuery.__post_init__` rejects an empty one, and `_find_unsafe_brace`
   lints it). There are about 850 of them beside their SPARQL. Every new
   query needs a Cypher translation nobody runs. `scripts/check_cypher_ratchet.py`
   (B314) still runs in CI to stop inline Cypher spreading, a goal the
   cutover made moot.
3. **Production code refers to the test double.** `campy/cli/backup.py`
   (two places, around lines 330 and 418) looks up
   `sys.modules["tests.kuzu_test_client"]` to read a legacy single-file
   `brain.db`, which only works when the tests have already imported it.
   Runtime type hints and docstrings still name `KuzuClient`
   (`warm_frontier.py`, `step4b_associative.py`, `sweep.py`,
   `sweep_patterns.py`).

`kuzu==0.11.3` stays a declared dependency. That is legitimate for one
purpose: B417's migrator, which reads a pre-cutover `brain.db`.

### What It Does (Scope)

1. **Inventory the 28 files** (largest first: `test_arc_queries` 40 tests,
   `test_authority` 31, `test_bundle_compiler_stages` 28,
   `test_app_continuity` 25, `test_capability_queries` 22,
   `test_workspace_router` 19, ...). Classify each test:
   - **port**: checks behaviour a user can hit. Re-point it at a real
     `OxigraphClient` store, as the B465/B467 tests already do.
   - **delete**: only checks Cypher text or Kùzu specifics, or duplicates an
     Oxigraph test.
   - **keep on Kùzu**: legitimately needs Kùzu. Only
     `test_b417_kuzu_migrate.py` (the migrator reads Kùzu) is expected here.
   A port must keep the test's intent; the inventory records each decision.
2. **Make `cypher` optional on `NamedQuery`** once no test executes it.
   Require `sparql` instead. Then delete the Cypher strings, either in
   batches per query module or in one mechanical pass. Retire or repurpose
   `check_cypher_ratchet.py` and `cypher_baseline.json`, and remove the
   gateway's non-Oxigraph dispatch path (`execute_read` / `execute_write`
   with `query.cypher`). Mock-based unit tests that go through that path move
   to an Oxigraph store or to a mocked `_dispatch_oxigraph`.
3. **Backup.** Replace the `tests.kuzu_test_client` lookup in
   `campy/cli/backup.py` with B417's reader (or a read-only shim next to it),
   or drop the legacy path if B417 makes it unnecessary.
4. **Runtime hints and docstrings**: `KuzuClient` becomes the gateway or
   client type actually passed.
5. **Dependency**: `kuzu` stays only where B417 needs it, ideally as an
   optional extra (`campy[migrate-legacy]`) so a normal install does not pull
   it in.

### Not changed

- B417's migrator and its Kùzu dependency.
- `docs/ARCHITECTURE.md`'s cutover record (history), apart from a line that
  the residue is gone.

### Sequencing

This is mechanical but wide (28 test files, about 850 query strings). Do it
in PRs per area: tests first (step 1), since steps 2–4 are only safe once no
test runs Cypher. Each PR must show the same full-suite failure set as main,
and a test count that drops only by the "delete" decisions in the inventory.

### Acceptance Criteria

- [ ] Inventory of every test in the 28 files with a port / delete / keep
      decision, committed with the first PR.
- [ ] No test except B417's executes a `cypher` string; every ported test
      runs on a real Oxigraph store and keeps its original intent.
- [ ] `NamedQuery` no longer requires `cypher`; the Cypher strings and the
      gateway's Cypher dispatch path are gone; the Cypher ratchet is
      retired from CI and the Makefile.
- [ ] No production module imports or looks up anything from `tests/`.
- [ ] `kuzu` is needed only by B417's migrator.
- [ ] Full suite: same failure set as main at each step; the test count
      changes only by the inventory's deletions.
