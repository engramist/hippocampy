# B411 - Exhaustive Migration Fixture: Round-Trip Every Node and Edge Type

State: complete
Priority: P0 — **gates B397**
Branch: feat/b411-exhaustive-migration-fixture

Blocks: B397 (engine cutover — the one-way door)

### Problem

B397's round-trip migration test — the **primary safety evidence** for an irreversible
engine cutover — runs against the patent conformance fixture, not a populated graph.
B397's own card required *"a real, populated graph — not a synthetic fixture."*

Measured coverage of `tests/fixtures/patent_conformance_graph.jsonl`:

```
26 nodes, 31 edges
node types:  10 / 57   (18%)
edge types:  13 / 110  (12%)
```

**What it does prove:** all three reification classes round-trip successfully.

| class | in fixture | in schema |
|---|---|---|
| `plain` | 8 | 52 |
| `star` | 4 | 28 |
| `occurrence` | **1** | 15 |

RDF-star quoting, the occurrence-node pattern, and plain triples each execute. The
class-level logic is genuinely verified and that is worth keeping.

**What it does not prove:** anything table-specific. 88% of edge types and 82% of node
types have never round-tripped. Uncovered: unusual datatypes, `STRING[]` columns,
property-name collisions, and — most seriously — any table whose `EDGE_REIFICATION`
class was misjudged.

That is exactly the bug class this migration has already produced three times:

- **B404** — wrong PK column; decay silently dead for three node types
- **B405** — property written to a property-free edge table; dedup aborted mid-merge
- **B406** — the guard built precisely because this class cannot be eyeballed

And `occurrence` — the most intricate pattern, and the one where a wrong class
**silently destroys data** rather than erroring — is exercised by **1 of 15** types.

### Scope

Build `scripts/generate_migration_fixture.py`:

1. **Derive coverage from `schema.py` by importing it**, not by re-parsing — including
   `_MIGRATIONS` and the comprehension-generated migrations over `PROVENANCE_TABLES` /
   `CONTENT_HASH_TABLES`. B406 already solved this derivation; reuse it rather than
   re-deriving, and do not approximate it (approximation produced false positives
   twice during B406's investigation).
2. **Emit at least one row per node table (57) and per edge type (110).**
3. **Exercise every datatype** in the §3.1 mapping table — notably `STRING[]`
   (unordered per §3.3), `TIMESTAMP`, `DOUBLE` (the `xsd:decimal` trap, §3.2), and
   `FLOAT[384]` (which must leave the graph entirely, §5).
4. **Weight toward the dangerous classes.** Every one of the 15 `occurrence` types must
   round-trip with **multiple occurrences on the same `(s,p,o)`** — a single
   occurrence cannot distinguish correct behaviour from silent overwrite. Every `star`
   type must assert both the plain triple and the quoted annotation (§4.2a).
5. **Cover the deliberately-unclassified tables**: assert `classify_edge()` raises for
   each of the 15 in `UNCLASSIFIED_ESCALATED_TABLES` rather than silently defaulting.
6. Wire the generated fixture into `tests/test_migration_roundtrip.py` **alongside**
   the patent fixture. Do not replace it — the patent fixture has its own purpose.

### Explicitly NOT in scope

- Do not change `EDGE_REIFICATION` classifications. If the exhaustive round-trip
  reveals a misclassification, **report it** — that is a finding, and it is the whole
  point of this card.
- Do not modify the migration code to make the fixture pass. A failure here is
  evidence the migration is unsafe, not evidence the test is wrong.

### Acceptance Criteria

- [ ] Fixture covers 57/57 node tables and 110/110 edge types.
- [ ] Coverage asserted programmatically against `schema.py`, so new tables fail the
      test until represented — this must not drift the way the schema did.
- [ ] Every `occurrence` type round-trips **multiple** occurrences on one `(s,p,o)`.
- [ ] Every `star` type round-trips both plain triple and quoted annotation.
- [ ] Every §3.1 datatype exercised, including `STRING[]` and `FLOAT[384]`.
- [ ] `classify_edge()` proven to raise for all 15 unclassified tables.
- [ ] Round-trip set-equality holds across the full fixture.
- [ ] Any misclassification or data loss discovered is **reported, not patched away**.

### Related

- **B397** — gated on this. The cutover is irreversible; its evidence should carry that weight.
- **B406** — reuse its schema derivation; do not re-implement.
- **B404 / B405** — precedents for the per-table bug class this fixture is designed to catch.

### Outcome

The one-way door is backed by evidence proportional to its irreversibility: every node
type, every edge type, and every reification class proven to survive the migration —
rather than 12% of them.
