# B245 - Rename Config Namespace from `sidequests.toml` to `campy.toml`

State: complete
Priority: P0

Plan: backlog/plans/B-245-rename-config-namespace-to-campy-toml.md

### Problem

The default repository config is still named `sidequests.toml`. Publicly, the product is now HippoCampy/Campy. New installs should prefer `campy.toml`, while existing projects using `sidequests.toml` must continue working.

### What This Card Does

Introduces `campy.toml` as the primary config filename, updates config search order, updates installer output, and preserves read compatibility for `sidequests.toml`.

### Dependencies

- B241 complete - public Campy naming exists
- B242 complete - Campy namespace exists

### Files to Create/Modify

| File | Action |
|---|---|
| `campy.toml` | CREATE or MOVE from `sidequests.toml` |
| `sidequests.toml` | KEEP as legacy sample or replace with forwarding comment if safe |
| `campy/data/config/campy.toml` | CREATE - packaged default config |
| `campy/data/config/sidequests.toml` | KEEP - legacy packaged fallback if still needed |
| `mcp_engine/config.py` or new `campy/config.py` owner | MODIFY - search `campy.toml` before `sidequests.toml` |
| `campy/cli/install.py` | MODIFY - write `campy.toml` for new project/global configs |
| `campy/cli/doctor.py` | MODIFY - report config source and legacy status |
| `tests/test_config.py` | MODIFY - test precedence and fallback |
| `tests/test_packaging_installed_mode.py` | MODIFY - assert packaged `campy.toml` resource |

### Acceptance Criteria

- [ ] New project/global config writes use `campy.toml` or `~/.campy/config.toml`.
- [ ] Config search order prefers explicit path, then `campy.toml`, then legacy `sidequests.toml`, then runtime configs.
- [ ] Existing `sidequests.toml` projects still load without errors.
- [ ] If both `campy.toml` and `sidequests.toml` exist, `campy.toml` wins.
- [ ] Doctor reports when a legacy config is being used.
- [ ] No durable DB/log/socket paths are moved by this card.

### Validation Commands


### Outcome

Campy has a primary config filename without breaking old projects that still contain `sidequests.toml`.
