# B266 - Rename Overlapping Skills to campy-* Prefix

State: ready
Priority: P1

Plan: backlog/plans/B-266-rename-overlapping-skills.md

### Problem

Five Campy skills share names with Matt Pocock's upstream superpowers skills (`grill`, `diagnose`, `tdd`, `handoff`, `improve-architecture`). These are Campy's forks with memory integration added, but the identical names cause confusion and shadowing conflicts, especially in Codex where skills are installed to a shared `~/.codex/skills/` directory.

### What This Card Does

Renames the 5 overlapping skill directories in `plugin/skills/` to use a `campy-` prefix. Updates all internal references.

### Dependencies

- None (can run in parallel with B265)

### Files to Modify (rename directories)

Rename these directories under `plugin/skills/`:

| Old Name | New Name |
|----------|----------|
| `grill/` | `campy-grill/` |
| `diagnose/` | `campy-diagnose/` |
| `tdd/` | `campy-tdd/` |
| `handoff/` | `campy-handoff/` |
| `improve-architecture/` | `campy-improve-architecture/` |

For each renamed directory:
1. `git mv plugin/skills/OLD plugin/skills/NEW`
2. Update any cross-references inside the SKILL.md files. For example, if `grill/SKILL.md` references `diagnose`, update to `campy-diagnose`.
3. Search for references to old skill names in these files and update:
   - `plugin/skills/*/SKILL.md` — any cross-skill references
   - `campy/cli/plugin_installer.py` — the `CODEX_LEGACY_PROCESS_SKILL_NAMES` set (line 18-27)
   - `campy/cli/register.py` — any skill name references
   - `docs/ARCHITECTURE.md` — skill name references
   - `CLAUDE.md` — skill name references
   - `docs/superpowers/specs/2026-05-22-context-window-integration-design.md` — skill references

### How to Find All References

Run these commands to find every reference to the old skill names:

```bash
# Find all references to old skill names (case-sensitive)
rg -l "skills/grill|skills/diagnose|skills/tdd|skills/handoff|skills/improve-architecture" --type md
rg -l "skills/grill|skills/diagnose|skills/tdd|skills/handoff|skills/improve-architecture" --type py

# Find references in SKILL.md files that cross-reference other skills
rg "diagnose|grill|handoff|improve-architecture" plugin/skills/*/SKILL.md
```

### Do NOT rename these 7 Campy-native skills (no conflict):

- `recall/`, `brief/`, `learn/`, `session-start/`, `memory-awareness/`, `quest-management/`, `status/`

- [ ] `plugin/skills/campy-grill/SKILL.md` exists

### Outcome

All 5 overlapping skills have unique `campy-*` names that won't conflict with upstream superpowers skills on any platform.
