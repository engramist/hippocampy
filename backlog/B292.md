# B292 - Split the tools/__init__.py God Module

State: ready
Priority: P1

Plan: (inline — this card is self-contained)

### Problem

`campy/brain/thalamus/tools/__init__.py` is 3,426 lines and holds nearly every MCP tool handler: memory tools (`notify_turn`, `current_truth`, `explore_graph`), quest tools, ARC tools' glue, `register_artifact` (B290), plus shared helpers (`_with_phase`, `get_or_create_session`, `get_or_create_main_quest`) and the `TOOL_HANDLERS` registry. Every feature card collides in this one file; review diffs are noisy; subagents must load 3.4k lines of context to change one handler.

The correct pattern already exists in this package: B290 put CWS logic in `campy/brain/thalamus/tools/work_summary.py` and `__init__.py` only wires it. This card applies that pattern to the rest of the module.

### What This Card Does

Split `__init__.py` into focused domain modules, keeping `__init__.py` as a thin aggregator that (a) re-exports every public name that exists today and (b) builds `TOOL_HANDLERS`. **No behavior change, no signature change, no test-assertion change.** This is a pure mechanical move.

Target module layout (create under `campy/brain/thalamus/tools/`):

| New module | Moves in (search for these defs in `__init__.py`) |
|---|---|
| `_shared.py` | `_with_phase`, `get_or_create_session`, `get_or_create_main_quest`, severity/phase constants, common imports helpers |
| `capture.py` | `notify_turn` and its private helpers (token-limit update, session boot) |
| `retrieval.py` | `current_truth`, `explore_graph`, `analogical_search`, `diff_since`, `reconstruct_timeline`, `context_status`, lexical fallback helpers |
| `quests.py` | `set_quest`, `complete_quest`, `branch_quest`, `get_open_loops`, task-graph tools (`register_task_graph`, `get_ready_tasks`, `advance_task`, `fail_task`, `get_task_graph`) |
| `lessons.py` | `upsert_lesson`, `recall_relevant_lessons`, `recall_procedures`, `recall_plans`, `register_plan`, `_synthesize_lesson` (the bare `asyncio.create_task` at the old line ~2207 moves with it) |
| `artifacts.py` | `register_artifact`, `_infer_document_type`, `_ARTIFACT_TYPE_MAP` (B290) |
| `arc_tools.py` | every `arc_*` handler currently defined in `__init__.py` (thin glue only — `arc_queries.py` / `arc_artifacts.py` already exist and stay put) |
| `context_tools.py` | `compile_context`, `memory_decision`, `ask` wiring, `ingest_document`, `ingest_data` |

Rules for the move:

1. Read `__init__.py` fully FIRST and build the actual def → module mapping; the table above is the intent, the file is the truth. Any handler not listed goes to the most-fitting module (never leave one behind in `__init__.py`).
2. `__init__.py` after the split contains ONLY: imports from the new modules, `from ... import *`-free explicit re-exports of every name that was previously importable (`from campy.brain.thalamus.tools import notify_turn` etc. MUST keep working — tests import this way), and the `TOOL_HANDLERS` dict (unchanged keys/order/wrapping).
3. Private cross-module helpers move to `_shared.py`; do NOT duplicate code between modules.
4. Preserve the module-attribute patching contract: `tests/test_cws.py` patches `campy.brain.thalamus.tools.work_summary.update_work_summary`, and `notify_turn` deliberately imports `work_summary` at call time via module attribute (`_cws.update_work_summary`). Keep that call-site import style for any similar lazy imports you move.
5. Do the split in 2–4 commits (e.g., shared+capture, retrieval+quests, lessons+artifacts+arc, context+final wiring), running the gate tests between each.

### Dependencies

None. Do BEFORE B293 (tool-surface codegen) — codegen is cleaner against split modules.
