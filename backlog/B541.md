# B541: cycles in the kind hierarchy (`BROADER`)

**Status:** Open. Found in passing by the B540 offline screen (store copies of the LoCoMo design conversations, 2026-10-27).

**Principles:** P2 (the kind closure `BROADER*` is the query list and count answers rely on; a cycle makes every kind on it equal to every other), P3 (a rule refuses the write, no model involved).

**What was seen.** A baseline store (built by main's capture) holds both `game BROADER video game` and `video game BROADER game`, and `basketball game BROADER game` sits on both sides of that cycle. Under `BROADER*` a question about "games" and one about "video games" then return the same set.
