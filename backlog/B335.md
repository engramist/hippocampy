# B335 - SWE_CI Benchmark Cites a Placeholder arXiv ID and "TBD" Repository, Dataset n=4

State: complete — merged via PR #57 (2026-08-20)
Priority: P1

Plan: none yet.

### Problem

`benchmarks/benchmark_sources.md`'s SWE-CI entry cites:

```
Source: https://arxiv.org/abs/2603.xxxxx (March 2026)
Repository: TBD (Private/Beta early access)
Task Count: 100 tasks across 68 repositories.
```

`2603.xxxxx` is a placeholder arXiv ID (the literal `xxxxx` was never filled in), and "Repository: TBD"
confirms this citation was never completed. An external audit additionally found the actual dataset
this benchmark runs against has `n=4` — nowhere close to the "100 tasks across 68 repositories" the
sources doc claims. Confirmed for this card: grep the actual benchmark data/task list under
`benchmarks/` (check whatever `SWE_CI`/`swe_ci` harness module loads its task set from — likely
alongside `benchmarks/causal/` or a dedicated `benchmarks/swe_ci/` directory) for the true current task
count before writing the fix.

This is the same category as B332/B333/B334: a citation describing something more real/large than what
actually exists and runs.

### What it does (scope)

1. Locate the actual SWE_CI harness and its task source (grep `rg -rln "swe_ci|SWE_CI|SWE-CI" -i
   benchmarks/` to find the harness module and confirm the real current task count — do not assume it's
   still exactly 4, verify fresh).
2. Fix `benchmarks/benchmark_sources.md`'s SWE-CI entry: either resolve the placeholder arXiv ID to a
   real citation if one now exists, or remove the citation and mark the source as "internal
   task set, not derived from a specific published paper" if no real paper backs it. Correct the "Task
   Count: 100 tasks across 68 repositories" line to the verified actual count from item 1. Change
   "Repository: TBD" to either a real repository reference or an explicit "no external repository —
   internal task set" statement.
3. Grep for any other citation of "100 tasks across 68 repositories" or the SWE-CI numbers in reports/
   README and correct those too.

### Dependencies

None. Independent of B332/B333/B334 — separate files, can run in parallel.

### Files to create/modify

- `benchmarks/benchmark_sources.md` (SWE-CI section).
- The SWE_CI harness module itself, only if item 1's investigation finds the module's own docstrings
  or constants repeat the same false numbers.
- Any report docs citing the "100 tasks / 68 repositories" figure — grep first.
