### Problem

Campy's CLI (`campy`) has `setup`, `start`, `stop`, `status`, `doctor`, `activity`, `smoke`, `review`, and `tool list` — but zero recall commands. Developers and hooks need a way to query memory from the command line without going through MCP. CLI interfaces are gaining popularity for AI tools and this is a natural integration surface.

### What This Card Does

Adds 6 new CLI subcommands under `campy` that call the MCP daemon's tools and format the output for terminal display:

| Command | MCP Tool | Purpose |
|---|---|---|
| `campy recall <query>` | `current_truth` | Quick semantic recall |
| `campy bundle <query>` | `compile_context` | Full bundle compilation |
| `campy timeline [--since ISO]` | `reconstruct_timeline` | Temporal event view |
| `campy diff [--since ISO]` | `diff_since` | What changed since last session |
| `campy decide <query>` | `memory_decision` | Ask router what tool to use |
| `campy context` | `context_status` | Current context health |

### Dependencies

- None (uses existing MCP daemon HTTP interface at `http://127.0.0.1:7799`)

### Design Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Communication | HTTP POST to daemon's MCP endpoint | Reuses existing `_send()` helper from `smoke_test.py` |
| Output format | Rich tables + markdown by default, `--json` for raw | Consistent with existing `activity` and `tool list` commands |
| `--format=prompt` flag | Outputs bare text suitable for hook injection | Enables B259 hooks to use `campy recall --format=prompt` |
| Error handling | Graceful "daemon not running" message | Don't crash if daemon is down |

### Changes

- `recall_app = typer.Typer()` with all 6 subcommands
- Each command calls `_send("tools/call", {"name": tool, "arguments": args})`
- Rich-formatted output with `--json` and `--format=prompt` options

**Modified `campy/cli/main.py`:**
- Import and mount `recall_app` commands (either as subcommands or top-level)
- `campy recall`, `campy bundle`, `campy timeline`, `campy diff`, `campy decide`, `campy context`
