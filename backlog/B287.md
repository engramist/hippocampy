### Problem

`current_truth` merges results from four signal sources with incompatible scales and no normalization:

- Vector scores per table (nonlinear distance transform — true cosine after B279)
- Lexical exact matches (hardcoded `score: 1.0` — always beats everything)
- `pathway_strength` (unbounded, grows with Hebbian reinforcement)
- Outcome signals / valence boosts

The final ranking is therefore ad hoc: a lexical substring hit on a throwaway message outranks a high-confidence reinforced Decision; pathway_strength's unbounded scale can dominate or be dominated depending on graph age. The ranking semantics are undocumented and will shift again whenever any component's scale changes (as B279 does).

### What This Card Does

1. Documents the current fusion behavior precisely (read the ranking code in `current_truth` and write down what actually wins).
2. Replaces ad-hoc fusion with **Reciprocal Rank Fusion (RRF)** across the source lists (vector per-table, lexical), then applies bounded multiplicative adjustments for pathway_strength and outcome valence.
3. Encodes the ranking contract in a fixture test so future scale changes break loudly.
