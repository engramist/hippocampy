### B63 · Consolidation Loop for Non-Git Sessions

**Problem:** When `notify_turn` is called from a session without a Git context (e.g., OpenClaw extension not in a repo), the Hippocampus routing returns an empty `quest_id`, and the consolidation loop may not properly link or store artifacts.

**What it does:** Ensures every session has a valid quest by creating a default "SideQuest" when no Git repository or existing quest is identified. This allows for persistent memory even in non-repo-linked sessions.

**Acceptance Criteria (Evaluation):**
- Calls to `notify_turn` without `repo_root` successfully return a `quest_id`.
- Memories stored in non-repo sessions are recallable in subsequent sessions.
- Graph shows these sessions linked to a default quest node.

**Outcome:** Every conversation, whether repo-linked or not, is captured into the long-term memory graph.
