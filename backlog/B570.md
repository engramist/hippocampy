# B570: the migration fixture cannot be regenerated: INSTANCE_OF has properties but is classified plain

**Status:** Fixed 2026-11-14 (design A, approved by the review session): REIFIER_ANNOTATION_COLUMNS; the fixture carries reifier rows checked through the steward's SPARQL. Found in passing while adding RELATION_OF in item 3.

**Principles:** P6 (measure correctly before believing): a fixture that cannot be rebuilt from the schema no
longer checks the schema.

**What.** Running `scripts/generate_migration_fixture.py` on main writes INSTANCE_OF rows with the properties
`agreed_by`, `evidence_set`, `link_source`, `link_status` and `steward_reason` (from schema.py's migrations), but
EDGE_REIFICATION classifies INSTANCE_OF as `plain`. `tests/test_migration_roundtrip.py` then fails with "INSTANCE_OF
is classified 'plain' (no properties) but properties were passed". The checked-in fixture predates those columns, so
CI passes only because nobody regenerates it. Item 3 added its one RELATION_OF row and its two new columns by hand
for that reason.

**Fix (to design).** Either classify INSTANCE_OF as `star` (it carries properties now; check how BROADER handles
`link_source`), or move those properties off the edge. Then regenerate the fixture and let the round-trip test
cover them.

**Graph edge.** INSTANCE_OF (read and written by the kinds steward); no new edge.
