# B474 - Conversation Evidence in Rank Order, Not Oldest-First (M1.1)

State: implemented (2026-10-10; merge gate pending)
Priority: P2

Plan: (inline — this card is self-contained)

### Problem Statement

The conversation stage (`GraphGateway._bundle_conversation`, B454) picks the
top `conversation_limit` (6) user turns by fused vector + FTS score, then
re-sorts them **oldest first** so that a later statement reads after the one
it supersedes. On DMR and LoCoMo the supersession case is rare, and the sort
puts the best-ranked turn anywhere in the list. The answer model then
answers from a near-duplicate turn by the same speaker.

Evidence (campy-benchmarks replay R27, current-main stores, same six turns,
only the order changed): best-ranked-first against oldest-first

- DMR, 50 questions: gained 5, lost 1.
- LoCoMo-10, 60 questions: gained 5, lost 2.

Replays at temperature 0 are deterministic (99/99 in R26), so these are real
differences, not noise. Held-out confirmation is part of the merge gate.

(plan M2.1).

### Decision and Implementation

1. **`[retrieval] conversation_order = "rank" | "time"`**, default `"time"`
   (the B454 order, unchanged). `"rank"` = best fused score first, opt-in.
   Unknown values log one warning and use `"time"`.
2. **Threading.** `bundle_compiler._stage_conversation` reads the setting
   like `conversation_limit` and passes it to `thalamus.bundle_conversation`
   as a new declared param `order`. The gateway handler picks the same
   top-`limit` turns in both modes; only the final sort differs.
3. **Supersession stays visible.** Each turn already carries its date in its
   stamp (`[Speaker 1, 2022-12-14 07:00]`). The ask prompt's description of
   the conversation section said "oldest first"; it is now order-aware (new
   `BundleSection.order`): under rank order it says "best match first, each
   stamped with its date -- the most recent date supersedes". The B463
   successor statement inherits its on-topic predecessor's fused score, so on
   a tie it lands right after it; a successor that outranks the predecessor
   on its own score keeps that higher place.
4. **Not changed.** `bundle_assistant_words` (B471) stays oldest first: it
   returns at most 3 turns about the assistant's own words and R27 did not
   test it. No consumer slices the first k turns of the section.

### Tests
