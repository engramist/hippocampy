# B234 - Universal SideQuests Memory Usage Skill

State: complete
Priority: P0

Plan: backlog/plans/B-234-universal-sidequests-memory-usage-skill.md

### Problem

SideQuests can capture memory reliably, but agents do not consistently know when to recall it. Current adapter prompts contain lightweight guidance such as "before answering about past choices, call current_truth," but that behavior is fragile across Codex, Claude Code, Claude Desktop, Gemini CLI, ChatGPT Desktop, and VS Code/Copilot.

The system needs one canonical memory-use policy that teaches agents when to recall, when not to recall, which tool to use, and how to preserve the core architecture goal: shrink context, do not bloat it.

### What This Card Does

Creates a universal SideQuests memory policy skill/playbook and wires it into agent-facing documentation and install paths.

The skill is canonical content, not client-specific behavior. Codex can consume it as an actual local skill. Claude, Gemini, ChatGPT Desktop, and VS Code can receive the same policy through adapter prompt fragments, agent docs, or generated setup snippets.

### Acceptance Criteria

- [ ] `skills/sidequests-memory/SKILL.md` exists and is the canonical memory-use policy source.
- [ ] Skill explains the difference between passive capture/write and active recall.
- [ ] Skill includes a recall decision tree for `current_truth`, `diff_since`, `reconstruct_timeline`, `recall_plans`, `recall_procedures`, `recall_relevant_lessons`, `analogical_search`, ARC recall tools, and `context_status`.
- [ ] Skill includes anti-bloat rules: do not recall for simple/local tasks, do not dump raw results, summarize compactly, prefer top results, and recall only when a decision needs memory.
- [ ] Skill includes examples of prompts that should and should not trigger recall.
- [ ] Skill tells agents to use `sidequests activity --follow` to verify live write/recall behavior.
- [ ] Codex install path can copy/install the skill to `~/.codex/skills/sidequests-memory/SKILL.md` when Codex skill directories are available.
- [ ] Claude/Gemini agent docs point to the same policy instead of duplicating long divergent instructions.
- [ ] Adapter prompt fragments remain short and reference the same tool-selection rules.
- [ ] Tests assert the skill file exists and mentions the core recall tools and anti-bloat guidance.

All supported agents share one memory-use policy. Codex can load it as a real skill, while other clients receive the same behavior contract through docs and adapter instructions. Recall becomes more consistent without making every turn retrieve memory.
