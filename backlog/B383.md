### Problem

Developers using agent harnesses (Claude Code, Codex, Cursor) frequently switch models mid-workflow—e.g. from Claude Sonnet to an inexpensive model (GLM 5.3, local Llama) or vice versa. Currently, this switch causes **total agent amnesia**:
1. The new model does not inherit conversation history, prompt cache, or recent architectural decisions.
2. Developers are forced to manually write "handoff markdown files" (documenting current goal, state, constraints, decisions made, and definition of done) before killing one session and starting another.
3. If an operator forgets to document a subtle constraint, the incoming model derails the codebase or reverses earlier progress.

This manual handoff process is friction-heavy and error-prone. In contrast, Campy's decoupled memory architecture positions it to automate the handoff completely.

### What it does (scope)

This card implements the **Automated Model Handoff Generator**, realizing Patent Claim #7 (*Session Handoff Intelligence between context windows*). Because Campy continuously captures turns and builds the graph (accessed via `gateway.py`), Campy generates the handoff dynamically:

1. **Automated Handoff Extraction (`campy/brain/thalamus/handoff.py`):**
   - Compiles a standardized **Handoff Artifact** directly from the live graph:
     - **MainQuest & Sub-Task Goal:** Active purpose and target outcome.
     - **Architectural Ground Truth:** All active Decisions and confirmed Constraints.
     - **Active Work Boundary:** Files touched in the current branch, modified schemas, and open ActionItems.
     - **Negative Controls & Anti-Goals:** "Do NOT do X" rules established in earlier sessions.
     - **Definition of Done:** Verification commands, test suites, and expected exit criteria.
   - Applies **Smart Deduplication via `[LOADED]` tracking**: Demotes information that has already been ingested into the incoming session.
   - **Boundary Subgraph Extraction Pattern (`query-patterns-and-translation.md`, `anti-patterns.md`):** Filter early, expand late. Extraction anchors to the active `Quest` and current session entry points, immediately filters out `archived = true` and `[:DEPRECATED_BY]` nodes at root, bounds neighbor traversal strictly to $\le 2$ hops along explicit dependency edges (`:ENABLES`, `:CONSTRAINS`, `:REQUIRES`), and caps the extracted entity boundary to $\le 40$ nodes to guarantee total prompt budget (<500 tokens). Open `ActionItem` nodes are emitted as a topologically sorted DAG.

2. **Handoff Export Formats:**
   - **CLI Generation:** `campy handoff --out HANDOFF.md` or `campy handoff --copy` (copies to clipboard for instant pasting into a new chat).
   - **MCP Tool:** `generate_handoff(target_model_tier: str)` tool callable by agents before session shutdown.
   - **Automated Hook Handoff:** Claude Code / Codex session-end and session-start hooks automatically sync the handoff bundle through Unix domain socket IPC.

3. **Cross-Model Compatibility:**
   - Strips model-specific formatting quirks or XML tags when generating handoffs intended for open-source or local models (e.g. clean markdown with bulleted constraints).
