### Problem

Campy now builds clean wheel/sdist artifacts, but the project does not yet have a confirmed public package install path. A true one-click installer should not require cloning the repository; it should be able to install Campy from a published package using `pipx`, `uv tool`, or plain `pip` in a managed virtual environment.

### What This Card Does

Prepares and validates the canonical package distribution path for Campy: package metadata, package data, release audit, TestPyPI dry run, PyPI publish checklist, and installed-mode smoke tests.

This card does not force public publication if release ownership is not ready. It creates the exact publish workflow and validates it against TestPyPI or a local package index first.

### Acceptance Criteria

- [ ] `python -m build --wheel --sdist` succeeds from a clean checkout.
- [ ] `twine check dist/*` passes.
- [ ] `scripts/release_build.sh` runs the public audit before producing uploadable artifacts.
- [ ] A fresh virtual environment can install the wheel and run `campy --help`, `campy doctor --help`, `campy install --help`, and `campy activity --help`.
- [ ] `pipx install dist/hippocampy-*.whl` or equivalent local pipx install works in a clean test environment.
- [ ] `uv tool install dist/hippocampy-*.whl` or equivalent local uv install works when `uv` is present.
- [ ] TestPyPI publish path is documented and dry-run validated, or explicitly skipped with a documented reason.
- [ ] README names the canonical package install command and clearly labels it as public, private, or pending.
- [ ] No runtime user data, ARC run artifacts, logs, sockets, or local DBs are included in wheel/sdist.
- [ ] Rollback procedure is documented for a bad package release.

### Validation Commands

```bash
rm -rf dist build *.egg-info
.venv/bin/python -m build --wheel --sdist
.venv/bin/python -m twine check dist/*
bash scripts/audit_public_release.sh --release
.venv/bin/pytest -q tests/test_public_release_manifest.py tests/test_packaging_installed_mode.py
python -m venv /tmp/campy-wheel-test
/tmp/campy-wheel-test/bin/python -m pip install -U pip
/tmp/campy-wheel-test/bin/python -m pip install dist/hippocampy-*.whl
/tmp/campy-wheel-test/bin/campy --help
/tmp/campy-wheel-test/bin/campy doctor --help
```

Campy has a verified package distribution path that a one-line bootstrap script can depend on without requiring a source checkout.
