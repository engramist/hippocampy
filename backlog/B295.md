### What This Card Does

1. Re-baseline: `pytest tests/ -q 2>&1 | tail -40` on current main; save the list to the card's PR description.
2. Work cluster by cluster (A→I), one commit per cluster. For each: root-cause FIRST (read the code, run the single test with `-x -l`), then choose exactly one of: **fix** (preferred), **xfail with `reason=` linking a backlog card/issue**, or **delete** (only for E-class "tests a thing that no longer exists").
3. Hard rules: no bare `skip` without a reason string; no loosening of assertions to make tests pass; cluster A (decay) MUST be a real fix — if it can't be fixed in this card, STOP and report BLOCKED with root-cause analysis (that's a product bug, not a test bug).
4. Add a CI job to `.github/workflows/` (`tests.yml`, separate from security-gate): `pytest tests/ -q` on push/PR with Python 3.12, so green-main is enforced going forward. Cache pip. If the full suite is too slow for CI (>10 min), split into `-m "not slow"` with markers as a follow-up note — measure first.
5. Final gate: THREE consecutive full-suite runs, all green (catches the flaky cluster I).
