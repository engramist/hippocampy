### Problem

The Campy landing page (`Campy/index.html` in the landing page repository) features attractive bioluminescent visual themes, but its messaging and technical architecture references are disconnected from what HippoCampy actually delivers:
1. It describes vague "connected memories" rather than highlighting the core patented innovation: the **Gated Consolidation Loop** (Kahneman System 1/2), Shape-First ontologies, and Thalamic Context Gating.
2. It lacks developer quickstarts for the verified one-line install (`curl -fsSL https://raw.githubusercontent.com/engramist/hippocampy/main/scripts/install.sh | sh`) and native multi-agent support (Claude Code, Codex, Gemini CLI, VS Code Copilot).
3. The interactive canvas background displays generic random nodes instead of visually demonstrating real cognitive types (Decisions, Constraints, Requirements, Lessons, Quests).

### Strategic Positioning: The Universal Memory Layer for Unbundled Harnesses

Recent market shifts demonstrate that developers are unbundling their agent harnesses (Claude Code, Codex, Cursor) from expensive frontier models to slash API bills, using $18/month models for routine work. Campy solves the two biggest bottlenecks holding this back: **Model Amnesia on Handoff** and **Uncontrolled Context Bloat**. The landing page must lead with this immediate economic and developer value:
- **"Stop Paying $200 for Work an $18 Model Can Do."**
- **"The Universal Context Bridge: Swap Models Mid-Task with Zero Amnesia."**
- **"Private. Local. Yours: Your Permanent Knowledge Graph Stays on Your Machine."**
