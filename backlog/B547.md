# B547: the question is analysed once

**Status:** Open.

**Principles:** P2 (the graph query needs the subject, the kind and the shape), P4 (syntax, not content words).

**Why.** Each retrieval stage resolves the question's Concepts on its own; the subject is guessed inside some stages; the set-valued router existed only in the L3 screen and B524 has its own. One analysis per question, recorded with the bundle: the Concepts it names, the subject (a person in the graph), the kind asked for (closed kind set), the shape (count, list, latest, when, before/after, yes/no, open), all by rule from the parse. Every stage reads it; the result is logged so a miss can be traced to the analysis.

**Measure (offline):** on the gate questions, subject right, kind right, shape right against a hand-labelled sample; part of the profile (B545).
