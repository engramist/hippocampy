# B235 - MCP Memory Decision Helper Tool

State: complete
Priority: P0

Plan: backlog/plans/B-235-mcp-memory-decision-helper-tool.md

### Problem

A static skill/prompt policy helps agents understand SideQuests, but agents still need a lightweight runtime way to ask: "Should I recall memory for this prompt, and if so, which tool should I use?"

Without a helper, clients behave inconsistently. Some under-recall and miss durable memory. Others may over-recall and bloat context. SideQuests needs a universal MCP-accessible memory traffic cop that works across Codex, Claude, Gemini, ChatGPT Desktop, VS Code, and future clients.

### What This Card Does

Adds a `memory_decision` MCP tool that recommends whether to recall memory and which recall tool to call next.

The tool does not retrieve memory in its first version. It returns a compact recommendation: recall or do not recall, recommended tool, optimized query, reason, confidence, and anti-bloat guidance. This preserves the architecture principle that retrieval should be selective and decision-triggered.

### Acceptance Criteria

- [ ] `memory_decision` appears in `tools/list` for all supported adapters.
- [ ] Tool accepts `user_prompt`, optional `task_phase`, optional `available_context_summary`, optional `session_id`, and optional `client_name`.
- [ ] Tool returns `should_recall`, `recommended_tool`, `query`, `reason`, `confidence`, `context_budget`, and `anti_bloat_guidance`.
- [ ] Tool returns `should_recall=false` for simple local coding/editing prompts where current context is sufficient.
- [ ] Tool recommends `current_truth` for prior decisions, architecture, constraints, preferences, and "what did we decide" questions.
- [ ] Tool recommends `diff_since` for "what changed since" questions.
- [ ] Tool recommends `reconstruct_timeline` for sequence/history/debug chronology questions.
- [ ] Tool recommends `recall_plans` for planning similar implementation work.
- [ ] Tool recommends `recall_procedures` for reusable workflows/process questions.
- [ ] Tool recommends `recall_relevant_lessons` for learned lessons or cross-session learning questions.
- [ ] Tool recommends `analogical_search` for "this resembles past work" situations.
- [ ] Tool recommends ARC recall tools for ARC/world-model/scene-graph/mechanic prompts.
- [ ] Tool never calls recall tools itself in v1; it only recommends the next action.
- [ ] Tool output is compact and safe to include in context.
- [ ] Tests cover positive, negative, ambiguous, and ARC-specific routing cases.
