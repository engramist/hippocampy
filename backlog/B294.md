# B294 - Finish the mcp_engine Migration (Kill the Half-Moved Package)

State: ready
Priority: P1

Plan: (inline — this card is self-contained)

### Problem

The codebase-anatomy refactor moved the engine into `campy/brain/`, but a top-level `mcp_engine/` package (8 tracked files) still exists and is LIVE:

- `campy/brain_daemon.py:35` → `from mcp_engine.llm.provider import create_llm_client`
- `campy/brain/thalamus/ask.py:34` → `from mcp_engine.llm.provider import create_llm_client`
- `campy/brain/brainstem/sweep.py:36` → `from mcp_engine.llm.provider import LLMClient`

This violates the repo's own layer rules (`campy/` importing a stray top-level package), contradicts `docs/codebase-anatomy.md`, and CLAUDE.md's Layer Cake section still cites `mcp_engine/file_bridge.py`, `mcp_engine/trigger_manifest.py`, `mcp_engine/loop/step4b_associative.py` — paths that are stale post-refactor. The project's own Copilot ecosystem checklist (Rule 1: layer placement) would flag this on any contributor PR. For a public repo whose pitch includes strict layer discipline, this is a credibility bug as much as a code bug.

### What This Card Does

1. **Inventory first:** `git ls-files mcp_engine` (8 files) and `grep -rn "mcp_engine" campy/ tests/ adapters/ scripts/ docs/ *.md --include="*.py" --include="*.md"` — build the full list of live imports AND doc references before moving anything.
2. **Move the live code:** relocate `mcp_engine/llm/provider.py` → `campy/brain/llm/provider.py` (create `campy/brain/llm/__init__.py`). Keep the module content byte-identical except its own internal imports if any.
3. **Update the three live imports** (brain_daemon, ask, sweep) to `from campy.brain.llm.provider import ...`. Grep again for any others the inventory found.
4. **Compatibility shim, then delete:** check whether anything OUTSIDE the repo could import `mcp_engine` (search `adapters/`, `plugin/`, `extensions/`, `scripts/`, installed-hook templates, and `pyproject.toml` packaging config for the string). If nothing external: DELETE `mcp_engine/` entirely (`git rm -r mcp_engine`). If something external needs it, leave a 5-line deprecation shim `mcp_engine/llm/provider.py` re-exporting from the new path with a `DeprecationWarning` — and say so in the report.
5. **Fix stale docs:** update CLAUDE.md Layer Cake key-modules line to the real current paths (verify each with `ls` before writing — e.g. find where `file_bridge.py` actually lives now: `campy/brain/thalamus/file_bridge.py`; locate the real trigger-manifest and step4b modules with `find campy -name "*trigger*" -o -name "*step4b*"`). Also sweep `docs/ARCHITECTURE.md`, `docs/codebase-anatomy.md`, `AGENTS.md` for `mcp_engine` references and fix them.
6. **Packaging check:** confirm `pyproject.toml` package discovery does not list/ship `mcp_engine` after removal (this also nudges the failing sdist test in the right direction — but fixing sdist wholesale is B295/B297 territory, don't scope-creep).
