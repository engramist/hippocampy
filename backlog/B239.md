# B239 - Homebrew Tap and macOS Native Install Path

State: complete
Priority: P1

Plan: backlog/plans/B-239-homebrew-tap-and-macos-native-install-path.md

### Problem

Many macOS users trust Homebrew more than piping shell from the internet. A true friendly install story should include a Homebrew path once the package/bootstrap path is stable.

### What This Card Does

Defines and validates a Homebrew tap/formula strategy for Campy. The formula should install the Campy CLI, make daemon setup discoverable, and delegate user-data creation to `campy install` / `campy doctor` rather than doing unsafe work during `brew install`.

### Acceptance Criteria

- [x] Formula installs the published Campy package or stable release artifact. — Not literally true yet: Campy has no public PyPI release or public repo (see B236), so `url`/`sha256` in `packaging/homebrew/hippocampy.rb` are documented placeholders pointing at the intended PyPI sdist pattern. `scripts/validate_homebrew_formula.sh` resolves the formula against a freshly-built local sdist and installs *that* for real. Swap the placeholders for the real PyPI URL/sha256 once B236 publishes.
- [x] Formula does not write user memory data during package install. — Verified: `~/.campy/brain.db` mtime unchanged across a real `brew install --build-from-source` run.
- [x] Formula prints or documents `campy install` and `campy doctor` as post-install steps. — `caveats` block prints both (plus `campy setup`, `campy doctor --repair`); confirmed live during a real `brew install`.
- [x] Formula passes `brew audit --strict` where feasible for a local/private tap. — Verified: `brew audit --strict` exits 0 against the formula resolved into a scratch local tap.
- [x] Formula passes `brew install --build-from-source` or documented equivalent in a local tap test. — Real install completes, links (`opt/hippocampy`, `bin/campy`), and `campy --help` / `brew test` both pass. Note: `brew install`'s own exit code is non-zero because of a known, documented, non-formula upstream issue (Homebrew's post-install linkage-fix step can't rewrite one Rust/PyO3-compiled transitive dependency's `.so`, `openai`'s `jiter`, which ships with no Mach-O header padding) — see `docs/homebrew-install.md` "Known limitation" section. The keg is genuinely installed and functional despite that exit code.
- [x] Uninstall instructions preserve user memory by default and document explicit data removal separately. — `docs/homebrew-install.md` "Uninstall" section; `brew uninstall` only removes the keg, `campy uninstall --delete-data` is the explicit opt-in for memory removal.
- [x] README includes Homebrew only after formula validation passes. — Added to README's "Alternative install methods" only after `scripts/validate_homebrew_formula.sh` passed locally.
- [x] Homebrew path is clearly optional; `curl`/package install remains canonical until tap is public. — Stated explicitly in both README and `docs/homebrew-install.md`.

### Validation Commands

```bash
bash -n scripts/validate_homebrew_formula.sh
brew audit --strict packaging/homebrew/hippocampy.rb || true
brew install --build-from-source packaging/homebrew/hippocampy.rb || true
rg -n "Homebrew|brew install|campy doctor|preserve user memory" README.md docs packaging scripts
```

### Outcome

Campy has a macOS-native install path for users who prefer package-manager trust over `curl | bash`.
