# B229 - Ingest ARC World-Model Evaluation Artifacts

State: complete (2026-05-03)
Priority: P1

Plan: backlog/plans/B-229-ingest-arc-world-model-evaluation-artifacts.md

### Problem

B225 ingests standard ARC artifacts, but the new ARC world-model architecture emits additional evidence:

- `submission_results_single.world_model.live.jsonl`
- `world_model_snapshot` inside `submission_results_single.json`

Without ingestion support, SideQuests can store aggregate mechanics through tools but cannot later analyze or project whether the world-model redesign is working.

### What This Card Does

Extends ARC artifact ingestion to parse world-model evaluation rows and per-result world-model snapshots into graph-native records. These records support wiki projection, regression analysis, and future mechanic-memory consolidation.

### Acceptance Criteria

- [ ] Ingestion reads `submission_results_single.world_model.live.jsonl` when present.
- [ ] Ingestion extracts `world_model_snapshot` from `submission_results_single.json` results when present.
- [ ] World-model eval step rows create bounded graph records with node/edge counts, compiled claim counts, action effect class, reasoning mode, planner candidate count, and stall signal.
- [ ] World-model summary rows create run-level health records.
- [ ] Ingestion remains idempotent by content hash and run/task/step identifiers.
- [ ] Malformed JSONL rows are skipped and reported without aborting the batch.
- [ ] Wiki projection can show a compact ARC world-model health section.
- [ ] Raw world-model snapshots are summarized; large nodes/edges payloads are not dumped into Markdown.

### Validation Commands


### Outcome

SideQuests can analyze whether ARC is actually forming and using world models, not just whether a benchmark run solved or crashed.
