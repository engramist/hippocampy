### Why we are leaving Kùzu — read this, the card's rationale changed

B384 justified this migration primarily on memory. **That justification is wrong.**
Measured RSS on this machine:

| Imports | RSS |
|---|---|
| bare Python | 14.8 MB |
| `+ kuzu` | 24.3 MB |
| `+ kuzu + fastembed` | 76.1 MB |

Kùzu costs ~1 MB on top of fastembed, and B387 alone clears the <80 MB target.
**Do not repeat the memory claim in this card's PR.** The actual reasons:

1. **Kùzu has been archived/EOL since October 2025.** An unmaintained embedded
   database holding the single source of truth is the real risk. This is the
   primary driver.
2. **B311 commit-checkpoint spikes** (150 MB → 1.1 GB transient).
3. **B285:** no in-place index updates; HNSW rebuild requires an archive-move Kùzu
   0.11.3 cannot do cheaply.
4. Native RDF-star edge annotation for the provenance model.

### Scope

Build `campy/brain/hippocampus/graph/oxigraph_client.py` implementing
`docs/rdf-schema-mapping.md` — which is **normative**. Do not invent mappings.

1. **Read/write API mirroring `KuzuClient`'s surface** (`execute_read`,
   `execute_write`) so `GraphGateway` can dispatch to either engine without call
   sites changing. B386 made this possible — keep it true.
2. **Node serialization** per spec §3: one predicate per property, explicit
   datatype tags on **every** numeric literal (§3.2 — bare Turtle `0.8` parses as
   `xsd:decimal`, not `xsd:double`; this must have a unit test), `STRING[]` as
   repeated triples (§3.3), and **NULL emits no triple** (§3.4).
3. **`EDGE_REIFICATION` classification table** — the core deliverable. An
   exhaustive `dict[str, Literal["plain","star","occurrence"]]` covering **all 102**
   rel tables. A missing entry must raise at write time, never default silently.
   - `plain` — no properties (51 tables)
   - `star` — at most one edge per `(s,p,o)`, carries properties: RDF-star quoted
     triple **plus** the asserted plain triple (spec §4.2a)
   - `occurrence` — can legitimately repeat for the same `(s,p,o)`: occurrence
     nodes hanging off the quoted triple (spec §4.2b)
   - Spec §4.2 names the known members of each family. The remainder need a
     per-table pass against their call sites. **If a table's correct class is not
     clear from the schema and its callers, escalate — do not guess.** Choosing
     `star` for an edge that actually repeats silently destroys data.
4. **Parameter binding** per spec §7.2: `$param` → SPARQL `?param` via
   `VALUES`/`BIND`. **Never string-interpolate.** Extend `NamedQuery.__post_init__`
   static-string validation to the `sparql` field.
5. **`tests/test_rdf_mapping_spec.py`** — executable conformance tests for every
   pattern in the spec, so spec and client cannot drift (spec §9).
