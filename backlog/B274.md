### Problem

Many AI coding tool users have Node.js installed but not Python packaging tools. An npm wrapper lets them install Campy with `npx hippocampy setup` or `npm install -g hippocampy`.

### What This Card Does

Creates a thin npm package that:
1. Checks for Python 3.12+
2. Delegates to `scripts/install.sh` for actual installation
3. Provides `npx hippocampy setup` as an entry point

### Dependencies

- B272 (install script must exist)

### Files to Create

1. **`scripts/npm/package.json`**:
```json
{
  "name": "hippocampy",
  "version": "0.1.0",
  "description": "AI memory that learns from every conversation. Install wrapper for HippoCampy.",
  "bin": {
    "hippocampy-install": "./install.js"
  },
  "scripts": {
    "postinstall": "node install.js"
  },
  "keywords": ["ai", "memory", "claude", "codex", "gemini", "mcp"],
  "author": "HippoCampy",
  "license": "Apache-2.0",
  "repository": {
    "type": "git",
    "url": "https://github.com/engramist/hippocampy"
  }
}
```

2. **`scripts/npm/install.js`** (~40 lines):
```javascript
#!/usr/bin/env node
const { execSync, spawnSync } = require('child_process');
const os = require('os');

console.log('Installing HippoCampy...');

// Check platform
if (os.platform() === 'win32') {
    console.error('Windows is not yet supported. Please use WSL.');
    process.exit(1);
}

// Download and run install script
try {
    execSync(
        'curl -fsSL https://raw.githubusercontent.com/engramist/hippocampy/main/scripts/install.sh | bash',
        { stdio: 'inherit' }
    );
} catch (error) {
    console.error('Installation failed:', error.message);
    console.log('');
    console.log('Manual install: pip install hippocampy && campy setup');
    process.exit(1);
}
```

3. **`scripts/npm/README.md`** — npm package README explaining this is a thin wrapper.
