# B400 - Remove Unused PyTorch Backend (Keep spaCy)

State: ready
Priority: P0
Branch: feat/b400-drop-torch

Design: docs/superpowers/specs/2026-09-05-entity-candidate-generation-design.md
Supersedes: B387 (measured and rejected — ONNX replacement scored F1 0.534 vs the >=95% bar)

### Problem

`import spacy` pulls `torch` into `sys.modules`, but **torch is never used for
computation**. Verified: `thinc`'s backend is `NumpyOps`, and the `en_core_web_md`
pipeline is entirely CNN-based (`tok2vec`, `tagger`, `parser`, `attribute_ruler`,
`lemmatizer`, `ner`) — no transformer component. It is an unused optional backend.

Measured warm (model loaded *and invoked*):

| | RSS |
|---|---|
| baseline Python | 14.5 MB |
| spaCy loaded + invoked, torch present | **541.0 MB** |
| spaCy loaded + invoked, torch import blocked | **386.9 MB** |

**154 MB of resident memory and 436 MB on disk, for zero functional contribution.**

Verified by blocking `torch` at the import hook: NER, `noun_chunks`, and dependency
labels are all still produced, byte-identical. It is the same model.

### Why this rather than B387's ONNX replacement

B387 replaced spaCy with ONNX + a shallow parser and measured **entity F1 0.534**
against the spaCy baseline — far below the >=95% bar. That branch is preserved as
evidence, not deleted. See the design doc for why "find a better NER model" is
probably the wrong follow-up, and B401 for what to measure instead.

This card takes only the free win: identical behaviour, less memory.

### Scope

1. Remove `torch` and `torchvision` from `pyproject.toml` and `requirements.txt`.
2. Determine how `thinc` is pulling torch and prevent it: verify whether
   `thinc-apple-ops` / `thinc[torch]` extras are implicated, and pin/exclude
   appropriately. **`thinc` and `spacy` themselves stay** — only the torch backend goes.
3. Add a regression test asserting `torch` is absent from `sys.modules` after a full
   ingestion path exercise.
4. Verify install works from a clean venv without torch — this is the real risk, since
   a transitive dependency may reinstall it.

### Explicitly NOT in scope

- Do **not** change `step1_ner.py` or `step1b_relations.py` behaviour.
- Do **not** replace spaCy. Extraction output must be byte-identical.

### Acceptance Criteria

- [ ] `torch` absent from `sys.modules` after exercising the full ingestion path.
- [ ] Clean-venv install produces no torch; `pip list | grep -i torch` empty.
- [ ] Extraction output **byte-identical** to pre-change on a fixed sample of turns
      (assert equality, do not eyeball).
- [ ] Warm RSS measured and reported before/after, per the methodology in the design
      doc §5 (warm, post-invocation — not import-time).
- [ ] Full `tests/patent_claims/` passes with zero assertion edits.
- [ ] `tests/test_loop.py`, `tests/test_retrieval.py` pass.
- [ ] Cypher ratchet still 0.

### Outcome

~154 MB resident and 436 MB on disk removed with zero behavioural change, and the
extractor question deferred to B401's measurement rather than guessed at.
