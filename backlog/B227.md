# B227 - ARC Mechanic Prior Retrieval and Ranking Tool

State: complete (2026-05-03)
Priority: P0

Plan: backlog/plans/B-227-arc-mechanic-prior-retrieval.md

### Problem

`ARC_AGI` now calls `recall_mechanic_priors(signature=..., limit=..., min_confidence=...)` during safe reasoning phases, but sidequests-brain does not expose that tool. Without it, ARC can publish and compile current-game evidence, but it cannot retrieve reusable cross-game mechanic priors.

### What This Card Does

Adds `recall_mechanic_priors`, a bounded graph traversal over ARC mechanic memory. The tool returns small ranked mechanic priors with action/effect patterns, failure modes, recovery policies, confidence, and evidence summaries.

Graph rule: retrieval must return similar world-model structures, not similar raw logs.

### Acceptance Criteria

- [ ] `recall_mechanic_priors` appears in `tools/list`.
- [ ] Tool accepts `signature`, `limit`, and `min_confidence`.
- [ ] Retrieval filters early by bounded signature fields such as action-set shape, effect class, terminal relevance, coordinate relevance, archetype, and failure signal.
- [ ] Traversal is bounded and avoids global action/color supernodes.
- [ ] Results are ranked by signature similarity, confidence, evidence count, and recency when available.
- [ ] Response includes `results`, each with mechanic id/name, confidence, similarity, action patterns, effect patterns, failure modes, recovery policies, evidence summary, and provenance.
- [ ] Missing or empty graph returns `{"results": []}` without error.
- [ ] Tests verify ranking, min confidence, limit, and bounded traversal behavior.

ARC can retrieve reusable mechanic priors from graph memory and use them to guide world-model planning instead of re-learning every game from scratch.
