### B64 · Bug: Message Count Shows 0 in Stats

**Problem:** After successfully storing messages via `notify_turn`, the `/api/stats` endpoint still shows `"message": 0`, even when concept counts increase.

**What it does:** Investigates and fixes the stat counting logic in `mcp_engine/graph/kuzu_client.py` or the stats API to correctly reflect stored message counts.

**Acceptance Criteria (Evaluation):**
- `/api/stats` accurately reflects the total number of message nodes in the graph.
- After a successful `notify_turn`, the message count increment is visible in stats.

**Outcome:** Accurate observability of ingestion activity.
