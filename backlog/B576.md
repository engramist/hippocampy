# B576: remove the concept walk's code

**Status:** Open. Filed 2026-11-18 with B575, on the review session's ruling.

**Principles:** P7 (a switch that lost its gate is deleted, not kept off), P2.

**Why.** The concept walk (`[retrieval] graph_linking_limit`, B503/B559/B560) lost alone (R95, 7 gained / 14 lost), was off in both measured profiles (step 0c and step 4 ran principled with the limit at 0), and B575 removed it from the profile. Its default has been 0 since B514, so it adds no section anywhere.

**What.**
- Remove the walk's retrieval stage (`thalamus.bundle_concept_walk` and its NamedQuery), the `graph_linking_limit` key, its env var `CAMPY_GRAPH_LINKING_LIMIT` and the `linked` bundle section.
- Keep what capture writes: `graph_linking` (Observation to Concept links), SKOS, SPOKEN_BY and MENTIONS stay; other stages read them.
- Benchmark scripts that set `CAMPY_GRAPH_LINKING_LIMIT=0` must keep working: an unknown env var is ignored today, so check that before removing the key.

**Done when:** no code reads `graph_linking_limit`; a bundle never has a `linked` section; the tests that covered the walk are removed or point at what replaced them; the full suite passes.
