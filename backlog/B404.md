# B404 - test_daemon_script_worktree_resolution.py cannot pass from a worktree

State: ready
Priority: P2
Branch: TBD

### Problem

Both tests in `tests/test_daemon_script_worktree_resolution.py` fail whenever the
test file itself lives in a git worktree (e.g. any session working under
`.claude/worktrees/`), independently of the code under test.

The file computes

```python
REPO_ROOT = Path(__file__).resolve().parent.parent
```

which is the **worktree**, then asserts that `campy.cli.launchd._canonical_repo_root()`
— whose entire job is to resolve to the **main checkout** — equals it:

```python
assert resolved["repo_root"] == str(REPO_ROOT)
```

So the production behaviour is correct and the assertion is what is wrong: the
test's own notion of "the repo root" is worktree-relative while the resolver's is
canonical. Observed 2026-09-05 during B403; the resolver returned
`/Users/.../hippocampy` (correct) against an expected
`/Users/.../hippocampy/.claude/worktrees/<name>`.

`test_canonical_repo_root_from_main_checkout_is_itself` fails for the same reason:
run from a worktree, "the main checkout" is not `REPO_ROOT`.

### Why it matters

This is the regression guard for the 2026-08-04 launchd-from-worktree incident,
and agent sessions in this repo run from worktrees by default — so the guard is
red exactly in the environment it was written to protect, which trains readers to
ignore it. It also makes "is the suite green?" ambiguous for every worktree
session.

### Fix sketch

Derive the canonical root the same way the resolver does rather than from
`__file__`:

```python
REPO_ROOT = Path(
    subprocess.run(["git", "rev-parse", "--path-format=absolute", "--git-common-dir"],
                   cwd=Path(__file__).parent, capture_output=True, text=True,
                   check=True).stdout.strip()
).parent
```

(`--git-common-dir` points at the main checkout's `.git` from inside a worktree,
and at its own `.git` otherwise.) Keep every assertion as-is; only the expected
value changes. Verify by running the file from both a worktree and the main
checkout.

### Acceptance Criteria

- [ ] Both tests pass when run from the main checkout.
- [ ] Both tests pass when run from a `.claude/worktrees/` worktree.
- [ ] The incident's actual regression — daemon script resolving into a worktree —
      still fails the test (verify by neutering `_canonical_repo_root()`).
