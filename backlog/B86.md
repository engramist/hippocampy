### B86 · Use Git Root Instead of os.getcwd() for Workspace Path

**Problem:** All 5 adapters use `ctx.setdefault("workspace_path", os.getcwd())`. If the adapter runs from a subdirectory, `workspace_path` mispoints. MainQuest hash depends on the repo root path, so the same repo gets different quest hashes from different working directories.

**What it does:** Detects git root via `git rev-parse --show-toplevel` with fallback to `os.getcwd()`.

**Depends on:** None

**Files to modify:**
- `adapters/claude_code/adapter.py`
- `adapters/claude_desktop/adapter.py`
- `adapters/codex/adapter.py`
- `adapters/chatgpt_desktop/adapter.py`
- `adapters/gemini_cli/adapter.py`

**Adapter allow-list propagation check:** No tool changes — N/A.

**Acceptance Criteria:**
- All adapters attempt `git rev-parse --show-toplevel` for workspace_path
- Falls back to `os.getcwd()` if not in a git repo
- `pytest tests/test_adapters.py -q` passes
- MainQuest hash is consistent regardless of working directory within a repo

**Outcome:** Workspace path is stable across adapter invocations from any directory in the repo.
