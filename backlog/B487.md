# B487 - Neighbour Expansion in the Conversation Stage

State: implemented (off by default; gate pending: LoCoMo-10 replay, held-out conv-30 + dev, McNemar)
Priority: P2

Plan: `learnings/e2e-improvement-plan.md` Part D (stage 3 Retrieve) and Part G; next lever from `learnings/e2e-status.md`

### Problem Statement

Many evidence turns are REPLIES that do not repeat the question's words:
"Jon's favorite style of dance?" has the evidence turn "I love all dances, but
contemporary is my top pick", a reply to "what's your fave?"; "what piece did
Gina's team perform?" has "It was called 'Finding Freedom'". Ranking finds
the turn next to the evidence (or none of it); the 6-turn stage then shows
turns with no context. Offline on LoCoMo-10 held-out conv-30, +-2 neighbours
around each retrieved turn covered 11 of 39 absent evidence turns.

### Proposed Fix

`[retrieval] conversation_neighbours = 0` (env
`CAMPY_RETRIEVAL_CONVERSATION_NEIGHBOURS`; 0 = off = today's stage,
byte-identical) and `conversation_neighbour_cap = 18`. When > 0,
`_stage_conversation` calls the new `thalamus.bundle_conversation_windows`
(a new NamedQuery; G.2), handled by `GraphGateway._bundle_conversation_windows`:

1. The matched turns are exactly `_bundle_conversation_budget`'s. When that is
   the full history (B482 fit_all, DMR) it is returned untouched.
2. Otherwise each matched turn gets up to N turns before and after it in the
   same session (Message -[SENT_IN]-> Session), by either speaker, questions
   included. Excluded: archived, assistant role (ISSUE-024), an echo of the
   query. Messages without a session get no window.
3. Order within a session: (occurred_at, stored created_at, uri). LoCoMo
   `occurred_at` is per session, so stored order does the work.
4. Windows fill in rounds by distance across the matched turns in rank order,
   so a tight `neighbour_cap` (added turns in total) keeps the best-ranked
   turns' nearest neighbours. Overlapping windows merge, contiguous runs are
   one window, turns are de-duplicated by Message.
5. Windows are presented oldest first (`conversation_order = "time"`) or best
   matched turn first ("rank"); turns inside a window are always chronological.
   Neighbours carry the same stamp as matched turns; rows carry
   `neighbour: True` for diagnostics only.

### Measure

Offline, no LLM, conversation-section evidence recall on copies of golden
stores (see PR for the table). Behaviour: replay gate on LoCoMo-10 held-out
conv-30 and dev conv-42/43, N = 1 and 2 against 0, same pins; watch prompt
tokens, latency, and adversarial abstention.
