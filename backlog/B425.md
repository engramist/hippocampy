### 1. Gate the 17 `arc_*` puzzle tools (MEDIUM)

The re-vet flagged 17 of 61 advertised MCP tools as ARC-puzzle leftovers, ungated on
`tools/list`. Added `arc_tools_exposed(config)` (`brain_daemon.py`, default **True** so the
ARC client keeps working). When `config["arc"]["expose_tools"] = false`:
- both `tools/list` builders (socket `_dispatch` and HTTP `_dispatch_mcp` in `web/server.py`)
  omit `arc_*` tools, and
- `route_tool_call` rejects an `arc_*` method as `UnknownMethodError` (so hiding also
  disables, defense-in-depth).
the platform's remote deployment sets the flag off; local/ARC use is unaffected. Proven by
`tests/test_b425_arc_tool_gating.py`.

### 2. cloud integration-guide doc fixes (MEDIUM)

- **SigV4 documented wrong.** The guide implied SigV4-signing the `POST /mcp` request.
  Corrected to the actual Vault-style pattern: the caller **presigns an
  `sts:GetCallerIdentity` request** and sends those headers; Campy replays them to STS.
  Added the 15-minute replay-window caveat (in-VPC/TLS only, not a public edge).
- **Sizing contradiction.** Header said Fargate 0.5 GB; reality is ~595 MB warm. Updated to
  1–2 GB, its own ECS service, with a pointer to ARCHITECTURE's Open Research Questions and
  the unsoaked RocksDB-on-EFS caveat.
