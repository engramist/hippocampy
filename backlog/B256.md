# B256 - Verify MCP Server Exposes All Memory OS Tools

State: complete -- verified via git log 2026-08-02 (feat(B256) 4a9f3f5); card file was stale
Priority: P0

Plan: backlog/plans/B-256-verify-mcp-tool-surface.md

### Problem

The plugin's `.mcp.json` points to `http://127.0.0.1:7799/sse`. The MCP server must expose all tools including the Memory OS additions (B249-B254): `compile_context`, `memory_decision`, `ingest_data`. If any tools are missing from the SSE endpoint, agents won't see them even with the plugin installed.

### What This Card Does

Verifies every registered tool in `mcp_engine/tools/__init__.py` is reachable through the SSE MCP endpoint. Adds a smoke test that connects to the running daemon and lists available tools. Fixes any gaps.

### Dependencies

- None (can be done in parallel with B255)

### Design Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Test approach | Smoke test that connects to SSE and lists tools | Same pattern as existing `campy/cli/smoke_test.py` |
| Tool checklist | Compare TOOL_DISPATCH keys against SSE tool list | Single source of truth is `mcp_engine/tools/__init__.py` |

### Acceptance Criteria

- [ ] Smoke test connects to `http://127.0.0.1:7799/sse` and lists all available tools
- [ ] All 30+ tools from `TOOL_DISPATCH` are present in the SSE tool list
- [ ] `compile_context`, `memory_decision`, `ingest_data` are confirmed reachable
- [ ] Test added to `tests/` and passes in CI
