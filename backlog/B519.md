# B519: settle the three standing security-advisory findings

**Status:** Open

The security gate's advisory comment repeats the same three findings on every PR, which trains readers to skip it:

1. `campy/brain/llm/provider.py` `log_truncated` (B494) writes the first 120 characters of the last user message to `daemon.log`. That isn't a hardcoded secret (the rule's wording is off), but it puts raw user text into the log, and the activity feed deliberately redacts such text. Fix: log the message length and a short hash instead of the text, or log only when a debug flag is on.
2. `campy/brain/thalamus/tools/capture.py` B338 warning logs counts and secret *types*, not values. It's a false positive. Mark it with an inline `nosemgrep` and a reason.
3. `campy/cli/doctor.py` `os.chmod(path, 0o700)` makes the runtime dir owner-only, which is the most restrictive useful mode. It's a false positive. Mark it with `nosemgrep` and a reason.

Done when the advisory comment no longer lists these on a PR that doesn't touch them.
