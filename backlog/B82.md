### B82 · Add Periodic Health Check to OpenClaw Extension

**Problem:** `registerService.start()` checks daemon health once at plugin load, never again. If the Brain Daemon crashes mid-session, OpenClaw stays in a stale offline state with no recovery.

**What it does:** Adds a periodic ping (every 30s) to detect daemon recovery and transition OpenClaw back to online state.

**Depends on:** None

**Files to modify:**
- `extensions/sidequests-brain/src/index.ts` — add `setInterval` health check

**Adapter allow-list propagation check:** No tool changes — N/A.

**Acceptance Criteria:**
- Extension pings Brain Daemon every 30 seconds
- If daemon was offline and ping succeeds, extension transitions to online state
- If daemon was online and ping fails, extension transitions to offline state with logged warning
- Existing `tests/test_b41_plugin_startup.py` still passes
- Health check interval is configurable (default 30s)

**Outcome:** OpenClaw extension recovers automatically when the Brain Daemon restarts after a crash.
