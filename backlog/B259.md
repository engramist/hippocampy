### Problem

Even with perfect skills, Claude Code won't call recall tools unless something triggers the behavior. Claude Code supports hooks (`SessionStart`, `PreToolUse`, `PostToolUse`, `Notification`) that can inject system-prompt context at key moments. Currently `_register_claude_code_hook` in `register.py` calls `adapters.claude_code.setup.register` but this only registers a passive user-turn hook — not the assertive session-start recall protocol.

### What This Card Does

Implements Claude Code hooks that inject memory recall at two critical moments:
1. **SessionStart hook**: Injects the session-start recall protocol (from B258's skill) so Claude Code automatically checks memory at conversation start
2. **PreToolUse hook**: Before tool calls that touch architecture/design, injects a reminder to check `current_truth` first

### Dependencies

- B258 complete (session-start skill must exist to reference in hook content)
- B255 complete (plugin must be installable)

### Design Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Hook type | `SessionStart` for recall, `PreToolUse` for reminder | SessionStart fires once per conversation; PreToolUse fires on specific tool patterns |
| Hook format | `.claude/hooks/session-start.sh` script that calls `campy recall --format=prompt` | Shell script hook is Claude Code's native mechanism |
| Content injection | Script outputs system prompt text to stdout | Claude Code reads hook stdout as injected context |
| PreToolUse scope | Only fires before `Read`, `Edit`, `Write` on architecture files | Avoids noise on every tool call |

### Changes

**New `adapters/claude_code/hooks/session_start.sh`:**
- Calls `campy recall --query="session context" --format=prompt` (B261)
- Falls back to static skill content if CLI not available

**New `adapters/claude_code/hooks/pre_tool_use.sh`:**
- Checks if the tool target matches architecture patterns
- If yes, outputs a 1-line reminder: "Check current_truth before modifying architecture"

**Modified `adapters/claude_code/setup.py`:**
- `register()` now installs both hooks into project `.claude/hooks/`

**Modified `campy/cli/register.py`:**
- `_register_claude_code_hook()` updated to call new `setup.register()` with hook installation
