# B242 - Add `campy` Python Import Namespace Shim

State: complete
Priority: P0

Plan: backlog/plans/B-242-add-campy-python-import-namespace-shim.md

### Problem

HippoCampy currently publishes the `campy` CLI, but the Python import package is still `sidequests`. Jumping directly to a package move risks breaking installed MCP adapters and legacy imports. We need a safe intermediate namespace so code can begin importing `campy` before the implementation package is moved.

### What This Card Does

Adds a new `campy` Python package that forwards to the existing `sidequests` implementation package. This is a compatibility bridge only; it should not duplicate logic or introduce a second durable state path.

- B241 complete - public product/CLI branding exists

### Outcome

Agents and installers can begin using `campy.*` import paths safely while legacy `sidequests.*` remains the implementation namespace.

### Completion Notes (verified 2026-08-02)

`campy` is not a thin shim — it is the full implementation package (this happened via a larger direct rename, commits `27c9f6e` "Rename project namespace to Campy" and later `3b4c608` "chore: remove sidequests compatibility shims and console scripts", both already on `main` before this card was actioned). This exceeds B242's original scope rather than falling short of it:

- `import campy`, `campy.paths.runtime_dir`, `python -m campy.cli.main --help`, and `campy.adapters.mcp_server` import all work — verified via `tests/test_campy_namespace.py` (5/5 passing).
- `pyproject.toml` package discovery includes `campy*` (and `adapters*`, `web*`).
- The literal bullet "`sidequests` imports still work unchanged" is no longer true: the `sidequests/` package was deliberately and fully removed by `3b4c608` after confirming no production code depended on it. That removal already happened before this audit, is documented in `docs/legacy-name-audit.md`, and is intentional — not a regression to fix.

No `__main__.py` shim was needed for `python -m campy.adapters.mcp_server` (it works directly). Marking complete since the card's actual outcome — agents/installers can safely use `campy.*` — is achieved and superseded by the full migration.
