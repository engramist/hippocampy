### B72 · Expand explore_graph Traversable Edge Types

**Problem:** `_TRAVERSABLE_RELS` in `mcp_engine/tools/explore_graph.py` has only 19 edge types. ARCHITECTURE.md defines 30+. Missing edges prevent traversal into plan graphs (`PLANNED_IN`, `TARGETS`, `STEP_OF`, `NEXT_STEP`, `ACTS_ON`, `OUTCOME_SIGNAL`), lesson graphs (`LEARNED`, `APPLIES_TO`, `RELATED_TO`, `CONTAINS_LESSON`), working memory (`LOADED`, `REROUTED_FROM`), anomaly detection (`ANOMALY_DETECTED`), and session provenance (`USED`, `IN_WORKSPACE`, `WORKING_ON`, `SENT_IN`).

**What it does:** Expands `_TRAVERSABLE_RELS` to include all relationship types defined in `schema.py`, making the full graph traversable.

**Depends on:** None

**Files to modify:**
- `mcp_engine/tools/explore_graph.py` — expand `_TRAVERSABLE_RELS`
- `docs/tool-catalog.md` — update explore_graph edge type list if documented

**Adapter allow-list propagation check:** No tool changes — N/A.

**Acceptance Criteria:**
- `_TRAVERSABLE_RELS` includes all relationship types from `schema.py`
- `explore_graph` can traverse Plan→PlanStep→Concept chains
- `explore_graph` can traverse Session→Lesson chains
- `pytest tests/ -k explore_graph -q` passes
- Count of `_TRAVERSABLE_RELS` entries ≥ 30

**Outcome:** `explore_graph` can traverse the entire knowledge graph, including plan chains, lesson networks, and session context.
