### Implementation (2026-08-04)

**Token budget by agent context window:** the audit noted "no defined per-agent window table anywhere in the repo to wire up" — but each adapter (`adapters/*/adapter.py`, from B18) already declares its own `_TOKEN_LIMIT` constant (`claude_code`/`codex`/`chatgpt_desktop`: 128000, `claude_desktop`: 200000, `gemini_cli`: 1000000) and sends it to the daemon as `token_limit` on every turn. `campy/brain/` can't import from `adapters/` (adapters wrap campy, not the reverse — see `docs/ecosystem-rules.md`), so `memory_decision.py` gained its own `_CLIENT_CONTEXT_WINDOWS` dict mirroring those same values (documented as needing to stay in sync if an adapter's constant changes), plus `_token_budget_for_client()`: a quarter of the client's window, capped at 128000 (so `gemini_cli`'s 1M-token window doesn't produce a quarter-million-token bundle recommendation), falling back to the original hardcoded 32000 when `client_name` is absent or unrecognized — existing callers see unchanged behavior. Client-name matching is case/separator-insensitive (`claude-desktop`, `Claude_Desktop`, and `claude_desktop` all resolve the same way), since the function's own docstring example uses a hyphenated form that doesn't match the adapter directory's underscored name.

**Layer 2 onboarding prompt:** before adding a `compile_context` mention, verified it's actually reachable from an OpenClaw session rather than assuming — `extensions/hippocampy/src/index.ts` registers `compile_context` directly by its real tool name (not just via the `memory_*` alias tools `_OPENCLAW_MEMORY_TOOLS` tracks elsewhere in this codebase, which are a narrower convenience-alias set, not the full allowlist). Added a `compile_context` line to `LAYER_2_ONBOARDING` in `adapters/openclaw_gateway.py`, explaining when to prefer it over `memory_recall`.

**Verification:** TDD. `tests/test_memory_decision.py` gained 7 new tests (default/unknown-client fallback, per-client scaling, the `gemini_cli` cap, case/separator-insensitive matching, always-positive-int invariant) — written first, watched fail against the hardcoded-32000 baseline, then implemented. `tests/test_openclaw_system_prompt.py` gained 1 new test asserting `compile_context` appears in the onboarding prompt, same TDD sequence. `tests/test_memory_decision.py`: 44/44 passed. Broader check (`-k "memory_decision or openclaw"`): 82 passed.
