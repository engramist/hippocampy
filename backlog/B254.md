# B254 - Memory Router Skill (Agent-Side Guidance)

State: ready
Priority: P2

Plan: backlog/plans/B-253-memory-router-skill.md

### Problem

`memory_decision` currently recommends which single tool to call. With the bundle compiler (252), agents should know when to request a compiled bundle vs. individual tools. The agent-side skill and onboarding prompts need updating to reflect the new memory capabilities.

### What This Card Does

Upgrades `memory_decision` to be bundle-aware and updates the agent-facing skill documentation and onboarding prompts to teach agents how to use `compile_context` effectively.

### Dependencies

- B252 complete (Bundle Compiler)
- B253 complete (Agent Output Formatters)

### Design Decisions

| Decision | Choice | Rationale |
|---|---|---|
| `memory_decision` upgrade | Add `compile_context` as a recommended_tool option | Transparent routing to the new capability |
| Skill location | Update existing `skills/campy-memory/SKILL.md` | Single canonical memory skill |
| Onboarding update | Add `compile_context` to Layer 2 prompt | Agents learn about bundles on first session |
