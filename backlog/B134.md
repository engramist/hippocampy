# B134: Gate Unconditional `current_truth` Recall — Fires 15× Per Run With Zero Results

**Status**: Ready  
**Assigned**: TBD  
**Depends on**: None  
**Complexity**: Small (< 1 hour)  
**Priority**: P1 (HIGH — wastes ~95ms × 15 steps = ~1.4s per run; adds noise to trace; returns nothing)  
**Plan**: backlog/plans/B-134-gate-unconditional-recall.md

## Problem Statement

`agents/arc3/runner.py` unconditionally calls `current_truth("What did I learn from similar puzzles?")` after **every single action** at every step, regardless of context:

```python
# runner.py line ~212
recall_query = "What did I learn from similar puzzles?"
await adapter.ingest_step(..., recall_query=recall_query)
```

This fires 15 times per run, returns 0 results every time (because there are no prior lessons stored yet), and wastes ~95ms per call.

Evidence from `master_timeline.json`:
```
×15  event: current_truth  query="What did I learn from similar puzzles?"  results=0
     elapsed_ms: ~95ms each
```

This is a mechanical check with no gating condition that was presumably intended to only fire when context warranted it (e.g. first step, loop detected, no progress streak).

## What This Card Builds

1. Replaces the unconditional recall with a **conditional gate** — fires only when one of the following is true:
   - `step == 0` (first step of the run — always worth checking)
   - `self._consecutive_no_progress_steps >= 2` (agent is stuck)
   - `self._hypothesis_context.get("loop_detected") is True`
2. Adds a trace event `recall_skipped` with reason when skipped, so the trace still shows decision was made.
3. Reduces per-run trace noise from 15 recall events to 1–3 in happy path.

## Files to Create/Modify

## Acceptance Criteria

- [ ] A 15-step run produces at most 3 `current_truth` events for this query (step 0 + up to 2 for stuck detection)
- [ ] `recall_skipped` event appears in trace when gate conditions are not met
- [ ] When `loop_detected=True`, recall fires on that step
- [ ] `pytest -q tests/` passes with no regressions

## Outcome Statement

After this card, episodic recall is selective and purposeful. Trace noise is reduced significantly, and per-run runtime improves by ~1–2 seconds. The pattern serves as a model for other unconditional brain calls in the codebase.
