# B540: objects of Observations captured as typed entities with a kind

**Status:** Open. Design phase (edge, rule, query result on store copies) before any code.

**Principles:** P8 (the answer needs a subject -> relation -> typed object edge that capture does not write; fix capture first), P2 (list and count questions then become a query anchored on the subject), P3 (rules decide the entity and its kind; a model may propose, never write), P7 (flag, one lever).

**Lever and target.** The L3 replay screen (scratch, 2026-10-27) found that the subject-anchored kind query (Observation -> subject, Observation -> object entity, entity -INSTANCE_OF/BROADER*-> question kind, Observation -> evidence turn) reaches only 5 of the 130 missing gold turns behind the 42 design set-valued retrieval failures (9 of 183 on unseen conversations). The subject edge is present on almost every Observation of those turns; the object is free text. Example: "What books has Tim read?" has 7 gold turns; one object (`The Alchemist`) is an entity of kind `book`; `The Name of the Wind`, `A Dance with Dragons`, `Harry Potter` have no entity at all. "Which endorsement deals has John been offered?": `Nike`, `Gatorade`, `Under Armour` have no entity. The B522 roles backfill gives HAS_OBJECT on 20.6% of Observations.

Target, measured offline before a GPU gate: the number of those 130 / 183 missing gold turns the same kind query reaches (5 / 9 today), with the row "anchored, kind resolved, but the object is not an entity of that kind" (51 / 43) as the class this card must shrink. Typing precision is audited by hand on a sample.

## Scope

In: for each Observation, the object span becomes (or links to) an entity node with `INSTANCE_OF` a kind, by rule: named-entity labels, title spans, WordNet first-sense category and the existing closed set of kinds (B525/B534). The object of an Observation that is not an entity ("an endorsement deal", "book collection") is kept as an object with a kind and no name.

Out (separate cards if the design shows they matter): containment between instances (Toronto -> Canada, which needs a gazetteer, not a kind link); questions that name no kind (40 / 76 of the missing turns, a question-side problem); turns with no Observation at all (18 / 34, extraction recall).

## Depends on

The parked stack: B522 (HAS_SUBJECT / HAS_OBJECT), B525 (clean kind labels), B534 (WordNet kind links). The design states whether it builds on that stack or needs only main.
