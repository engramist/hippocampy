# B575: the former principled-profile members are the built-in defaults; the concept walk leaves the profile

**Status:** Done in this PR. Ruled 2026-11-18 by the review session under the user's delegation.

**Principles:** P7 (no third state: a gated switch goes on by default or is deleted), P6 (two measurements agree before acting), P8 and P2 (the members write and read the subject-anchored edges).

**Why.** The whole `principled` profile was gated against `main` twice on the 809 and tied both times: step 0c +0.7 points (432 against 426), step 4 +0.2 points (438 against 436). So there is no score case for or against its members, and the principles decide. The capture members write the edges the graph needs (HAS_SUBJECT/HAS_OBJECT, MENTIONS from entity admission, SPOKEN_BY, INSTANCE_OF); graph_count and graph_vote answer and select by subject-anchored queries; question_analysis feeds them.

**Cost check (from step 4's own records):** principled capture took 1.03 times main's time (312 against 303 minutes over five conversations), and its stores are 1.06 times main's size (133 against 125 MB). The ruling's limits were 1.5 and 2.

**What changed.**
- On by default (14): loop entity_admission, entity_standing, tracker_side_branch, spoken_by; observations object_roles, ownership_rule, kind_hygiene, wordnet_kinds, vocab_steward, typed_objects, evidence_entity_links; retrieval graph_count, question_analysis, graph_vote. Each keeps its env var to turn it off.
- Deleted from the profile: graph_linking_limit 12 (the concept walk). Step 4's principled arm ran with the walk off, and the walk lost alone (R95, 7 gained / 14 lost). Its default stays 0; the walk code is removed under B576.
- Both profiles are now the empty table (the same config). The name `principled` stays so recorded runs and scripts that set it still load.
- The packaged template leaves the 14 keys unset (commented), so a copied template never pins them.
- `campy status` reports the 14 flags and the walk limit, and marks any of them the user's file sets as "file".

**Score effect:** none expected on the 809 (two ties).
