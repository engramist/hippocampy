# B225 - ARC Artifact Ingestion Into Graph Memory

State: complete
Priority: P0

Plan: backlog/plans/B-225-arc-artifact-ingestion-into-graph-memory.md

### Problem

ARC live-smoke and benchmark runs produce valuable raw artifacts in the sibling `ARC_AGI` repository, including execution traces, timelines, submission results, and live JSONL output. These files are useful, but they are not graph memory by themselves.

SideQuests architecture requires KuzuDB to remain the single source of truth for durable memory. A browsable wiki must project graph-backed knowledge, not scrape loose JSON files directly. Today, the `arc_agi` wiki persona can be empty even when ARC artifacts exist, because the artifacts have not been ingested into KuzuDB as first-class graph records.

### What This Card Does

Adds an explicit ARC artifact ingestion path that imports selected ARC run artifacts from the sibling `ARC_AGI` repository into SideQuests graph memory.

This card creates graph-backed ARC run/event/metric records that can later be projected into the Obsidian wiki by persona filters. The importer is intentionally one-way: ARC artifacts are source evidence, KuzuDB is the durable memory store, and generated Markdown remains read-only projection.

### Acceptance Criteria

- [ ] Importer reads `master_timeline.json`, `agent_execution_trace.json`, `submission_results_arcServer.json`, `submission_results_single.json`, and `submission_results_single.live.jsonl` when present.
- [ ] Importer accepts an explicit `artifact_root` path and defaults to the sibling `../ARC_AGI` only when that path exists.
- [ ] Importer never creates or uses non-canonical Kuzu DB paths under `~/.sidequests`; all writes go through the active SideQuests DB/tool path.
- [ ] Importer creates stable graph records keyed by content hash, run ID, task ID, timestamp, and artifact path where available.
- [ ] Re-running ingestion is idempotent: the same artifact content does not create duplicate run/event records.
- [ ] ARC records include domain tags compatible with the existing `arc_agi` persona: `arc`, `arc_agi`, `benchmark`, `evaluation`, `puzzle`, and `agent-learning`.
- [ ] Imported records preserve provenance: source file path, source artifact kind, source timestamp if present, and ingestion timestamp.
- [ ] Importer summarizes large artifacts instead of storing unbounded raw JSON blobs as page-ready text.
- [ ] Importer records enough structured facts for wiki pages: run status, puzzle/task IDs, solve outcome, step counts, trajectory summary, SideQuests tool calls, warnings/errors, and notable learned action effects when available.
- [ ] The `arc_agi` wiki persona produces at least one run summary page after ingesting a fixture ARC artifact set.
- [ ] Generated wiki pages link back to source graph IDs and artifact provenance, not directly to mutable raw JSON as the authoritative source.
- [ ] Missing artifact files are skipped with warnings, not fatal errors.
- [ ] Malformed JSON/JSONL records are reported in the ingestion summary and do not abort the entire batch.
- [ ] Existing wiki drift guard behavior remains unchanged.
- [ ] Docs clearly state that raw ARC files are evidence inputs, KuzuDB is authoritative memory, and Obsidian is read-only projection.
