# B403 - Sweep queries reference wrong PK for GlobalConstraint, GlobalPreference, Requirement

State: done
Priority: P1
Branch: claude/reverent-yonath-785d6a

### Problem

Three per-entity sweep query blocks in
`campy/brain/hippocampus/graph/queries/sweep.py` referenced primary-key
property names that do not match the declarations in
`campy/brain/hippocampus/schema.py`:

| Node label | Query used | Schema declares |
|---|---|---|
| `GlobalConstraint` | `n.constraint_id` | `n.global_constraint_id` |
| `GlobalPreference` | `n.pref_id` | `n.global_preference_id` |
| `Requirement` | `n.req_id` | `n.requirement_id` |

Affected queries (× 3 entities = 12): `get_active_pathway_*`,
`unwind_archive_*`, `resurrect_active_embeddings_*`, `resurrect_node_*`.
(`decay_pathway_*` and `index_hygiene_*` referenced only real columns
and were unaffected.)

Kùzu 0.11.3 raises `Binder exception: Cannot find property X for n.` at
bind time on such references — even against an empty table — so this is
not a silent no-op at the DB layer. The reason the bug hid: the broad
`except Exception: errors += 1` block in
`campy/brain/brainstem/sweep.py::_decay_and_archive` (and the
symmetric one in `_resurrect_archived`) swallowed the RuntimeError and
counted it as a plain error. Operationally the effect was that decay
kept running (the decay query only touches real columns) but archive
candidacy and resurrection never advanced for these three tables.

Unit tests didn't catch it because `tests/test_sweep*.py` runs against
a `MockDB` that never binds the Cypher.

### Discovered during

B392 (SPARQL translation of `sweep.py`, PR #170) — the SPARQL rewrite
deliberately preserved the mismatch for bug-for-bug parity. This fix is
independent of and does not block B392; B392's SPARQL side will be
brought back into line separately.

### Scope

- Fix the 12 property references in `sweep.py` NamedQuery Cypher strings.
- Leave the base `Constraint` table alone (its PK really is
  `constraint_id`, per schema line 233).
- Add a real-Kùzu bind regression test (`tests/test_sweep_query_bind.py`)
  covering all four sweep-eligible constraint/preference/requirement
  tables; skipped when kuzu is not importable.

### Verification

- `pytest tests/test_sweep.py tests/test_sweep_batching.py
  tests/test_sweep_patterns.py tests/test_sweep_query_bind.py` → 61 passed.
- Reintroducing the bug reproduces the failure in the new bind test
  (confirmed by temporarily reverting one substitution and rerunning).
