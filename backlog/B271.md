# B271 - Deprecate plugin_installer.py and Legacy Adapter Setup Scripts

State: ready
Priority: P2

Plan: backlog/plans/B-271-deprecate-legacy-installer.md

### Problem

After B270, `campy setup` delegates to native plugin install commands. The old `campy install-plugin` command (backed by `plugin_installer.py`) and the per-platform `adapters/*/setup.py` scripts are now redundant. They scatter-copy files manually, which is the approach we're replacing.

### What This Card Does

1. Marks `campy install-plugin` as deprecated with a message pointing to `campy setup`.
2. Removes the old per-platform hook files from `adapters/` (they've been replaced by `plugin/hooks/`).
3. Cleans up dead code.

### Dependencies

- B270 (native plugin install must be working and verified)

### Files to Modify

1. **`campy/cli/main.py`** — Find the `install-plugin` command and add deprecation:
   ```python
   @app.command(name="install-plugin")
   def install_plugin_cmd(...):
       """[DEPRECATED] Install plugin for AI agents. Use 'campy setup' instead."""
       console.print("[yellow]⚠ install-plugin is deprecated. Use 'campy setup' instead.[/yellow]")
       console.print("[dim]Running legacy installer for compatibility...[/dim]")
       # ... existing code ...
   ```

2. **`campy/cli/plugin_installer.py`** — Add deprecation warning at module level:
   ```python
   import warnings
   warnings.warn(
       "campy.cli.plugin_installer is deprecated. Use 'campy setup' which delegates to native plugin installers.",
       DeprecationWarning,
       stacklevel=2,
   )
   ```

### Files to Remove

After verifying B270 works end-to-end, remove these files that are replaced by `plugin/hooks/`:

- `adapters/codex/hooks/__init__.py`
- `adapters/codex/hooks/session_start.py`
- `adapters/codex/hooks/pre_tool_use.py`
- `adapters/codex/hooks/post_tool_use.py`
- `adapters/codex/hooks/user_prompt.py`
- `adapters/codex/setup.py`
- `adapters/gemini_cli/hooks/__init__.py`
- `adapters/gemini_cli/hooks/session_start.py`
- `adapters/gemini_cli/hooks/before_tool.py`
- `adapters/gemini_cli/hooks/after_tool.py`
- `adapters/gemini_cli/setup.py`

Do NOT remove `adapters/claude_code/hooks/` or `adapters/claude_code/setup.py` until verified that the plugin hooks.json fully replaces them.

### Acceptance Criteria

- [ ] `campy install-plugin` prints deprecation warning before running
- [ ] `campy setup` still works (primary path unaffected)
- [ ] Old adapter hook files removed from `adapters/codex/hooks/` and `adapters/gemini_cli/hooks/`
- [ ] Old setup.py files removed from `adapters/codex/` and `adapters/gemini_cli/`
- [ ] No imports of removed files remain: `rg "adapters.codex.setup|adapters.gemini_cli.setup" --type py`

### Validation Commands

```bash
# Check deprecation warning
campy install-plugin --help 2>&1 | grep -i deprecated

# Verify removed files are gone
ls adapters/codex/hooks/ 2>/dev/null && echo "FAIL" || echo "PASS"
ls adapters/codex/setup.py 2>/dev/null && echo "FAIL" || echo "PASS"
ls adapters/gemini_cli/hooks/ 2>/dev/null && echo "FAIL" || echo "PASS"
ls adapters/gemini_cli/setup.py 2>/dev/null && echo "FAIL" || echo "PASS"

# Verify no stale imports
rg "from adapters.codex.setup|from adapters.gemini_cli.setup" --type py

# Run tests
pytest tests/ -q --ignore=tests/benchmarks
```

### Outcome

Legacy install paths are deprecated with clear migration guidance. Dead adapter hook/setup files are removed.
