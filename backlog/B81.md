### B81 · Verify OpenClaw 31 Tool Aliases vs 17 Tool Handlers

**Problem:** The TypeScript OpenClaw extension (`extensions/hippocampy/src/index.ts`) registers ~31 tools (including aliases like `memory_recall` → `current_truth`). `TOOL_HANDLERS` only has 19 entries. Unmapped aliases return errors from the Brain Daemon.

**What it does:** Audits all registered aliases in the OpenClaw extension, verifies each maps to a valid `TOOL_HANDLERS` key, and removes or comments out invalid aliases.

**Depends on:** None

**Files to modify:**
- `extensions/hippocampy/src/index.ts` — remove unmapped aliases or add backend mapping
- `docs/tool-catalog.md` — update OpenClaw alias mapping table if present

**Adapter allow-list propagation check:** No tool changes — N/A. (But alias-to-handler mapping is the equivalent concern for OpenClaw.)

**Acceptance Criteria:**
- Every tool alias in `index.ts` maps to a valid key in `TOOL_HANDLERS`
- Invalid/orphan aliases are removed or commented out with explanation
- Test verifying all aliases resolve to valid handlers passes
- `npm run build` (or TypeScript compile) passes for the extension

**Outcome:** OpenClaw extension only exposes tools that the Brain Daemon can actually handle.
