# B497: Principles load into every agent's context, not behind a pointer

**Status:** complete (2026-10-20) · **Found:** 2026-10-20 (owner review of B495)

## Problem

B495 put the principles in `AGENTS.md` and left one line in `CLAUDE.md`, `GEMINI.md`
and the Copilot instructions telling agents to go read them. Claude Code loads
`CLAUDE.md` automatically, not `AGENTS.md`, so the principles reached a Claude session
only if the agent chose to follow the pointer — the "rule in a file the agent doesn't
read" failure the principles were meant to prevent.

## Fix

- `PRINCIPLES.md` is the single source.
- `CLAUDE.md` and `GEMINI.md` import it at the top (`@PRINCIPLES.md`), so the full
  text is in context every session.
- `AGENTS.md` (Codex) and `.github/copilot-instructions.md` (Copilot) cannot import,
  so they carry verbatim copies between `principles:begin/end` markers.
- `tests/test_principles_in_sync.py` fails if a copy drifts from the source or an
  import is missing.
