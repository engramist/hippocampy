# B529: every bundle section is described to the answer model

**Status:** Open

The first project once found its judge packages defined only 6 of the 8 classes the answer allowed. Its context check passed every time, because the check covered only the blocks it had already been burned by. Our equivalent: `ask._bundle_to_prompt` prints a one-line description per section, keyed by section source. A section that `bundle_compiler` can emit without a matching description reaches the model unexplained.

**Work:** a unit test that enumerates every section source `compile_bundle` can emit (from code, not a hand list) and fails if `ask.py` has no non-empty description for it. A reviewer rule goes into skills/campy-graph: before merging a retrieval or answering change, open one real rendered prompt on a store copy and read what the model sees.
