# B428 - Narrow `requires-python` to 3.12-Only — 3.13 Was a False Advertised Claim

State: fixed (this PR)
Priority: P3
Branch: fix/b428-python-version-honesty

### Problem

`pyproject.toml` claimed `requires-python = ">=3.12,<3.14"` and listed both 3.12 and 3.13
PyPI classifiers, but the 2026-09-11 re-vet found the project "effectively 3.12 only."
Verified precisely against PyPI's actual wheel listings (not just trusting the re-vet's
prose):

- `tree-sitter-languages` (used by `campy/brain/thalamus/compression/ast_mapper.py` for
  AST-aware code compression) ships **zero `cp313` wheels for any version**, including
  its maintained successor `tree-sitter-language-pack` (also zero cp313 wheels as of this
  writing).
- **Correction to the re-vet's implication:** `spacy` is *not* the blocker — `spacy>=3.8.16`
  ships `cp313` wheels. Only `tree-sitter-languages` blocks 3.13.

### Fix

- `requires-python` narrowed to `>=3.12,<3.13`; dropped the `Programming Language :: Python
  :: 3.13` classifier. Comment on the pin explains the precise blocker and the condition
  that would re-widen it (a cp313 wheel for `tree-sitter-languages` or its replacement).
- README's "Requirements" section corrected to name the actual blocker (was vaguer:
  "some pinned dependencies do not yet ship 3.13 wheels").

### Provenance

Follow-up from the 2026-09-11 external re-vet's "Python support effectively 3.12 only"
finding, verified independently against PyPI before acting on it.
