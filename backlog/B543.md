# B543: the original decision tracker becomes a deprecated side branch

**Status:** Open. Lands with or after B542.

**Principles:** P8 (what is stored is decided by the entity rule, not by whether a turn sounds like a decision), P7.

**What.** Loop steps 2 to 7 (`temporal_lobe/loop/orchestrator.py`: the gist centroids, schema.org routing, the decision / constraint / requirement / action-item gate, arbitration and pathway) were built to track developers' decisions. They now gate whether any entity of a turn is stored. With B542's lane on, they only add Decision, Constraint, Lesson and Procedure records on top of entities that are already stored; they never remove or withhold one. Marked deprecated in code and in `docs/ARCHITECTURE.md`, kept working for the personal developer store (Layer 2 triggers read Lessons and Procedures). Removal is a later decision, not this card.
