### B70 · Add 4 Missing Tools to ALL Adapter Pass-Through Lists

**Problem:** Four tools defined in `tool_schemas.TOOLS` and dispatched by `TOOL_HANDLERS` are missing from ALL 5 adapter pass-through allow-lists: `upsert_lesson`, `recall_relevant_lessons`, `get_anomalies`, `get_openclaw_prompt`. Any agent call to these tools returns `{"error": {"code": -32601, "message": "Unknown tool: ..."}}`.

**Root cause:** B11/B12/B21 tools were added to `tool_schemas.py` and `TOOL_HANDLERS` but never propagated to adapter allow-lists.

**What it does:** Adds all 4 missing tool names to the `if tool_name in (...)` tuple in each of the 5 adapter files.
