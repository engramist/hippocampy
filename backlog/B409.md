# B409 - Explicit Status Writes: Timeless/Status Split and the Cheap Filter Form

State: ready
Priority: P1
Branch: feat/b409-explicit-status-writes

Design: docs/rdf-schema-mapping.md §3.4a, §3.4b, §4.2e

### Problem

Three separate issues turn out to have one fix.

**1. The `OPTIONAL + !BOUND` filter costs ~2x, and the spec mandated it everywhere.**

Measured against `pyoxigraph 0.5.11`, 148k-triple store:

| Query | Rows | Time |
|---|---|---|
| no status filter | 39,999 | 36.9 ms |
| `?n campy:archived false` (plain BGP) | 20,000 | **36.9 ms** |
| `OPTIONAL {…} FILTER(!BOUND(…) ‖ …=false)` | 32,000 | **52.7 ms** |

Consistent ~2x penalty across 1–3 hops. Notably, at 3 hops the plain filter (61.4 ms)
beats *no filter* (69.3 ms) — filtering shrinks the intermediate set and pays for
itself. `performance-and-debugging.md` flags "wide OPTIONAL sections" as a SPARQL red
flag; spec §3.4 wrote one into ~600 translated queries.

**2. OWL entailment is monotonic; unset status makes it unsound.** A property that is
sometimes absent cannot be reasoned over safely — and asserting mutable class
membership (`:c1 a :ActiveConstraint`) makes stale entailments immortal.

**3. Superseded-belief history is valuable on its own.** For provenance, for debugging
*"why did the agent believe X?"*, and for the patent record.

The `OPTIONAL` form buys exactly one thing: matching "false **or unset**". If status
is always explicitly written, "unset" cannot occur, and all three issues resolve.

### Scope

1. **Backfill explicit status on all existing nodes** — `archived` written explicitly
   everywhere it can currently be absent. **This must land and be verified before any
   query converts.**
2. **Make writers always set status.** No conditional status writes; absence stops
   being representable.
3. **Convert queries to the plain BGP form** where the property is now guaranteed
   written. Mechanical across the ~600 already-translated queries, and the same shape
   the B391–B396 agents handled well.
4. **Adopt the §4.2e timeless/status split**: class membership never encodes mutable
   state; supersession expressed with PROV-O (`prov:wasRevisionOf`,
   `prov:invalidatedAtTime`, `prov:wasAttributedTo`).

### The hazard — ordering is not negotiable

Converting a query to the plain form **before** the backfill **silently drops every
row where the property was never written.** No error, no failing test — just missing
results. Same class as B404, which silently disabled decay for three node types for
an unknown length of time.

**Backfill → verify → convert.** Never the other way. A test must prove row-count
parity between the two filter forms on real data *before* any conversion lands.

### Explicitly NOT in scope

- Do not decide the OWL question — that is B407. This card makes OWL *possible*; it
  does not argue it is *needed*.
- Do not delete history. Cold facts may move to a separate named graph; they are not
  removed.

### Acceptance Criteria

- [ ] Backfill complete; zero nodes with absent status where a filter depends on it.
- [ ] Row-count parity proven between `OPTIONAL` and plain forms on real data, per
      query family, **before** conversion.
- [ ] Writers guarantee explicit status; a test proves absence is unrepresentable.
- [ ] Converted queries measured — expect ≈2x improvement on filtered traversals.
- [ ] Spec §3.4a's conditional rule reflected in the converted queries: plain form
      where guaranteed, `OPTIONAL` retained only where absence is genuinely possible.
- [ ] Supersession expressed in PROV-O terms per §4.2e.
- [ ] No mutable class membership asserted (`:x a :ActiveConstraint` and similar).

### Related

- **B406** — schema conformance guard. Omitting a status filter still returns
  superseded facts; correctness dependence survives even though the cost concern did not.
- **B407** — inference pilot. This card removes the monotonicity blocker; it does not
  settle whether OWL is wanted.
- **B404** — the precedent for how silently a missing/mismatched filter fails.

### Outcome

One discipline — always write status explicitly — buys a ~2x cheaper filter, a
monotonic graph that OWL could reason over soundly, and a standards-based audit trail
of superseded beliefs.
