# B416 - Detect Local Environment Drift From Declared Dependencies

State: ready
Priority: P1

### Problem

The development venv in this checkout carries packages that are **not declared
anywhere** in `pyproject.toml`:

```
declared dependencies : 35
installed packages    : 199
undeclared contaminants present: sentence-transformers, torch, transformers
```

`torch` arrives via `sentence-transformers`, which **B355 removed** when fastembed
replaced it. It has lingered ever since, and `thinc.compat` opportunistically imports
`torch` whenever it is importable — so it loads, and costs ~150–225 MB, in an
environment where production has neither.

This has now produced a wrong number **three separate times**:

1. My warm-RSS figures (541.0 / 818.6 MB) — overstated production by ~223 MB, and
   propagated into `ARCHITECTURE.md`'s Open Research Questions section before being
   corrected.
2. B400's investigation, which correctly identified the cause but noted it **cannot be
   fixed from a PR** — `.venv` is not tracked.
3. The post-cutover baseline attempt, which first read 744.8 MB before `torch` was
   blocked, versus 588.5 MB clean.

Each time it was caught only because someone thought to check `sys.modules`. Nothing
makes it visible by default.

### Why a guard rather than a one-time rebuild

Rebuilding the venv fixes today and nothing else. The next stale transitive dependency
reproduces the failure, and the failure mode is silent: measurements simply diverge
from production by an invisible margin.

CI is unaffected — it installs clean from `requirements.txt` — so this is specifically
a **local development** hazard, which is exactly where measurement happens.

### Scope

1. **`scripts/check_env_drift.py`** — compare installed packages against the closure of
   what `pyproject.toml` declares. Report undeclared top-level packages, flagging the
   known-harmful set (`torch`, `sentence-transformers`, `transformers`) explicitly.
   Distinguish *undeclared* from *transitive-but-legitimate*; a naive diff would flag
   all 164 non-declared packages and be useless.
2. **A rebuild path** — `make rebuild-venv` or documented equivalent:
   ```
   rm -rf .venv && python3.12 -m venv .venv \
     && .venv/bin/pip install -r requirements.txt \
     && .venv/bin/pip install -e ".[test]"
   ```
3. **Wire the check into the measurement path**, not CI: B415's `kpi_monitor.py` should
   refuse to produce a baseline from a drifted environment.

### Explicitly NOT in scope

- Do not add this to the CI gate. CI installs clean; adding it there guards nothing and
  adds a failure surface.

### Acceptance Criteria

- [ ] Guard detects the three current contaminants and does **not** flag legitimate
      transitive dependencies (demonstrate both).
- [ ] Rebuild path documented and verified to produce a `torch`-free environment.
- [ ] Post-rebuild warm RSS measured and reported; expect ≈588 MB, versus 744.8 MB
      contaminated.
- [ ] B415's monitor refuses to emit a baseline when drift is detected.

### Related

- **B400** — identified the cause; explicitly could not fix it from a PR.
- **B415** — the measurement half. This card is the enforcement half.

### Outcome

An environment that diverges from production announces itself, instead of being
discovered three measurements later.
