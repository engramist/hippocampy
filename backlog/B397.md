### Scope

1. **Gateway dispatch.** `GraphGateway.run()` selects `query.sparql` +
   `OxigraphClient` or `query.cypher` + `KuzuClient` by configured engine. Call sites
   do not change — B386 made that possible and B391–B396 preserved it.
2. **Vector/FTS wiring.** Route the Python-handler queries (spec §5) through
   `vector_store.py` from B390: ANN/FTS → `[(uri, score)]` → Oxigraph hydration via
   `VALUES ?s {...}` → join in Python preserving rank order.
3. **Data migration.** Extend `campy export-graph` / `campy import-graph` (B281) to
   load legacy Kùzu JSONL dumps into Oxigraph + sqlite-vec under the mapping spec.
4. **Ratchet allowlist.** `scripts/check_cypher_ratchet.py`: swap `kuzu_client.py`
   → `oxigraph_client.py` in `ALLOWLIST_FILES`, and review `CYPHER_LINE_RE`
   (`MATCH|CREATE|MERGE`) — **`CREATE` is also valid SPARQL 1.1 Update** and will
   false-positive against the new client. This breaks CI at exactly this step if
   missed.
5. **Remove `kuzu`** from `pyproject.toml` and `requirements.txt`; delete
   `kuzu_client.py`.

### Round-trip migration test — the acceptance gate

Per spec §8: **Kùzu → JSONL → Oxigraph → JSONL must be set-equal** on nodes, edges,
and edge properties. `STRING[]` ordering differences are permitted (spec §3.3);
nothing else is. Run this against a real, populated graph — not a synthetic fixture.

A migration that loses one `occurrence` row loses audit history that cannot be
reconstructed. Prove the round trip before removing Kùzu, not after.

### Dual-engine patent re-certification

The `tests/patent_claims/` suite (B380) must pass against Oxigraph through
`gateway.py`, **unchanged**.

Per spec §8: any claim test requiring modification indicates a **mapping defect, not
a test defect**. Escalate — do not edit the assertion. This suite is legal evidence
for the March 2027 non-provisional filing; the whole point of running it on both
engines is that the same assertions hold on both.

Regenerate `docs/patent-evidence-pack.md` with dual-engine traces.

### Footprint certification

Certify daemon idle RSS on macOS (`vmmap -summary`) and Linux

and Oxigraph is expected to be comparable. **Do not claim this card delivers the
<80 MB target** — B387 did. Report the honest before/after delta whatever it shows;
if Oxigraph costs *more* than Kùzu, say so plainly.
