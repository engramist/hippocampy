# B545: the principled profile: one switch for the assembled pipeline

**Status:** Open.

**Principles:** P1 (the assembled pipeline is what gets gated), P7 (each part keeps its own flag; the profile only names a set of them).

**What.** `docs/pipeline-map.md` lists the parts that follow the principles. A profile, `[pipeline] profile = "principled"` with env `CAMPY_PROFILE=principled`, turns on exactly those flags and demotes the legacy parts; an explicit per-flag setting or env var still wins. Default stays `main` (today's defaults). `campy status` prints the active profile and the resolved flags, and every benchmark result records them in its provenance, so a gate says exactly what ran (P6).

**Members today:** `entity_admission` (B544), roles (B522), ownership (B523), count and list (B524), kind hygiene and hierarchy (B525, B534, B535), the concept walk with a non-zero `graph_linking_limit`, and the gap cards B546-B548 as they land. Demoted: the decision tracker as a side branch (B543), the old semantic fallback stage.

**Gate.** None for this card (switching mechanism only); the profile itself is gated as a whole against main once its members are offline-checked (fresh ingest, unseen LoCoMo, plus a breakdown of each miss by the stage where it died).
