# B286 - Consolidate Node Table Registry

State: complete -- verified via git log 2026-08-02 (feat: B279-B287 graph hardening 89cacc9/b6d1a09); card file was stale

Plan: backlog/plans/B-286-node-table-registry.md

### Problem

The `(table, pk_column, vector_index)` metadata for the graph's node tables is hand-maintained in at least five places, and they have already drifted:

- `hippocampus/schema.py` — `NODE_TABLES` DDL (source of truth, but stringly-typed)
- `brainstem/sweep.py` — `SWEEP_TABLES` (9 tables, includes index names)
- `thalamus/tools/explore_graph.py` — `_NODE_TABLES` (12 tables, includes Lesson + Document + quests)
- `temporal_lobe/warm_frontier.py` — `NODE_PK_MAP` (7 tables)
- `thalamus/tools/__init__.py` — `artifact_tables` lists inside `current_truth` and other tools (10 tables)

Adding a new artifact-bearing node table requires updating all five; missing one produces silent gaps (the new table is invisible to retrieval, traversal, or decay). Relationship types already solved this with `get_relationship_types()` derived from REL_TABLES (B72) — node tables need the same treatment.

### What This Card Does

Creates a single registry in `campy/brain/hippocampus/table_registry.py` derived from the schema DDL, exporting typed metadata per table (name, pk column, vector index name, has_embedding, capability tags like `sweepable`, `retrievable`, `traversable`). All five consumer sites import from it.

### Acceptance Criteria

- [ ] Registry is derived from `schema.py`'s `NODE_TABLES` dict (parses PK from DDL) — not a third hand-written list
- [ ] Each entry: `TableInfo(name, pk, vector_index, has_embedding, tags)` (dataclass or NamedTuple)
- [ ] A consistency test fails if a table in NODE_TABLES with an `embedding` column lacks a registry entry with `has_embedding=True`
- [ ] All five consumer sites import from the registry; their previous behavior is preserved exactly (same table sets — encode current membership as explicit tags, e.g. Lesson is `traversable` but not `sweepable`)
- [ ] Grep proves no orphaned hand-written lists remain: `rg "concept_emb_idx" campy/brain --include='*.py'` hits only the registry and schema

### Outcome

Adding a node table is a one-place change; retrieval/traversal/decay coverage can no longer silently drift.
