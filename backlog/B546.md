# B546: the object of a fact is a typed entity

**Status:** Implemented behind `[observations] typed_objects` (env `CAMPY_TYPED_OBJECTS`, default off; member of the principled profile, B545). Offline check done on a fresh copy of the R104 store (below). Judged only inside the profile gate (B545), not alone.

**Principles:** P8, P3, P2.

**Why.** About 6% of Observations have a typed object entity; the subject-anchored kind query reaches 5 of 130 missing evidence turns (L3). B540 and B542 tried rule typing and a model reader in isolation on today's pipeline; with B544 admitting every named entity, the object of a fact can link to an existing entity, and its kind can come from rules that measured precise: a kind stated in the sentence ("brands like Nike", "a novel called X", "It's a fantasy novel"), WordNet places, and the head noun of a noun-phrase object. The model's kind stays a candidate (P3).

**Measure (offline):** Observations with a typed object entity; subject-anchored kind-query reach on the missing evidence turns; a seeded hand audit. Part of the profile (B545); judged with it.

## What it does

At Observation write time (the extractor path; `backfill_typed_objects` for an existing store, idempotent) a rule with no model call (spaCy, WordNet, the kinds the store already has) finds the object of the fact:

* **Entity object**: a Concept B544 admitted (`ner_label`, `Message -MENTIONS->`) whose text is in the quote as whole words and is the object. `HAS_OBJECT` (B522's writer, first wins) and `OBSERVATION_ABOUT`. No entity is created. Without B544 there are no admitted Concepts and only the nameless path runs.
* **Nameless object** (not for `has_attribute` / `is_a`): one `ObjectPhrase` node per Observation (a book in two facts is two nodes), `HAS_OBJECT` to it. It is not a Concept, so the word "book" still resolves to the kind.

Kind, first match wins, written as `INSTANCE_OF`: (1) stated in the sentence (Hearst, apposition, "called", copula, "It is a ..." with a thing named in the previous sentence); (2) WordNet place (tagger label GPE/LOC/FAC *and* first noun sense an instance of a city, country, state, province, continent or region); (2b) a speaker of the conversation is a `person` (a tagger label PERSON alone never is, B549); (3) the head noun of a nameless object that is a kind the store has (the closed set; never a modifier); (4) else only a candidate: the phrase keeps `kind_candidate`, an entity keeps its `ner_label`. A kind is created (by `resolve_kind`) only for a stated, place or speaker cue and never from a label a named entity already holds (B544's `can_be_kind`, repeated for stores that predate it). The model's own kind never becomes an edge.

Guards (the two incidental cards from the design screen, folded in): a sentence-initial common word that is the subject of a copula is not a name, and the referent of "It is ..." must have been written capitalised ("Nature is my haven", "It's my sanctuary" no longer type a kind); a place kind needs the tagger's place label in this very turn and is refused after an indefinite article ("a Labrador" is a dog, not a region).

Evidence span (B552, not fixed here): stored offsets that do not select the quote are not trusted. The quote is searched in the Message text (exact, then with quotation marks folded, then ignoring case); a quote that cannot be placed is skipped and counted.

## Graph design

Edges written: `Observation -OBSERVATION_ABOUT-> Concept`, `Observation -HAS_OBJECT-> Concept | ObjectPhrase`, `Concept | ObjectPhrase -INSTANCE_OF-> kind`; node `ObjectPhrase` (`phrase_id`, `text_raw`, `kind_candidate`, `rule_version`); kind Concepts and `BROADER` by `resolve_kind`. Writers: `typed_objects.link_object_phrase`, `typed_objects.link_phrase_kind`, `typed_objects.set_phrase_candidate`, plus the existing `observations.link_about_concept`, `link_object`, `set_object_id_from_role`, `kinds.link_instance_of`. NamedQueries that read it: `typed_objects.exact_role_turns` (KX: the subject's facts whose object, by `HAS_OBJECT`, is under a kind; B548 votes with this), `typed_objects.loose_role_turns` (K+), `typed_objects.phrase_kind_candidates` (what a steward may confirm). Every row carries the fact's `EVIDENCED_BY` turn.

Readers made phrase-safe (no change with the flag off, where no phrase exists): B524's count/list pattern (`?x a campy:Concept`, so "a book" twice is not two books), `observations.instantiated_kinds` (B523's ownable test), and the concept walk's second hop.
