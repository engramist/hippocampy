# B546: the object of a fact is a typed entity

**Status:** Open. Design first (edge, rule, query result on a store copy).

**Principles:** P8, P3, P2.

**Why.** About 6% of Observations have a typed object entity; the subject-anchored kind query reaches 5 of 130 missing evidence turns (L3). B540 and B542 tried rule typing and a model reader in isolation on today's pipeline; with B544 admitting every named entity, the object of a fact can link to an existing entity, and its kind can come from rules that measured precise: a kind stated in the sentence ("brands like Nike", "a novel called X", "It's a fantasy novel"), WordNet places, and the head noun of a noun-phrase object (the B542 agreeing-kind rule, kind right 83-93%). The model's kind stays a candidate (P3).

**Measure (offline):** Observations with a typed object entity; subject-anchored kind-query reach on the missing evidence turns; a seeded hand audit. Part of the profile (B545); judged with it.
