# B243 - Move Implementation Package from `sidequests` to `campy`

State: complete
Priority: P0

Plan: backlog/plans/B-243-move-implementation-package-to-campy.md

### Problem

After B242, `campy` exists only as a shim. The actual implementation folder is still `sidequests`, which keeps the repo internally tied to the old name. To finish the namespace migration, implementation code should live under `campy`, with `sidequests` reduced to a legacy compatibility shim.

### What This Card Does

Moves implementation modules from `sidequests/` to `campy/`, then replaces `sidequests/` with thin forwarding shims for one compatibility release.

### Dependencies

- B242 complete - `campy` import namespace shim exists and is tested

### Files to Create/Modify

| File | Action |
|---|---|
| `campy/**` | MODIFY/MOVE - become the implementation package |
| `sidequests/__init__.py` | REPLACE - compatibility shim forwarding to `campy` |
| `sidequests/daemon.py` | REPLACE - compatibility shim forwarding to `campy.daemon` |
