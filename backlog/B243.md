# B243 - Move Implementation Package from `sidequests` to `campy`

State: ready
Priority: P0

Plan: backlog/plans/B-243-move-implementation-package-to-campy.md

### Problem

After B242, `campy` exists only as a shim. The actual implementation folder is still `sidequests`, which keeps the repo internally tied to the old name. To finish the namespace migration, implementation code should live under `campy`, with `sidequests` reduced to a legacy compatibility shim.

### What This Card Does

Moves implementation modules from `sidequests/` to `campy/`, then replaces `sidequests/` with thin forwarding shims for one compatibility release.

### Dependencies

- B242 complete - `campy` import namespace shim exists and is tested

### Files to Create/Modify

| File | Action |
|---|---|
| `campy/**` | MODIFY/MOVE - become the implementation package |
| `sidequests/__init__.py` | REPLACE - compatibility shim forwarding to `campy` |
| `sidequests/daemon.py` | REPLACE - compatibility shim forwarding to `campy.daemon` |
| `sidequests/paths.py` | REPLACE - compatibility shim forwarding to `campy.paths` |
| `sidequests/cli/**` | REPLACE - thin forwarding modules to `campy.cli.*` |
| `sidequests/adapters/**` | REPLACE - thin forwarding modules to `campy.adapters.*` |
| `pyproject.toml` | MODIFY - scripts point to `campy.*`; legacy scripts remain |
| `tests/test_campy_namespace.py` | MODIFY - assert implementation path is `campy` |
| `tests/test_sidequests_compat_namespace.py` | CREATE - prove legacy imports still work |

### Acceptance Criteria

- [ ] Primary implementation code lives under `campy/`.
- [ ] `sidequests/` contains only compatibility shims and packaged legacy resources where explicitly required.
- [ ] `campy = "campy.cli.main:app"` and `campy-daemon = "campy.daemon:main"` are the primary entry points.
- [ ] `sidequests = "sidequests.cli.main:app"` and `sidequests-daemon = "sidequests.daemon:main"` still work.
- [ ] `python -m campy.adapters.mcp_server` works.
- [ ] `python -m sidequests.adapters.mcp_server` still works with a deprecation-safe shim.
- [ ] No durable state path changes happen in this card.

### Validation Commands

```bash
.venv/bin/python -m compileall -q campy sidequests adapters mcp_engine
.venv/bin/pytest -q tests/test_campy_namespace.py tests/test_sidequests_compat_namespace.py tests/test_adapters.py tests/test_mcp_server_adapter.py tests/test_setup_cli.py
.venv/bin/pytest -q
```

### Outcome

The repository's internal Python namespace becomes `campy`, while installed legacy clients using `sidequests` continue to function through shims.
