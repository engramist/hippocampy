# B260 - Codex, Gemini CLI, and VS Code Recall Config

### Problem

Claude Code has hooks (B259), but the other 3 active agents — Codex, Gemini CLI, and VS Code (Copilot) — each have different configuration mechanisms for injecting recall behavior. Currently these agents have MCP server registration but no recall-triggering configuration.

### What This Card Does

Configures recall behavior for each non-Claude-Code agent using their native mechanisms:
1. **Codex**: Memory skill at `~/.codex/skills/campy-memory/SKILL.md` + AGENTS.md instruction
2. **Gemini CLI**: `GEMINI.md` instruction file + MCP tool instructions
3. **VS Code (Copilot)**: `.github/copilot-instructions.md` + MCP server config

### Dependencies

- B258 complete (assertive skill content to reference)
- B255 complete (plugin must be installable)

### Design Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Codex approach | Skill file + AGENTS.md section | Codex reads `~/.codex/skills/` and project AGENTS.md |
| Gemini approach | GEMINI.md + tool description hints | Gemini CLI reads GEMINI.md for project instructions |
| VS Code approach | copilot-instructions.md + MCP config | Copilot reads `.github/copilot-instructions.md` |
| Content source | All derive from the same session-start protocol | One protocol, three delivery shapes |
