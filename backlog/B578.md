# B578: a cross-encoder reranks the conversation section's turns (flag)

**Status:** Built 2026-11-18, behind `[retrieval] turn_rerank` (off, in no profile). Its GPU gate is approved by the review session to run after this merges.

**Principles:** P1 (gated on the 809), P2 (vectors.db stays an index; nothing stored), P3 (the reader sees verbatim, source-linked turns; graph-vote turns are not overridden by a model score), P4 (ND-5's construction, no knob tuned on the 809), P5 (a retrieval change, not wording), P7 (behind a flag).

**Why.** ND-3 and ND-4 showed the missing gold turns sit in a wider vector pool but rank low on the question's vector. ND-5 (offline) reranked the control's turns plus the top 100 by vector with a small cross-encoder and cut to the section's own size. Result: 46.0% of the no-gold questions gain a gold turn, 6.9% of the all-gold questions lose one, net estimate +20.5 questions by bucket moves.

**What.**
- `campy/brain/thalamus/turn_rerank.py`: the stage. Candidates are the section's turns plus the top 100 live user Messages by vector (`thalamus.bundle_conversation_rerank_candidates`). Each is scored as "speaker: text", the section's own turn count is kept, and graph-vote turns (B548, the top GRAPH_VOTE_TOP) are pinned. Presented in the section's order.
- Called from `_stage_conversation`; a full-history section is left as it is.
- Config: `turn_rerank` (env `CAMPY_TURN_RERANK`), `turn_rerank_model`, and `turn_rerank_path` (env `CAMPY_TURN_RERANK_PATH`, a local folder). There is no download; a missing model leaves the section unchanged, with one warning.
- Reported in the profile flags (PROFILE_STAYS_ON).

**Gate.** Step 4's principled stores, both arms at one commit, flag off against on. Pass above +1.9 points on the 809; kill at 0 or below, or category-5 correct refusals down more than 5 points.

**Replace mode killed (2026-11-19).** The gate scored 51.9% against 54.1%, -2.2 points. Coverage rose, but replace mode dropped the turns next to the evidence: on questions that kept every gold turn, accuracy fell 7.1 points.

**Add mode (review session, 2026-11-19).** `turn_rerank_mode = "add"` (env `CAMPY_TURN_RERANK_MODE`; default "replace").
- Every section turn is kept. The top 5 new candidates are added, each with the section's own session window (`thalamus.bundle_conversation_seed_windows`, built on the B487 window code), placed in session order.
- Graph-vote turns stay, since nothing is dropped.
- Offline sizing ND-6: 44.4% of the "none" questions gain a gold turn; median prompt growth 41.7%; no "all" loss.
- `run_ask` now records the answer call's server token usage in `meta["answer_usage"]`, so the gate can count truncated prompts.
- Gate: pass above +1.9 points; kill at 0 or below, category-5 refusals down more than 5 points, or the "all" bucket down more than 3; more than 2% of the on arm's prompts truncated means "confounded".

**Done when:** the gate is judged and the flag is either on by default or deleted.

**Add mode killed (2026-11-19, job 1010).** 48.8% against 54.1% on the 809, -5.3 points; the "all" bucket -13.0. No prompt truncated (slot and ratio detectors 0). Refusals rose 167 to 242; 63 of the 91 lost answers are refusals. Both modes are killed; the card is closed with the flag off.

**Window mode (review session, 2026-11-19; ND-7).** `turn_rerank_mode = "window"`: the section keeps its turn count; the graph-vote turns keep their slots; then the reranked seeds, best first, each with its session window (`thalamus.bundle_conversation_window_fill`), until the count is reached, the last window cut short. ND-7 cleared offline ("none" context gain 36.9%, "all" context loss 4.2%, chars +1.1%). It is the last reranker construction: a kill closes the line. **Gate (job 1011, 2026-11-19): pass**, 56.5% against 54.1% (+2.3 points; "all" bucket -2.3, category-5 abstention -1.4, refusals 167 → 153, truncation 0). **Confirmation (job 1012, rcon stores): +2.8 points, pooled +2.6, the confirmed line met**; 682 of 809 prompts repeat 1011's, so 127 questions are new. Default flip pending the review session's ruling.
