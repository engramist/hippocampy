### Problem

`campy/brain/thalamus/tools/explore_graph.py` walks the graph in Python. `_get_neighbors()` issues one Cypher query per (node table × relationship type × direction) combination — 12 node tables × ~90 rel types × 2 directions ≈ up to 2,000+ queries per node expansion — and `_get_node_data()` adds another query per visited node. A depth-3 BFS over a modest graph can issue tens of thousands of round-trips. This is the classic "traversal in application code" anti-pattern; Kuzu supports multi-label patterns and bounded variable-length relationships server-side.

The same N+1 pattern appears in `_add_temporal_context()` (same file) and in `step5_retrieval.py`'s `_get_neighbor_set()`.

### What This Card Does

1. Rewrites `explore_graph`'s neighbor expansion to use a small number of server-side Cypher queries with variable-length bounded paths and multi-relationship patterns.
2. Keeps the existing tool contract (params and response shape) byte-compatible — callers and tests must not notice.
3. Applies the same batching to `_get_neighbor_set()` in step5.

### Dependencies

- B279 recommended first (P0) but not technically required — no shared files except minor step5 overlap.

### Files to Modify

- `campy/brain/thalamus/tools/explore_graph.py` — replace `_get_neighbors`/`_get_node_data` per-row loops
- `campy/brain/temporal_lobe/loop/step5_retrieval.py` — batch `_get_neighbor_set`
- `tests/test_explore_graph.py` (or wherever explore_graph tests live — find with `rg -l "explore_graph" tests/`) — add a query-count regression test

### Acceptance Criteria

- [ ] A single `explore_graph` call at depth 3 issues ≤ 30 Cypher queries (measured by a counting wrapper in the test), down from potentially thousands
- [ ] Response shape unchanged: `{paths: [{nodes, edges, path_depth, path_strength}], total_nodes_visited, exploration_complete, exploration_truncated, context_window}`
- [ ] Cycle prevention, depth clamp (≤5), MAX_NODES=1000 bound, and edge-type allowlist all preserved
- [ ] Existing explore_graph tests pass unchanged
- [ ] `_get_neighbor_set` in step5 issues 1 query per direction instead of 1 per (table × rel)

### Outcome

`explore_graph` becomes usable on graphs beyond toy size; the flagship multi-hop tool does its traversal where traversal belongs — in the database engine.
