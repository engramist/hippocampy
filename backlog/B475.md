# B475 - Answer Prompt: Cite or Abstain (M1.3)

State: complete (2026-10-10; R33 gate passed on dev — DMR 0.52 -> 0.60, LoCoMo-10 adversarial 0/12 -> 3/12; held-out check pending R30)
Priority: P2

Plan: `learnings/e2e-improvement-plan.md` M1.3, Part D stage 5, trap G.1.

### Problem Statement

When any bundle section has content, `_bundle_to_prompt` told the answer model
"The sections below are NOT empty -- relevant memory exists for this query and
must be used to answer it." LoCoMo-10 adversarial (category 5) questions ask
about things never said and are scored by abstention; that line pushes the
model to answer anyway. Replay R27b abstention on adversarial questions:
0/12 to 2/12.

### Decision and Implementation

1. **`[ask] answer_style = "cite" | "legacy"`**, default `"cite"`.
   `"legacy"` is the old instruction verbatim (A/B and rollback). Unknown
   values log a warning and use `"cite"`.
2. **cite text**: "Answer only from the lines below. Give a short answer, then
   quote the line you used. If no line answers the question, say you don't have
   that information." General statement, no dataset special-casing; asks for a
   short answer first so the reply is never a bare quote.
3. `_bundle_to_prompt(bundle, query, config=None)` gained an optional `config`
   (`run_ask` passes it). Empty-bundle text and `_ASK_SYSTEM_PROMPT` unchanged.
4. Harness variants H1/H2 (B304) untouched. H2's retry still says "NOT empty"
   (it only fires on an empty-claim answer, and is off by default).
   `campy-benchmarks/baselines.py` holds a *copy* of the old prompt, so the
   external baselines are not affected.

### Verification

- Unit: `tests/test_ask_prompt_assembly.py` (cite default, legacy verbatim,
  fallback, empty bundle identical across styles, config default).
- Merge gate (pending, needs the GPU): LoCoMo-10 adversarial >= 0.25 with no
  accuracy loss beyond noise on LoCoMo-10 and DMR, `cite` vs `legacy`.
