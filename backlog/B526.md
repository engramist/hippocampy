# B526: dialogue-act tagger trained on open corpora (spike)

**Status:** Open (after the B522–B525 ownership and count stack is gated)

## Why
Several capture problems are dialogue-act problems that we solve with wording rules today:
- B501 keeps first-person statements that end in "?" with a regex. A trained statement-vs-question tag is the general construction behind that rule (principle 4).
- Backchannels ("yeah", "right") are not agreement, and cue-word rules over-fire on them.
- Capture could skip questions and backchannels by structure, not by wording (principle 5).

Ingest has never used an annotated dialogue corpus. It uses off-the-shelf spaCy, hand rules (B501, B499, B523), the LLM extractor's closed predicate set, and the step2 gist classifier, which assigns topic classes, not dialogue acts.

## What the earlier project already found (2026-10-23, its lessons-learned)
Another project trained two distilroberta classifiers on these corpora and tested ready-made taggers:
- **MRDA:** ICSI meetings, 52 tags, CC BY 4.0, test accuracy 0.63.
- **SwDA:** 41 tags, CC BY-NC-SA 3.0, internal use only, test accuracy 0.775.

SwDA's licence rules out shipping weights from it in this Apache-2.0 repository; MRDA's allows it with attribution. Against that project's targets, every tagger was thin or imprecise (MRDA 24.5% precision, zero-shot NLI a 98.8% recall net). Its conclusion: use act tags as evidence for a judge, not as a filter, because a dialogue act is not a higher-level class. Its standards survey recommends ISO 24617-2 as the label backbone, mapping our own labels to it rather than inventing new ones.

What this changes for the spike: start from MRDA (or SILICONE's CC BY-SA bundle) for any shipped weights. Keep the target coarse (statement or question, plus backchannel), which those taggers do far better than fine-grained classes. Report the result as evidence for B501's construction, not as a capture filter.

## Spike (no GPU)
1. **Licences first.** Confirm the licence of each candidate annotation set (SwDA, MRDA, and any others) and of the underlying audio/transcript corpus. Record which may be used to train weights that ship in an Apache-2.0 repository. Stop if none may.
2. **Classifier.** A small classifier on the all-MiniLM-L6-v2 embeddings Campy already computes with ONNX Runtime (B512), trained with scikit-learn. No torch at runtime (B400); the weights are one small committed file plus the training script. Map the corpus tag set onto a few coarse acts: statement, opinion, question, answer, backchannel/acknowledgement, other.
3. **Measure on LoCoMo.** Tag LoCoMo turns and compare against B501's regex on the questions B501 gained and lost. Also tag the conv-42/43/47 holdout, which B501 was never tuned on, and report the agreement.

## Done when
A short result in the card:
- the licence verdict;
- tag accuracy on the corpus test split;
- agreement with B501 on LoCoMo, with the turns where they disagree.

If the tagger beats the regex on turns we haven't tuned on, the follow-up is a capture lever behind a flag. It names B501's construction as its target and is gated on the published metric.
