# B508: SKOS vocabulary for kinds — consolidation, instance-of vs broader (flag, default off)

**Status:** open (PR pending gate) · **Step 2 of 3** in the graph-structure plan (1 SHACL, 2 SKOS vocabulary, 3 OWL typed properties). Stacked on B504 and merges B507.

## Problem

B504 writes a kind Concept under each entity with one `IS_A` edge, and the kind is a free string the
model invents. Two weaknesses:

1. "kit", "model kit" and "model kits" become separate Concepts, so a question about "model kits"
   reaches only the entities hung on that exact string.
2. One `IS_A` edge means both "this is an instance of" and "this is a subtype of".

## Change (flag `[retrieval] skos_vocab` / `CAMPY_SKOS_VOCAB=1`, default off)

**Model.** A kind is a `skos:Concept` in `campy:KindScheme`. Stored as `Concept.kind_scheme = 'kind'`
(one new column) plus three new plain edges: `INSTANCE_OF` (entity to kind), `BROADER` (kind to broader
kind, `skos:broader`) and `CLOSE_MATCH` (`skos:closeMatch`). The prefLabel is the existing `text_raw`;
altLabels are the existing `Label` nodes via `HAS_ALT_LABEL`. The SKOS statements are projected from the
store (`shapes/validator.skos_project`, driven by `shapes/campy_vocab.ttl`), so nothing is stored twice.
`INSTANCE_OF` is a campy property and deliberately not `rdf:type`: typing instances by a kind would make
the kind a class as well as a `skos:Concept` (punning). `campy_vocab.ttl` declares `INSTANCE_OF`
`owl:propertyDisjointWith` `BROADER`.

**Consolidation (rules, no model; `hippocampus/kinds.py` `plan_kind`).** A new kind label is compared with
the kinds already in the scheme, by `norm_key` (case, article, plural):

- (a) equals an existing prefLabel or altLabel: the same kind. Reuse it; a differently worded surface
  ("model kits") is added as an altLabel (case-only differences are not wordings).
- (b) an existing kind's key is a proper word-suffix of the new key ("kit" of "model kit"): the longer
  is `skos:broader`-linked to the shorter, never merged and never an altLabel. English compounds are
  headed by their last word, so "model kit" is a kind of "kit"; an altLabel would assert they are
  interchangeable, which would make a question about model kits reach every kit. Order independent: a
  "kit" that arrives later adopts the existing longer kinds. Longest suffix wins; no transitive reduction
  (redundant edges are harmless to the walk). Known limit: lexicalised compounds ("ice cream" is not a
  cream); the cost is a wider walk, never a lost fact.
- (c) optional: an embedding of the new label at or above `skos_closematch_threshold` (default 0.90, 0 =
  off) to an existing kind's prefLabel: a `CLOSE_MATCH` edge only. Advisory: never merged, never walked.

**Write path.** Entity proposals from B504 go through `entities.resolve_kind`; the entity gets
`INSTANCE_OF` the kind, or `BROADER` when the entity is itself already a kind. `is_a` claims from B503
split the same way (object becomes a kind; a subject that is a kind gets `BROADER`, any other
`INSTANCE_OF`). Flag off: `IS_A` exactly as B504, no kind column written, no new edge.

**Retrieval.** B503's walk (`thalamus.bundle_concept_walk`, new `skos` parameter) follows `INSTANCE_OF`,
`BROADER` and legacy `IS_A` one step either way and siblings, and descends the `BROADER` closure: every
narrower kind and its instances. The question side also matches kinds by altLabel. The path fragments
B505's counts need are exported from `kinds.py` (`RELATION_PATH_UP`, `RELATION_PATH_NARROWER_CLOSURE`).

**Shapes** (`campy_shapes.ttl`, now written in SKOS): `skos:prefLabel` exactly one, non-blank, not
stopword-only (replaces the `text_raw` placeholder); `skos:altLabel` same content rule and not a repeat of
the prefLabel; `skos:broader` / `skos:closeMatch` must point to a `skos:Concept`; a kind (object of
`INSTANCE_OF`, either end of `skos:broader`) must be in `campy:KindScheme`; a Concept may not be its own
broader, nor carry `INSTANCE_OF` and `skos:broader` to the same kind; an `INSTANCE_OF` subject that is
itself a kind is a Warning.

**Report** (`scripts/graph_structure_report.py`): fragment and duplicate metrics now read the prefLabel;
new columns for number of kinds, share with an altLabel, duplicate-kind rate (kinds sharing a normalised
pref/alt label), share of entities with an instance-of kind (legacy `IS_A` counts, so a B504 store is
comparable).

## Not in this card

OWL functional / typed properties (step 3). A BROADER edge is not retracted when a closer kind later
appears between two (no transitive reduction). The B505 aggregation code (separate branch) still reads
`IS_A` only until it adopts `kinds.RELATION_PATH_*`.

## Gate to flip the default

Fresh-ingest LoCoMo conv-30 + conv-44, flags ENTITIES+GRAPH_LINKING+SKOS_VOCAB vs R91
(ENTITIES+GRAPH_LINKING); cat1-4 plus the structure report for both. Flip only on a pooled net gain.

## Principle

2 (graph first: the vocabulary is graph edges and one marker column), 3 (the model proposes a kind
string; rules consolidate it; an embedding only advises), 4 (the rules are linguistic constructions, not
fitted to a dataset).
