### Tasks

#### 1. Claude Code Community Marketplace

**Submission process:**
1. Run `claude plugin validate ./plugin` to verify the plugin structure
2. Submit via [claude.ai/settings/plugins/submit](https://claude.ai/settings/plugins/submit) or [platform.claude.com/plugins/submit](https://platform.claude.com/plugins/submit)
3. Plugin goes through automated safety screening + review
4. Once approved, appears in `anthropics/claude-plugins-community` catalog
5. Users install with: `claude plugin install @claude-community/hippocampy`

**Files to verify before submission:**
- `plugin/.claude-plugin/plugin.json` — must pass validation
- `plugin/skills/` — all SKILL.md files well-formed
- `plugin/hooks/hooks.json` — valid hook config
- `plugin/.mcp.json` — valid MCP config
- `plugin/README.md` — clear description and usage

#### 2. Codex Marketplace

**Submission process:**
1. Create a marketplace entry in the repo at `.agents/plugins/marketplace.json`:
```json
{
  "name": "hippocampy-plugins",
  "interface": {
    "displayName": "HippoCampy Plugins"
  },
  "plugins": [
    {
      "name": "hippocampy",
      "source": {
        "source": "git-subdir",
        "url": "https://github.com/djs54/hippocampy.git",
        "path": "./plugin",
        "ref": "main"
      },
      "policy": {
        "installation": "AVAILABLE",
        "authentication": "ON_INSTALL"
      },
      "category": "Productivity"
    }
  ]
}
```
2. Users add marketplace: `codex plugin marketplace add djs54/hippocampy`
3. Then install: `codex plugin install hippocampy`

**Note:** "Public plugin publishing is coming soon" per Codex docs. For now, use git-backed marketplace.

#### 3. Gemini CLI Extension Gallery

**Submission process:**
1. Verify `plugin/gemini-extension.json` is valid
2. Submit to Gemini extension gallery (process TBD — check https://geminicli.com/docs/extensions/ for latest submission instructions)
3. For now, users install directly: `gemini extensions install https://github.com/djs54/hippocampy`
