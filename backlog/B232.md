# B232 - Public Release Private Data Audit

State: complete
Priority: P0

Plan: backlog/plans/B-232-public-release-private-data-audit.md

### Problem

The provisional patent filing is complete, but public distribution still requires a release audit. The repository may contain personal paths, local machine details, generated artifacts, raw benchmark outputs, private notes, secrets-adjacent config, or proprietary tuning details that should not ship publicly.

A one-line installer should never expose private user data or accidentally publish implementation artifacts that are not intended for release.

### What This Card Does

Creates a public-release audit process for private data, machine-specific paths, generated artifacts, credentials, sensitive notes, and release-boundary decisions.

This card does not delete files blindly. It produces a manifest, classifies findings, updates ignore/package rules, and creates explicit remediation commits for anything that should be removed, archived, redacted, or excluded from distributions.

### Files to Create/Modify

| `MANIFEST.in` or `pyproject.toml` | CREATE/MODIFY - exclude non-package files from sdist/wheel |

### Acceptance Criteria

- [ ] Audit scans for API keys, tokens, private keys, local usernames, absolute home paths, machine-specific paths, `.env` files, generated DBs, generated logs, raw benchmark artifacts, and large generated outputs.
- [ ] Audit scans git-tracked files and package distribution contents separately.
- [ ] `docs/public-release-audit.md` classifies every finding as keep, redact, remove, archive, ignore-only, or package-exclude.
- [ ] No secret-like values are present in tracked release files.
- [ ] No local Kuzu DBs, logs, sockets, Obsidian generated wiki output, ARC raw result artifacts, or user transcript journals are included in wheel/sdist.
- [ ] Personal absolute paths are removed or converted to examples unless retained in historical docs with explicit rationale.
- [ ] Patent and inventor docs are classified explicitly: publish, keep private, or move to private archive.
- [ ] Package manifest excludes backlog archives and private research notes unless intentionally published.
- [ ] Audit script is safe to run repeatedly and exits nonzero for high-severity findings.
- [ ] Public README contains a concise local-data/privacy explanation.
