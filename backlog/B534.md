# B534: WordNet proposes kind hierarchy links between existing kinds

**Status:** Open — gate pending (stack gate on fresh conversations; target: count questions per scripts/gate_slice.py)

Lever 1d of the object-linking work, on top of B522-B525. A count question names a kind ("how many pets / dogs /
animals"), but capture files objects under their own kind (`dog`, `puppy`, `car`) with no `BROADER` links, so the
subject-anchored count (B524, which walks `INSTANCE_OF` then `BROADER*`) finds nothing for the broader word. The
head-noun rule of B508 links only compounds that share a last word ("model kit" under "kit"). WordNet is the standard
resource for the rest ("puppy" is a kind of "dog", "dog" a kind of "animal"), and runs in the NLP pipeline, before
any model. A later steward (B535) fills the common-sense gaps WordNet misses.

1. **One WordNet loader** (`temporal_lobe/lexicon/wordnet.py`): `lexname()` (B523's ownable test now calls it),
   `noun_synsets()`, `hypernym_closure()`, `plan_links()`. NLTK is imported on each call and not cached, so
   "WordNet absent" is a real state: every function then returns nothing and nothing breaks.
2. **The rule** (`plan_links`, pure given WordNet): for each live kind, the noun senses of its label (the whole phrase
   as a compound, else its last word) are walked up through hypernyms and instance hypernyms; for every OTHER live kind
   whose label or altLabel is a lemma of an ancestor, `kind BROADER ancestor-kind`. Closed set: no kind is created.
   Nearest only (a match that is itself an ancestor of another match is dropped), no link to a synonym or to the
   kind's own wording, no link to an over-general ancestor ("entity", "object", "whole" ...), none already present.
3. **Sense choice.** First (most frequent) sense only, on both ends: the child's senses, and the sense of the parent's
   word that the ancestor must be ("country" is a lemma of the synset "area", not its main sense, so "venue" is not put
   under "country"). `SENSE_FREQUENT` (0.5: also later senses at least half as frequent as the first) is available;
   measured on two stores it added mostly wrong links (PR body), so it is not the default.
4. **Both directions.** When a kind is created (`entities.resolve_kind`) the links involving it are proposed: up to
   existing broader kinds, and from existing narrower kinds to it (order independent). `scripts/backfill_wordnet_kinds.py`
   applies the rule to every kind in a store (on a COPY).
5. **Provenance.** The link carries `campy:link_source "wordnet"` on the edge's RDF-star reifier
   (`kinds.link_broader_sourced`; declared on the `BROADER` table). A link without it is the label rule's. Read by
   `kinds.broader_links_by_source` and `kinds.broader_links_detail`, both used by `scripts/graph_structure_report.py` and
   the backfill, so a steward can tell WordNet links from its own. The write is skipped when the pair is already related
   through `BROADER` in either direction (no duplicate path, no cycle).

Flag: `[observations] wordnet_kinds`, env `CAMPY_WORDNET_KINDS`, default off. Dependency: the optional extra
`wordnet` (`nltk>=3.8`, Apache-2.0) plus the corpus, a one-time `python -m nltk.downloader wordnet` (Princeton WordNet
3.0, a permissive licence that requires keeping its notice). Neither is needed to run Campy.

Serves Principles 2 (a standard lexical resource writes the hierarchy; Python never counts), 3 (WordNet proposes, the
rule decides, the source is recorded), 8 (a count over a kind a question can name reaches the entities filed under
narrower kinds). Measurements are in the PR. Gate pending.
