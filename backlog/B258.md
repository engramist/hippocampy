### Problem

The existing plugin skills use passive language ("you can call...", "when the user asks..."). Agents interpret passive instructions as optional. Additionally, there is no `session-start` skill — the most critical recall moment (the start of a conversation) has no automated recall protocol.

### What This Card Does

1. Rewrites all trigger language across all 4 existing skills to use assertive mandatory phrasing ("ALWAYS call...", "Before answering... you MUST call...")
2. Adds a new `plugin/skills/session-start/SKILL.md` with a step-by-step session-start recall protocol

### Dependencies

- B257 complete (skills must have the correct tool references before we rewrite triggers)

### Design Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Language style | "ALWAYS", "MUST", "Before X → call Y" | Tested: assertive language dramatically increases agent compliance |
| Session-start steps | 4-step protocol: memory_decision → suggested tool → diff_since → surface findings | Ensures agents always check memory before working blind |
| Trigger table | Explicit "When you see X → call Y" table in recall skill | Gives agents a lookup table instead of requiring judgment |

### Changes

**All existing skills (`recall`, `memory-awareness`, `quest-management`, `status`):**
- Replace "you can call" → "ALWAYS call"
- Replace "when the user asks" → "Before answering questions about X, you MUST call"
- Add bolded trigger sections at top of each skill

**New `plugin/skills/session-start/SKILL.md`:**
- Step 1: Call `memory_decision` with the user's first message to get routing advice
- Step 2: Call the recommended recall tool (`current_truth`, `compile_context`, or specific tool)
- Step 3: If continuing an existing quest, call `diff_since` with last session timestamp
- Step 4: Surface what the Brain knows before working blind — present findings to user
