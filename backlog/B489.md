# B489 - Verify Step for Cited Answers

State: implemented (off by default; gate pending: LoCoMo-10 replay with neighbours on, `CAMPY_ASK_ANSWER_STYLE=verify`)
Priority: P2

Plan: `learnings/e2e-improvement-plan.md`; follows B487 (stacked on it)

### Problem Statement

B487 neighbour turns help answerable LoCoMo questions (about +34 net over 3
conversations) but the answer model stops abstaining on adversarial questions
(correct abstentions 83/112 -> 62/112). Those questions ask about something
the other speaker said, or something nobody said. The "cite" prompt asks the
model to quote its supporting line and abstain otherwise, but the small model
quotes loosely related lines and answers anyway.

### Proposed Fix

New `[ask] answer_style = "verify"` (env `CAMPY_ASK_ANSWER_STYLE`; default stays
"cite"). The answer is produced with the "cite" prompt, then, in
`_verify_cited_answer` (`campy/brain/thalamus/ask.py`):

1. An abstention (no quote) is returned unchanged, no extra call.
2. Quotes are extracted ("..." , curly quotes, or a `Quote: ...` line). No
   quote -> abstain. No quote matches a rendered context line (normalised
   substring or token overlap >= 0.8) -> abstain.
3. One YES/NO call (same client; the client already runs at temperature 0)
   gets only the question and the matched line(s) with speaker/date stamp:
   "Does this line directly answer the question, about the same person the
   question asks about?" Not YES -> abstain. Verifier error -> keep the
   answer (fail open, warning logged).
4. `meta["verify"]` records `already_abstained | no_quote |
   quote_not_in_context | verifier_no | verifier_error | kept` (run_ask returns
   a string, so the status goes in the caller-supplied `meta` dict).

Abstention text: "I don't have that information."

### Measure

Replay gate on LoCoMo-10 with neighbours on: answerable accuracy vs
neighbours-only, and correct abstentions on adversarial questions; analyse by
`meta["verify"]`. Cost: one short extra call per cited answer.

Tests: `tests/test_b489_ask_verify.py`.
