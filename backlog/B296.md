### What This Card Does

**Phase 1 — Maintainer decision checklist (BLOCKING, not delegatable):** produce a table of the paths above with a keep-public / untrack / relocate recommendation, and get an explicit maintainer decision on each of: `InvertorsDocs/`, `docs/nonprovisional-strategy.md`, `backlog/` (all-or-parts), `benchmarks/`. The subagent PREPARES the table and STOPS for sign-off — it does not decide IP questions. Recommended defaults to present:
- `InvertorsDocs/` → **untrack** (move to a private `hippocampy-ip` repo or local-only dir; add to `.gitignore`). Rationale: provisional already establishes priority; publishing the notebook adds disclosure surface with no OSS benefit. Cross-check against the "public disclosure boundaries" section of `docs/nonprovisional-strategy.md` before finalizing.
- `docs/nonprovisional-strategy.md` → **untrack**; replace the README link with a short `PATENTS.md` stating only the public facts (application number, filing date, "no patent granted").
- `backlog/` → **keep** (it's honest OSS work-in-public and feeds the agent workflow) BUT scrub `BacklogRules.md` of account/entitlement details (model IDs tied to accounts, executor availability notes).
- `benchmarks/`, `mcpb/`, `agents/` → keep if they run; delete if they're stale post-ARC-extraction (check `docs/arc-extraction-cleanup-audit.md`).

**Phase 2 — Execute the decisions:**
1. For every "untrack": `git rm -r --cached <path>` (files stay on disk), add to `.gitignore`. **IMPORTANT — history:** untracking does NOT remove past commits. For `InvertorsDocs/` (if untracked), ask the maintainer whether to also purge history via `git filter-repo --path InvertorsDocs --invert-paths` — this is a force-push history rewrite; the maintainer already did one for the OpenClaw token (backup-bundle → filter-repo → force-push → resync procedure is proven; a pre-rewrite `git bundle create` backup is MANDATORY). If the maintainer declines the rewrite, record that the notebook remains in history and is therefore effectively published.
2. Harden `.gitignore`: ensure `CONTEXT.md`, `.serena/`, `nohup.out`, `build/`, `dist/`, `*.egg-info/`, `__pycache__/`, `.claude/worktrees/` are all covered (several currently rely on luck).
3. Scrub pass on what remains public: `grep -rniE "djshelton|/Users/|api[_-]?key|token" docs/ backlog/ README.md CONTRIBUTING.md --include="*.md" | grep -v ...` — review hits for personal paths/emails; fix or accept each explicitly. (The git-history secret scan was already done 2026-06-28 with gitleaks — 1 token found and purged; this pass is about *content* hygiene, not credentials.)
4. Run `gitleaks detect --source . --no-banner` once more at the end as a belt-and-suspenders check → must report "no leaks found".
