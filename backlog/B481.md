# B481 - Conversation Stage Misses Evidence: Question Filter and FTS Fusion

State: implemented (2026-10-11; flags default off, gate pending)
Priority: P2

Plan: learnings/e2e-improvement-plan.md Part G (retrieval plane)

### Problem Statement

On 50 held-out DMR stores (R30a) Campy's conversation stage found 18/39
labelled evidence turns (macro recall 0.464) against naive RAG's 24/39
(0.667). Two causes in `GraphGateway._bundle_conversation`:

1. The question filter drops any turn ending in "?", including turns that
   state a fact and ask back ("She lives in Texas with me. What about
   you?"). 8 of 21 misses.
2. The FTS query is the whole framed question, so generic words ("you",
   "said", "about", "earlier", "time") OR-match generic turns, and RRF
   (k=60) lifts them over evidence at vector rank 2-6. B470's common-term
   drop never fires in small stores. 9 of 21 misses.

### Proposed Fix (all opt-in; defaults are today's behaviour)

New query `thalamus.bundle_conversation_v2` (G.2: no params added to the
existing query), fed by `bundle_compiler._stage_conversation`:

- `[retrieval] question_filter = "trailing" | "all_questions"`
  (`CAMPY_RETRIEVAL_QUESTION_FILTER`). `all_questions` drops a turn only if
  every sentence is a question; `ask`'s question echoes (a single question,
  also caught by the exact-echo and 0.985 similarity checks) stay excluded.
- `[retrieval] fts_query = "full" | "content"` (`CAMPY_RETRIEVAL_FTS_QUERY`).
  `content` builds the FTS query from content words only (spaCy English
  stopwords, which include pronouns, plus a short list of reporting and
  discourse words); nothing left means no FTS for that query. B470's
  common-term drop still applies afterwards.
- `[retrieval] fts_fusion = "rrf" | "extra_only"`
  (`CAMPY_RETRIEVAL_FTS_FUSION`). `extra_only`: FTS never changes a vector
  hit's rank; FTS-only hits queue after the last vector hit in FTS order.

### Measure

Offline on the 50 R30a DMR stores with the real stage code (macro evidence
recall): defaults 0.464, A 0.548, A+B 0.637, A+C 0.637, A+B+C 0.637.
Tuned on a held-out diagnostic, so it MUST be gated on the large dev sets
(DMR dev, LoCoMo-10, LongMemEval) before any default changes; FTS matters for
B459/B470 lexical-only hits on LoCoMo-10 and LongMemEval.
