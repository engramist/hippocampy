## Summary of the Invention

The present invention relates to computer-implemented systems for maintaining long-horizon memory and context in artificial-intelligence assistants, especially assistants used across extended, multi-session projects. Conventional large language model systems rely primarily on short-lived context windows, static retrieval-augmented generation, or passive memory layers that store text fragments or facts without a reliable mechanism for selectively consolidating, structuring, revising, and ranking memory over time. As a result, such systems tend to suffer from context bloat, repeated failed experimentation, weak contradiction handling, and poor continuity across sessions, users, tools, or devices.

The disclosed invention addresses these technical problems through a graph-native memory architecture centered on a Gated Consolidation Loop. In one embodiment, incoming user or assistant turns are passively captured through adapter infrastructure and processed through an ordered multi-step consolidation method including concept extraction, relation extraction, dual-process classification, ontology-aware routing, confidence-gated memory admission, retrieval against existing graph state, contradiction arbitration, and pathway update. Rather than treating memory as a passive storage layer, the system actively determines whether newly observed information should be ignored as noise, stored as tentative memory, or committed as confirmed structural memory.

In preferred embodiments, the system stores memory in a relational knowledge graph backed by vector search, enabling both semantic retrieval and constrained structural traversal. Temporal truth is preserved by maintaining lineage when information changes. Contradictory information does not require destructive overwrite; instead, prior state may be preserved under explicit deprecation lineage while a new artifact is introduced, thereby supporting auditability and deterministic rollback. In further embodiments, use-based strengthening and inactivity-based weakening are applied to memory pathways so that memory state evolves according to access patterns rather than simple accumulation.

The invention further introduces selective attention mechanisms modeled on cognitive heuristics. In one implementation, inbound content is evaluated through multiple attention channels corresponding to decision signals, constraint signals, planning signals, entity signals, contradiction signals, and anomaly signals. These signals feed a confidence gate that determines whether the content remains in a low-priority evidence layer or is promoted into structural memory. This approach reduces noise formation while retaining recoverable evidence for later re-scoring.

In another aspect, the invention organizes long-horizon work into quest structures, including a primary quest and one or more secondary quests. New sessions or conversation threads are routed to these structures using a multi-signal fusion process that may consider semantic similarity, entity overlap, workspace context, and prediction error. If a thread is initially routed incorrectly, the system can detect the mismatch and re-anchor the thread while preserving rerouting lineage. This quest-based structure enables long-running projects to remain coherent while still supporting exploratory tangents.

In still another aspect, the invention tracks what contextual artifacts have already been loaded into an active session. This working-memory awareness allows the system to suppress redundant reinjection, selectively refresh only high-salience items, and seed follow-on sessions with the most relevant previously loaded artifacts. The result is improved token efficiency and better continuity across sessions.

Accordingly, the invention provides a concrete technical improvement in AI memory systems by combining graph-native storage, selective memory admission, structured contradiction handling, temporal lineage, working-memory state tracking, and quest-based routing into a unified architecture that supports persistent, auditable, and adaptive long-horizon operation.
