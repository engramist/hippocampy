# SideQuests Brain — PPA Filing Packet Checklist

This checklist turns Step 3 and Step 4 of the filing guide into a concrete packet-assembly workflow tied to the files already present in this repository.

---

## What Gets Filed vs. What Stays Internal

### File with the provisional application

- Written description / specification in DOCX
- Drawings as static figure pages
- Cover sheet PTO/SB/16
- Micro entity certification PTO/SB/15A, if claiming micro entity status

### Keep internal only

- `InvertorsDocs/PriorArtSearch.md`
- Drafting artifacts such as Mermaid or Excalidraw source files
- Research notes used to shape the background and summary sections
