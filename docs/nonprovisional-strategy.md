## What "Patent Pending" Means and Does Not Mean

**What it means:**
- A U.S. provisional patent application has been filed establishing priority date (March 25, 2026).
- The system is eligible for utility patent protection if a non-provisional application is filed before March 25, 2027.
- Public disclosure or product launch does not forfeit provisional protection or priority date.

**What it does NOT mean:**
- No patent has been granted.
- No claims have been examined or approved by the USPTO.
- Competitive products using similar techniques are not blocked.
- The system is not automatically protected until a utility patent issues (if ever).

## Core Patent Claims Documented in Architecture

*These are the invention's key distinguishing features. All are implemented and evidenced in code.*

1. **Gated Consolidation Loop (9-Step Pipeline)**
   - Shape-first principle: ontological classification before semantic work
   - Multi-layer confidence gates (Step 4 <60% filter)
   - Dual-process routing (System 1/System 2 hybrid)
   - Temporal truth handling and reversible merges

2. **Hippocampus Mechanism (Semantic Quest Routing)**
   - Multi-signal routing fusion (context + entity overlap + semantic intent + legacy git)
   - Prediction-error driven dynamic re-routing
   - Session Handoff Intelligence (top 5 loaded thoughts transferred across devices)
   - Works without developer-tool dependencies

3. **Cocktail Party Effect (Selective Attention)**
   - Passive always-on interception model
   - Six cognitive senses: Decision, Constraint, Plan, Entity, Contradiction, Anomaly
   - Out-of-band behavioral integrity monitoring (constraint violation detection)
   - Zero-attack-surface observer architecture

4. **Biomimetic Heuristic Engine**
   - Hebbian Learning ("fire together, wire together")
   - Long-Term Potentiation (LTP) via dual-edge architecture
   - Synaptic Pruning (Ebbinghaus forgetting curve with exponential decay)
   - Dynamic Hybrid Ontology Routing (gist + schema.org)

5. **Cross-Quest Analogical Reasoning**
   - Lesson nodes synthesized at quest completion
   - Transfer learning from historically distinct projects
   - Domain-agnostic knowledge graph normalization

6. **Graph-Native Persistence and Resilience**
   - Kuzu property graph as single source of truth
   - Deterministic incident recovery (Step 4/5/6 durable checkpoints)
   - Multi-session temporal tracking (FOLLOWED_BY, DECISION_CHAIN)
   - Knowledge gap detection and procedural memory reuse

7. **Memory-Based Intrusion Detection (Security Claim)**
   - Out-of-band passive observation detects prompt injections
   - Constraint violation alerts flag erratic behavior
   - Conversation-layer anomaly detection independent of main agent
